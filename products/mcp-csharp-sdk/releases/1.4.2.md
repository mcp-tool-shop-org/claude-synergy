# mcp-csharp-sdk v1.4.2

**This patch release includes security fixes for OAuth authentication and authenticated HTTP sessions.**

## What's Changed

* Validate OAuth PKCE support and metadata issuer #1949 by @halter73 (co-authored by @PranavSenthilnathan @Copilot)

Deployments using metadata-free 2025-03-26 OAuth discovery may explicitly enable the legacy endpoint fallback only after independently verifying PKCE enforcement; otherwise, update metadata to advertise S256. The process-wide opt-in is `ModelContextProtocol.Authentication.AllowLegacyOAuthMetadataFallback`; it does not bypass validation of discovered metadata.

* Harden authenticated HTTP session handling ([7c5d15e](https://github.com/modelcontextprotocol/csharp-sdk/commit/7c5d15e05e21b4166adf3c56c4601bf6b15d0c2d)) by @halter73 (co-authored by @jeffhandley @PranavSenthilnathan @Copilot)
