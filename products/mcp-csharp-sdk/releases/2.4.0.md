# mcp-csharp-sdk v2.4.0

Version 2.4.0 adds experimental MCP Skills support through the new [ModelContextProtocol.Extensions.Skills](https://nuget.org/packages/ModelContextProtocol.Extensions.Skills) package, alongside OAuth hardening and reliability improvements for transport, session, and discovery flows. MCP Apps also now match protocol property names case-sensitively.

## What's Changed

* Add the experimental MCP Skills extension #1856 by @girishkvs (co-authored by @PederHP)
* Align Skills with server primitives and typed request handlers #1993 by @halter73 (co-authored by @Copilot)
* Require explicit opt-in for the legacy OAuth metadata fallback #1952 by @halter73 (co-authored by @Copilot)
* Preserve refresh tokens when OAuth refresh responses omit replacements #1968 by @halter73 (co-authored by @Copilot)
* Preserve canonical OAuth resource identifiers during refresh #1967 by @halter73 (co-authored by @Copilot)
* Fix cancellation being reported as missing OAuth metadata #1891 by @Empiree
* Cancel open subscriptions/listen requests when the transport stops delivering messages #1933 by @pournasserian (co-authored by @Copilot)
* Fix dropped notifications and cancellation when a request is canceled #1917 by @zerotohero3
* Prevent server/discover probes from committing the negotiated protocol version #1956 by @PrathmeshPawar2110 (co-authored by @claude)
* Fall back to SSE when AutoDetect receives a 405 with a JSON-RPC error body #1849 by @ump45nose
* Fix legacy output schemas for delegating server tools #1928 by @Oxygen56
* Match protocol property names case-sensitively #1934 by @FenjuFu
