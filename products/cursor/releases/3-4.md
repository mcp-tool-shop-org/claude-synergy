# cursor — Full-screen Tabs and Compact Chats

<p>This release introduces quality-of-life improvements to the <a href="https://cursor.com/docs/agent/agents-window">Agents Window</a>.</p>
<h2>Full-screen tabs</h2>
<p>Full screen maximizes the right panel so you can focus on a single tab.</p>
<p>Files, changes, canvases, PRs, browsers, and terminals can expand to fill the entire working area. This replaces the agent chat with a floating prompt bar.</p>
<p>Enter and exit full screen by clicking on the expand/contract button in the panel header, using the command palette, or pressing `Cmd/Ctrl+Shift+M`.</p>
<h2>Compact chat responses</h2>
<p>Compact chats give you a tighter view of your agent conversations so you can read threads more quickly without losing important context.</p>
<p>Customize tool call density to control how much of the agent&#39;s tool activity is shown in each response:</p>
<ul>
<li>Compact: shows concise results with minimal tool traces</li>
<li>Balanced: includes important intermediate steps</li>
<li>Detailed: provides near-complete step-by-step context</li>
</ul>
<p>Improvements (8)</p>
<ul>
<li>Improved PR tabs by adding clearer review states, better reviewer/thread visibility, and more predictable PR tab actions.</li>
<li>Improved long-chat scrolling to make it smoother, added better undo grouping in prompt input, and improved behavior while streaming.</li>
<li>Added clearer status text for background/resumed tasks.</li>
<li>Added cleaner environment/repo selection and better persistence when switching contexts.</li>
<li>Improved MCP auth token lifecycle handling.</li>
<li>Removed noisy in-app terminal notifications and improved shortcut behavior.</li>
<li>Clarified model naming and selection behavior in the model picker and added stronger fallback handling.</li>
<li>Improved search and navigation to make it faster and more reliable in large workspaces.</li>
</ul>
<p>Bug Fixes (9)</p>
<ul>
<li>Fixed PR tab bugs affecting branch lookup, header state, and diff loading.</li>
<li>Fixed background task reliability issues like resume failures, interrupt edge cases, and incorrect status scoping on resumed subagents.</li>
<li>Fixed cloud agents bugs blocking setup, state merge/persistence bugs, and multi-repo identity issues.</li>
<li>Fixed MCP/OAuth reliability bugs like transient 401/stale-token cases and large-token handling edge cases.</li>
<li>Fixed edge cases around slash menu + approval regressions, ask-question flow issues, and paste-chunk handling.</li>
<li>Fixed keyboard shortcuts bugs in modals, vim/emacs caret style leakage, and other key handling.</li>
<li>Fixed hook invocation/path-length issues and Git prompt-related regressions.</li>
<li>Fixed model-routing mismatches, proxy body normalization, and thought-chunk forwarding issues.</li>
<li>Fixed webhook auth/hostname resolution, GHES installation persistence, and mirrored-repo behavior.</li>
</ul>
