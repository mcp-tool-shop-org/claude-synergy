# cursor — Voice Chat with Agents

<p>You can now talk with your agents in a realtime voice call. Describe a change out loud, ask what an agent is working on, and hear updates as the work moves forward.</p>
<p>Voice chat works in the Agents Window, the IDE, on web, and in Cursor for iOS.</p>
<h2>Start a call</h2>
<p>When the agent is idle and the chat input is empty, click the waveform button labeled **Start voice chat**. It sits where Send usually is, next to the microphone button for dictation.</p>
<p>On iOS, you can also say &quot;Hey Siri, call Cursor&quot; to start a call with a new agent, and mute or hang up from the Lock Screen with a Live Activity.</p>
<h2>Talk while the agent works</h2>
<p>The voice agent listens, replies, and hands coding work to the agent in your chat. While that agent runs, you can keep the conversation going. Ask what changed in a diff, check on a run, search earlier messages and calls with this agent, or switch between workers in a Project that has them.</p>
<p>The coding agent speaks for itself too. It shares short progress notes while it works and a brief answer when it&#39;s done, so you usually hear a short update instead of the full written reply.</p>
<h2>Powered by Grok Voice</h2>
<p>Voice chat runs on Grok Voice. Pick from many voices in Voice settings, including Ara, Eve, Leo, Rex, and Sal. With Privacy Mode on, voice chat runs with zero data retention.</p>
<h2>Voice chat and dictation</h2>
<p>Voice chat is separate from dictation, which earlier releases called Voice Mode. Dictation still turns your speech into text in the chat input, and Cmd+Shift+Space still toggles it in the IDE. Voice chat is a two-way conversation where the agent answers out loud.</p>
<p>Update Cursor to try voice chat. Learn more in our <a href="https://cursor.com/docs/agent/voice-chat">docs</a>.</p>
