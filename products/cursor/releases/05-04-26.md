# cursor — Model controls, spend management, and usage analytics

<p>This release introduces updates for Enterprise admins: a new system for model controls, updated spend management, and more detail for usage analytics.</p>
<h2>Model access controls</h2>
<p>Admins can now set more granular allow or blocklists at the model and provider level. You can block entire providers or specific model configurations for speed and context window size.</p>
<p>Enterprises also have the option to block new providers or model versions by default.</p>
<p>Customers with existing blocklists will need to migrate to the new system by June 1st. Admins should go to their <a href="https://cursor.com/dashboard/team-settings/models">team model settings</a> in the Cursor dashboard to get started.</p>

<h2>Soft spend limits and intelligent alerts</h2>
<p>Admins can now set soft limits instead of hard limits to avoid blocking users. Cursor can also monitor usage and sends automatic alerts to users reaching 50%, 80%, and 100% of their soft or hard limits.</p>
<p>This keeps users productive while giving admins and users visibility into consumption patterns.</p>
<p>Go to the <a href="https://cursor.com/dashboard/spending">spend management settings</a> in the Cursor dashboard to get started.</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/cpp_videos/spend-alerts.mp4&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<h2>Updated usage analytics tab</h2>
<p>Admins can now filter usage by specific users, or break it down by product surface: clients, Cloud Agents, automations, Bugbot, and Security Review.</p>
<p>Go to the <a href="https://cursor.com/dashboard/usage">usage analytics tab</a> in the Cursor dashboard to get started.</p>
