# cursor — CLI Improvements and Mermaid ASCII Diagrams

<p>This release introduces the ability to hand off plans from the CLI to the cloud, in-line rendering of ASCII diagrams, and many quality-of-life improvements.</p>
<h3>Plan mode improvements in CLI</h3>
<p>When a plan is generated, the CLI now shows a persistent decision menu. You can choose to build in the cloud or build locally to execute the plan.</p>
<p>Typing `/plan` takes you back to your current plan and its action menu. We&#39;ve also added keyboard shortcuts in the prompt bar so you can use arrow keys to navigate options, `Enter` to execute the selected option, and `Shift+Enter` as a shortcut for &quot;Build in cloud.&quot;</p>
<h3>Mermaid ASCII diagrams in CLI</h3>
<p>Mermaid code blocks now render inline as ASCII diagrams in your CLI conversation. Flowcharts, sequence diagrams, state machines, class diagrams, and ER diagrams can all be displayed directly in the terminal.</p>
<p>`Ctrl+O` allows you to switch between the rendered diagram and the original mermaid source to see both representations.</p>
<h3>Other improvements</h3>
<p>We&#39;ve also made lots of improvements to the CLI focused on tooling, quality of life, and reliability.</p>
<p>General (6)</p>
<ul>
<li>AI code and conversations in CLI are now tracked by <a href="https://cursor.com/docs/integrations/cursor-blame">Cursor Blame</a>.</li>
<li>AI code attribution is now preserved by Cursor Blame when formatters like Prettier, Biome, or pre-commit hooks rewrite code.</li>
<li>File deletions are tracked by Cursor Blame to reflect the full lifecycle of code.</li>
<li>Clipboard operations on Linux now work with Wayland (`wl-copy`) and X11 (`xclip`) for better compatibility across desktop environments.</li>
<li>Agent sessions are now saved as JSONL transcripts. Headless mode also writes transcripts, making it easier to review and debug non-interactive runs.</li>
<li>CLI now stores conversation transcripts that the agent can use as context.</li>
</ul>
<p>Tools (5)</p>
<ul>
<li>Unified domain allowlisting for WebSearch and WebFetch.</li>
<li>Known-safe URLs (e.g. Cursor docs) are auto-approved without permission prompts.</li>
<li>When an MCP server&#39;s credentials expire mid-session, the agent can now re-authenticate on demand instead of failing silently.</li>
<li>If you skip approving an MCP server, it stays disabled for the rest of the session rather than prompting you repeatedly.</li>
<li>The <a href="https://cursor.com/docs/agent/terminal#sandbox-configuration">sandbox</a> in the CLI now supports granular network access controls: user config only, user config with defaults, or allow all.</li>
</ul>
<p>UX (14)</p>
<ul>
<li>`/resume` now sorts by last interaction time, not creation time, so your most recent conversations appear first.</li>
<li>Model reasoning and thinking blocks are now rendered inline as they stream in.</li>
<li>Markdown tables now wrap text within cells, use box-drawing borders, and correctly handle escaped pipes.</li>
<li>Your message appears right after sending, and the &quot;Generating...&quot; indicator clears as soon as the model finishes rather than waiting for the full stream to close.</li>
<li>`/auto-run`, `/max-mode`, `/vim`, and similar commands now toggle with a single invocation. Current status is shown in the command description.</li>
<li>Slash commands are ranked by how closely they match what you&#39;ve typed, with recency as a tie-breaker.</li>
<li>Added Emacs-style navigation: **`Ctrl+N`/`Ctrl+P`** for up/down and **`Ctrl+G`** for cancel/dismiss, alongside the existing arrow keys and `Esc`.</li>
<li>Added keybindings: `Alt+Delete` deletes the previous word; `Ctrl+D` exits questionnaire prompts.</li>
<li>Use `--yolo` and `--force` flags to approve workspace trust, skip MCP confirmation prompts, enable auto-run, and activate web tools.</li>
<li>Tool output now distinguishes &quot;Cancelled&quot; (you stopped it) from &quot;Interrupted&quot; (stopped externally).</li>
<li>When the sandbox isn&#39;t available, the message now explains why for your specific OS.</li>
<li>Reduced padding, removed the sandbox lock icon from shell prompts, and tightened up visual spacing throughout the CLI interface.</li>
<li>CLI output now detects your terminal&#39;s dark or light background and adjusts colors to match.</li>
<li>Shell and task durations now display in minutes and seconds.</li>
</ul>
<p>Reliability and Bug Fixes (17)</p>
<ul>
<li>Auto-updates now run in the background for faster time-to-interactive.</li>
<li>Reduced boot time.</li>
<li>Automatically retries connection on transport errors and stalls, with checkpoint-aware state recovery.</li>
<li>Background subagent resumes are now queued instead of interrupting running subagents.</li>
<li>403 errors no longer trigger logout.</li>
<li>Fixed hanging headless mode when workspace trust is required; `-force` now implicitly trusts the workspace.</li>
<li>`approvalMode: &quot;unrestricted&quot;` is now respected without requiring `-force`.</li>
<li>Fixed abort restore so when no checkpoint exists, state rolls back cleanly and user text is preserved.</li>
<li>Fixed `resume` in non-git workspaces.</li>
<li>Fixed stale model lookup after model renames.</li>
<li>Fixed auto-run not applying to delete and MCP tools when toggling with `Shift+Tab`.</li>
<li>Fixed iTerm2 `Ctrl+J` for newlines.</li>
<li>Hardened sudo askpass helper and fixed sudo prompts on macOS.</li>
<li>Fixed Windows Delete key sending forward-delete instead of backspace.</li>
<li>Fixed duplicate rendering artifacts during state transitions.</li>
<li>Fixed a readability issue with user message colors on light backgrounds.</li>
<li>Relative paths in `sandbox.json` now resolve correctly against their config file location.</li>
</ul>
