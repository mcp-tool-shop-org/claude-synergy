# cursor — Subagents, Skills, and Image Generation

<p>Agents are solving increasingly complex, long-running tasks across your codebase. This release introduces new agent harness improvements for better context management, as well as many quality-of-life fixes in the editor and CLI.</p>
<h3>Subagents</h3>
<p>Subagents are independent agents specialized to handle discrete parts of a parent agent&#39;s task. They run in parallel, use their own context, and can be configured with custom prompts, tool access, and models.</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/agent-subagents.mp4&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<p>The result is faster overall execution, more focused context in your main conversation, and specialized expertise for each subtask.</p>
<p>Cursor includes default subagents for researching your codebase, running terminal commands, and executing parallel work streams. These will automatically start improving the quality of your agent conversations in the editor and the <a href="https://cursor.com/docs/cli/overview">Cursor CLI</a>.</p>
<p>Optionally, you can define custom subagents. Learn more in our <a href="https://cursor.com/docs/context/subagents">docs</a>.</p>
<h3>Skills</h3>
<p>Cursor now supports <a href="https://cursor.com/docs/context/skills">Agent Skills</a> in the editor and <a href="https://cursor.com/docs/cli/overview">CLI</a>. Agents can discover and apply skills when domain-specific knowledge and workflows are relevant. You can also invoke a skill using the slash command menu.</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/agent-skills-jan-23.mp4&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<p>Define skills in `SKILL.md` files, which can include custom commands, scripts, and instructions for specializing the agent’s capabilities based on the task at hand.</p>
<p>Compared to always-on, declarative <a href="https://cursor.com/docs/context/rules">rules</a>, skills are better for <a href="https://cursor.com/blog/dynamic-context-discovery">dynamic context discovery</a> and procedural “how-to” instructions. This gives agents more flexibility while keeping context focused.</p>
<h3>Image generation</h3>
<p>Generate images directly from Cursor&#39;s agent. Describe the image in text or upload a reference to guide the underlying image generation model (Google Nano Banana Pro).</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/01-22-26-image-gen-3.mp4&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<p>Images are returned as an inline preview and saved to your project&#39;s `assets/` folder by default. This is useful for creating UI mockups, product assets, and visualizing architecture diagrams.</p>
<h3>Cursor Blame</h3>
<p>On the Enterprise plan, <a href="https://cursor.com/docs/integrations/cursor-blame">Cursor Blame</a> extends traditional git blame with AI attribution, so you can see exactly what was AI-generated versus human-written.</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/01-22-26-cursor-blame.mp4&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<p>When reviewing or revisiting code, each line links to a summary of the conversation that produced it, giving you the context and reasoning behind the change.</p>
<p>Cursor Blame distinguishes between code from Tab completions, agent runs (broken down by model), and human edits. It also lets you track AI usage patterns across your team&#39;s codebase.</p>
<h3>Clarification questions from the agent</h3>
<p>The interactive Q&amp;A tool used by agents in Plan and Debug mode now lets agents ask clarifying questions in any conversation.</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/01-22-26-agent-ask-questions.mp4&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<p>While waiting for your response, the agent can continue reading files, making edits, or running commands, then incorporate your answer as soon as it arrives.</p>
<p>You can also build custom subagents and skills that use this tool by instructing them to &quot;use the ask question tool.&quot;</p>
<p>Improvements (29)</p>

<li>Agents can now proactively request switching <a href="https://cursor.com/docs/agent/modes">modes</a> mid-conversation when it detects a different mode would be more effective for the task. You can also auto-approve and auto-reject specific transitions.</li>
