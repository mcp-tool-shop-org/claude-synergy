# cursor — Cursor in JetBrains IDEs

<p>Cursor is now available in IntelliJ IDEA, PyCharm, WebStorm, and other JetBrains IDEs through the Agent Client Protocol (ACP).</p>
<p>With Cursor ACP, developers who rely on JetBrains for Java and multilanguage support can use any frontier model from OpenAI, Anthropic, Google, and Cursor for agent-driven development.</p>
<p>Install the Cursor ACP directly in your JetBrains IDE from the ACP Registry, and authenticate with your existing Cursor account.</p>
<p>Read more in our <a href="https://cursor.com/blog/jetbrains-acp">announcement</a>.</p>
