# cursor — CLI Debug Mode and /btw Support

<p>We&#39;ve shipped quality-of-life improvements to the Cursor CLI to make working with agents in the terminal more delightful.</p>
<h2>Debug Mode in CLI</h2>
<p>Use `/debug` to find root causes and fix tricky bugs that are hard to reproduce or understand. In <a href="https://cursor.com/docs/agent/debug-mode">Debug Mode</a>, Cursor generates hypotheses, adds log statements, and uses runtime information to pinpoint the issue before making a targeted fix.</p>
<h2>/btw support in CLI</h2>
<p>Ask a quick side question without derailing the agent&#39;s main task. `/btw` allows you to get clarification on the change Cursor is making without stopping the current run.</p>
<h2>Configuration menu in CLI</h2>
<p>`/config` opens an interactive settings panel inside the CLI where you can view and change behavior, such as model choices, defaults, runtime preferences, and more.</p>
<p>You can also ask Cursor to apply configuration changes for you using the `/update-cli-config` skill.</p>
<h2>Custom status bars in CLI</h2>
<p>Customize the status bar using /statusline to surface the session and runtime signals you care about, including current mode, branch, environment, active task hints, or other session metadata.</p>
<p>CLI Improvements</p>
<ul>
<li>Trigger the model picker from anywhere to switch models without clearing your prompt first.</li>
<li>If Cursor detects you&#39;ve enabled auto-run three times in a row, it will now proactively suggest turning it on to help avoid endless approval loops.</li>
<li>The AskQuestion tool and Debug Mode now handle plaintext responses more smoothly.</li>
<li>Image paste from clipboard is now supported, including `Ctrl+V` in some terminals without native paste support.</li>
<li>The footer now shows your working directory, worktree, and current branch.</li>
</ul>
<p>CLI Bug Fixes</p>
<ul>
<li>You can now reliably send the CLI to the background using `Ctrl+Z`.</li>
<li>Auto-run now works in other modes like Debug Mode and Plan Mode.</li>
<li>Fixed an issue where background shell processes could remain running after quitting the CLI.</li>
<li>Fixed slash command handling and matching.</li>
<li>Fixed keyboard handling for `Cmd+Delete`, Vim keybindings, and `Ctrl` modifier combinations.</li>
</ul>
