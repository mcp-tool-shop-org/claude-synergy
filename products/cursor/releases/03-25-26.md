# cursor — Self-hosted Cloud Agents

<p>Cursor now supports <a href="https://cursor.com/docs/cloud-agent/self-hosted">self-hosted cloud agents</a> that keep your code and tool execution entirely in your own network.</p>
<p>Your codebase, build outputs, and secrets all stay on internal machines running in your infrastructure, while the agent handles tool calls locally.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/blog/og/self-hosted-og-image.png&quot; loading=&quot;lazy&quot; alt=&quot;Use Cursor&#39;s agent experience with workers that run inisde your own infrastructure&quot; /&gt;&lt;figcaption&gt;Use Cursor&amp;#39;s agent experience with workers that run inisde your own infrastructure&lt;/figcaption&gt;&lt;/figure&gt;</p>
<p>Self-hosted cloud agents offer the same capabilities as Cursor-hosted cloud agents, including isolated VMs, full development environments, multi-model harnesses, plugins, and more.</p>
<p>Try it out today by enabling self-hosted cloud agents in your <a href="https://cursor.com/dashboard/cloud-agents#self-hosted-agents">Cursor Dashboard</a>. Read more in our <a href="https://cursor.com/blog/self-hosted-cloud-agents">announcement</a>.</p>
