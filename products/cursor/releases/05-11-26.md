# cursor — Bugbot Effort Levels

<p>Teams admins and Individual plan users can now customize the effort level Bugbot uses for its PR reviews, with three different configurations:</p>
<ul>
<li>**Default:** Bugbot continues to use the same effort level as it does today. Optimized for efficiency and speed.</li>
<li>**High:** Bugbot spends more time reasoning. Reviews are more expensive and take longer, but Bugbot may find more bugs.</li>
<li>**Custom:** Describe in natural language when Bugbot should use default or high effort. Cursor will dynamically set effort levels based on your instructions.</li>
</ul>
<p>Customers must be on usage-based billing for Bugbot to customize effort levels. Learn more in our <a href="https://cursor.com/docs/bugbot#effort-levels">docs</a> and go to your <a href="https://cursor.com/dashboard/bugbot#effort-levels">Bugbot dashboard</a> to get started.</p>
<p>Bugbot improvements</p>
<ul>
<li>With default effort, Bugbot finds 0.7 bugs per run, on average. Over 79% of these bugs are resolved by users at merge time.</li>
<li>With high effort, Bugbot finds 0.95 bugs per run, on average.</li>
</ul>
