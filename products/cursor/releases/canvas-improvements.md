# cursor — Canvas Design Mode and Context Usage Report

<p>With <a href="https://cursor.com/docs/agent/tools/canvas">canvases</a>, agents can create interactive artifacts like dashboards, reports, and internal tools that you can <a href="https://cursor.com/changelog/shared-canvases#shared-canvases">share with your team</a>.</p>
<p>This release introduces Design Mode for faster canvas editing, new ways to understand context usage, and other quality-of-life improvements.</p>
<h2>Design Mode in canvases</h2>
<p>Design Mode is now available in canvases.</p>
<p>Select and annotate UI elements directly in a canvas to guide Cursor&#39;s edits, just as you would in the browser. Instead of describing the change in text, you can point to it, provide feedback, and iterate more quickly.</p>
<h2>Context usage report in canvas</h2>
<p>Cursor can now show your agent&#39;s <a href="https://cursor.com/docs/agent/prompting#context-usage">context usage</a> as an interactive report in a canvas.</p>
<p>The context explorer breaks down where tokens go across the system prompt, tool definitions, rules, skills, and more. Because it&#39;s a canvas, you can ask the agent follow-up questions, and it can customize the report to answer your specific questions.</p>
<p>Click the Debug with Agent button embedded in the canvas to ask Cursor to identify opportunities to reduce context usage in a new conversation.</p>
<p>Canvas Improvements (4)</p>
<ul>
<li>Shared canvases can now be opened full-screen in the browser, making them easier to present to others.</li>
<li>Added the ability for agents to embed buttons in canvases that will run a specific prompt when clicked.</li>
<li>Improved the agent&#39;s ability to fix canvas type errors.</li>
<li>Improved component styling, and added more chart customization functionality.</li>
</ul>
