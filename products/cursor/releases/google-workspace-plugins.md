# cursor — Google Workspace Plugins

<p>Cursor can now read, write, and act across your Google Workspace.</p>
<p>New plugins give coding agents direct access to Gmail, Google Drive, and Calendar, so you can pull context, draft and update files, and manage your inbox and calendar without leaving Cursor.</p>
<p>Install plugins to connect:</p>
<ul>
<li>**<a href="https://cursor.com/marketplace/cursor/google-drive">Google Drive</a>:** search files and folders, open and download content, create and organize files</li>
<li>**<a href="https://cursor.com/marketplace/cursor/gmail">Gmail</a>:** search and read mail, draft and send messages, apply labels and manage threads</li>
<li>**<a href="https://cursor.com/marketplace/cursor/google-calendar">Google Calendar</a>:** read schedules, create and update events, find free time</li>
</ul>
<p>Browse the new plugins in the <a href="https://cursor.com/marketplace">Cursor Marketplace</a> or install them from the Customize page in Cursor. Learn more in our <a href="https://cursor.com/docs/plugins">docs</a>.</p>
