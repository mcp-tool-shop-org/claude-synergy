# cursor — Cloud Agent Canvases and Environment Improvements

<h2>Canvases from cloud agents</h2>
<p><a href="https://cursor.com/docs/cloud-agent">Cloud agents</a> can now build interactive <a href="https://cursor.com/docs/agent/tools/canvas">canvases</a> as part of their work. Share a finished canvas with your team by sending its link.</p>

<p>Learn more about <a href="https://cursor.com/docs/agent/tools/canvas#sharing-canvases">sharing canvases</a>.</p>
<h2>Environments API</h2>
<p>The <a href="https://cursor.com/docs/cloud-agent/api/endpoints#environments">Environments API</a> is now available in beta. Use it to programmatically create and manage the cloud environments your agents run in.</p>
<h2>Larger, faster environments</h2>
<p><a href="https://cursor.com/docs/cloud-agent/setup">Cloud agent environments</a> now support up to 300 repositories. Large environments also load 5x faster.</p>
