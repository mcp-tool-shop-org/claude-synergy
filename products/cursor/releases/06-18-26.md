# cursor — Improvements to Cursor Automations

<p>Cursor Automations save you time by automating repetitive tasks with always-on agents. This release introduces the **/automate** skill, new triggers for GitHub and Slack, and support for computer use.</p>
<h2>/automate skill</h2>
<p>Use **/automate** to create an automation directly in your local agent session.</p>
<p>Describe the task you want to automate in plain language and Cursor will configure the triggers, instructions, and tools for you.</p>
<h2>An emoji trigger for Slack</h2>
<p>React to any Slack message with a designated emoji to kick off an automation. At Cursor, we use this to trigger specific automations right from Slack.</p>
<h2>New GitHub triggers</h2>
<p>Automations now support five additional GitHub triggers:</p>
<ul>
<li>**Issue comment:** when a comment is made on a non-PR issue</li>
<li>**PR review comment:** when an inline comment is left on a pull request diff</li>
<li>**PR review submitted:** when a PR review is submitted</li>
<li>**Review thread updated:** when a review thread on a pull request is marked resolved or unresolved</li>
<li>**Workflow run completed:** when a GitHub Actions workflow run finishes on a pull request or branch</li>
</ul>
<p>We&#39;ve added new templates for <a href="https://cursor.com/marketplace/automations/triage-github-workflow-failures">triaging failed GitHub actions</a> and <a href="https://cursor.com/marketplace/automations/autofix-pr-review-comments">auto-fixing PR review comments</a> to the <a href="https://cursor.com/marketplace">Cursor Marketplace</a> to help you get started.</p>
<h2>Computer use tool for automations</h2>
<p>Cloud agents kicked off by automations can now use their own computers to produce demos or artifacts of their work.</p>
<p>The computer use tool is enabled by default for every automation, just tell the agent to include a demo of its work in your instructions.</p>
<p>To get started, update to the latest version of Cursor. Learn more in our <a href="https://cursor.com/docs/cloud-agent/automations">docs</a>.</p>
<p>Improvements (3)</p>
<ul>
<li>Automations can now be saved in an incomplete state, so you can navigate away to set up an MCP auth without losing your progress</li>
<li>Automations can now open PRs by default; so you no longer have to specify that tool in the UI</li>
<li>You can now delete memory files in the UI, or prompt your automation to delete outdated memories when it runs</li>
</ul>
