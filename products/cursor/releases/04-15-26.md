# cursor — Canvases

<p>Cursor can now respond by creating interactive <a href="https://cursor.com/docs/agent/tools/canvas">canvases</a>.</p>
<p>These visualizations can include dashboards and custom interfaces built using first-party components like tables, boxes, diagrams, and charts, as well as existing Cursor components like diffs and to-do lists.</p>
<p>In the <a href="https://cursor.com/docs/agent/agents-window">Agents Window</a>, canvases are durable artifacts that live in the side panel alongside the terminal, browser, and source control.</p>
<p>Try it out in <a href="https://cursor.com/download">Cursor 3.1</a> in the Agents Window or the editor. Read more in our <a href="https://cursor.com/blog/canvas">announcement</a>.</p>
