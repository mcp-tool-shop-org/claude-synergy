# cursor — Cursor, now on iPad

<p>Cursor for iPad is now available on all paid plans.</p>
<p>New to both iPhone and iPad: an inbox to stay organized, and a review experience that covers the full PR. Create, review, and merge from anywhere.</p>
<h2>Built for the bigger screen</h2>
<p>The iPad layout is rebuilt around the extra space. Sidebar chats stay pinned so you can watch several agents run at once. Split screen keeps a review open next to a chat, and file diffs render in full.</p>
<p>Markup gets more room to work too. Attach a screenshot, then tap to drop a comment at a specific point, or draw directly on the image with Apple Pencil.</p>
<h2>A full review surface</h2>
<p>On iPhone and iPad, the review screen now covers the full PR: comments, checks, and approvals. Add or change reviewers, read comments, and prompt the agent to resolve them. The whole path from agent output to merged PR now travels with you.</p>
<h2>Inbox</h2>
<p>An Inbox helps you and your agents stay organized. See what&#39;s in progress, what needs your attention, and which PRs are in review.</p>

<h2>Additional improvements for Cursor on iPhone and iPad</h2>
<ul>
<li>Bitbucket and Azure DevOps SCM support</li>
<li>Multi-PR sessions: when one chat creates multiple PRs, you can now open every one of them, not just the last.</li>
<li>Switch between teams that you belong to directly in the app</li>
</ul>
