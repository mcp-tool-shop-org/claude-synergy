# cursor — MCPs and Organizations in Team Marketplaces

<p>We&#39;ve expanded <a href="https://cursor.com/docs/plugins#team-marketplaces">team marketplaces</a> to support Team MCPs and organization groups.</p>
<h2>Team MCPs in team marketplaces</h2>
<p>Admins can now configure Team MCP servers once and distribute them across cloud agents, the agents window, IDE, and CLI.</p>
<p>When an admin sets up Team MCP servers for cloud agents, they can make those same servers available in a team marketplace from **Dashboard -&gt; Plugins &amp; MCPs**. This allows members of the team to install approved integrations locally without configuring servers themselves.</p>
<p>Learn more in the docs on <a href="https://cursor.com/docs/plugins#migrate-existing-team-mcps">migrating existing Team MCPs</a>.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/team-mcps.png&quot; loading=&quot;lazy&quot; alt=&quot;Team MCP servers&quot; /&gt;&lt;figcaption&gt;Team MCP servers&lt;/figcaption&gt;&lt;/figure&gt;</p>
<h2>Marketplace access by organization group</h2>
<p>Team marketplaces now support <a href="https://cursor.com/docs/enterprise/organization-groups">organization groups</a>, in addition to team-level SCIM directory groups.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/marketplace-orgs.png&quot; loading=&quot;lazy&quot; alt=&quot;Marketplace organization groups&quot; /&gt;&lt;figcaption&gt;Marketplace organization groups&lt;/figcaption&gt;&lt;/figure&gt;</p>
<p>Under **Dashboard -&gt; Plugins &amp; MCPs -&gt; Team Marketplaces**, restrict marketplace access to specific organization groups. Marketplaces that already use SCIM directory groups keep that configuration.</p>
<p>Get started in the <a href="https://cursor.com/dashboard/plugins#team-marketplaces">Cursor dashboard</a>.</p>
