# cursor — Plugins, Sandbox Access Controls, and Async Subagents

<p>This release introduces plugins for extending Cursor, improvements to core agent capabilities like subagents, and fine-grained network controls for sandboxed commands.</p>
<h3>Plugins on the Cursor Marketplace</h3>
<p>Plugins package skills, subagents, MCP servers, hooks, and rules, into a single install. The <a href="https://cursor.com/marketplace">Cursor Marketplace</a> lets you discover and install plugins to extend Cursor with pre-built capabilities.</p>
<p>Our initial partners include Amplitude, AWS, Figma, Linear, Stripe, and more. These plugins cover workflows across design, databases, payments, analytics, and deployment.</p>
<p>Browse plugins at <a href="https://cursor.com/marketplace">cursor.com/marketplace</a> or install directly in the editor with `/add-plugin`.</p>
<p>Read more in our <a href="https://cursor.com/blog/marketplace">announcement</a>.</p>
<h3>Sandbox network access controls</h3>
<p>The <a href="https://cursor.com/docs/agent/terminal#sandbox-configuration">sandbox</a> now supports granular network access controls, as well as controls for access to directories and files on your local filesystem. Define exactly which domains the agent is allowed to reach while running sandboxed commands:</p>
<ul>
<li>User config only: restricted to domains in your `sandbox.json`</li>
<li>User config with defaults: restricted to your allowlist plus Cursor&#39;s built-in defaults</li>
<li>Allow all: unrestricted network access within the sandbox</li>
</ul>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/sandbox-network-02-11-26-1-.png&quot; loading=&quot;lazy&quot; /&gt;&lt;/figure&gt;</p>
<p>Admins on the Enterprise plan can enforce network allowlists and denylists from the <a href="https://cursor.com/dashboard">admin dashboard</a>, ensuring organization-wide egress policies apply to all agent sandbox sessions.</p>
<h3>Async subagents</h3>
<p>Previously, all <a href="https://cursor.com/docs/context/subagents">subagents</a> ran synchronously, blocking the parent agent until they complete. Subagents can now run asynchronously, allowing the parent to continue working while subagents run in the background.</p>
<p>Subagents can also spawn their own subagents, creating a tree of coordinated work. This allows Cursor to take on bigger tasks like multi-file features, large refactors, and challenging bugs.</p>
<p>We&#39;ve also made some performance improvements to subagents since our last release. They now run with lower latency, better streaming feedback, and more responsive parallel execution.</p>
<p>Improvements (16)</p>
<ul>
<li>Agents can now search past conversations and use chat history as context.</li>
<li>The <a href="https://cursor.com/docs/cli/overview">Cursor CLI</a> agent can handle the `sudo` password prompt inline for commands that require elevated privileges.</li>
<li>Common operations like `git clone`, `npm install`, and `pip install` now work out of the box in the agent sandbox. You can extend or override these defaults per-project.</li>
<li>When the agent is in Plan mode, you can now choose &quot;Build in Cloud&quot; to hand off plan execution to a Cloud Agent while you continue working locally or close your laptop.</li>
<li>Toggle inline diffs on or off in your settings. By default, diffs are shown only in the review panel.</li>
<li>Renamed &quot;Duplicate Chat&quot; to &quot;Fork Chat&quot; in the three-dot menu of a chat message.</li>
<li>Improved permission request flow for subagents.</li>
<li>Improved the performance of very long chats.</li>
<li>Improved the performance of @ mentions.</li>
<li>Added keyboard shortcut ⌘+Enter (Ctrl+Enter) to submit messages in agent conversations.</li>
<li>Removed the Dotfile Protection setting to remove unexpected approval prompts when the agent tried to edit dotfiles.</li>
<li>Removed Default Mode setting so each new agent conversation begins fresh.</li>
<li>Removed Auto-Accept on Commit setting so pending diffs are automatically accepted when you commit.</li>
<li>Cleaned up the More Actions chat menu.</li>
<li>Added a Close button to the agent chat pane.</li>
<li>Manual edits no longer create in-line diffs.</li>
</ul>
<p>Bug Fixes (7)</p>
<ul>
<li>Fixed bug where some terminal tool calls caused degraded performance.</li>
<li>Fixed keybinding behavior for Cmd+Opt Left/Right for tab navigation.</li>
<li>Fixed an auto-run mode switching bug.</li>
<li>Fixed errors when creating project rules with no workspace open.</li>
<li>The <a href="https://cursor.com/docs/context/ignore-files#global-ignore-files">global ignore list</a> is now empty by default to fix sandboxing issues. Existing ignore patterns still work the same.</li>
<li>Stopping the parent agent will always stop the child subagents.</li>
<li>Enforce read-only sandbox for Ask mode even with &quot;Run everything&quot; enabled.</li>
</ul>
