# cursor — Cursor Start

<p>We&#39;re introducing <a href="https://cursor.com/blog/cursor-start-india">Cursor Start</a>, a new ₹649 monthly plan for developers in India, making daily agentic development accessible and payment easy with local pricing and UPI.</p>
<p>Existing Free users in India can upgrade their plan from the <a href="https://cursor.com/dashboard?modal=plan-selection">dashboard</a>. New users in India can visit <a href="https://cursor.com/signup">cursor.com/signup</a> and select the Start plan during onboarding.</p>
<p>Start bills monthly with auto-renewal and is available from July 28, 2026.</p>
<p>Cursor Start includes:</p>
<ul>
<li>**Generous access to Cursor models:** Grok and Composer, with enough usage to build with agents every day.</li>
<li>**Always-on cloud agents** that build, test, and ship code while you keep working.</li>
<li>**Cursor for iOS** with remote control, so you can launch and steer agents from your phone.</li>
<li>**Plugins, MCP servers, hooks, and skills** to extend Cursor across your workflows.</li>
<li>**Local pricing** at ₹649 per month, tax inclusive, billed in INR with UPI or card.</li>
</ul>
<p>Learn more in our <a href="https://cursor.com/blog/cursor-start-india">announcement</a> and <a href="https://cursor.com/docs/models-and-pricing">docs</a>.</p>
