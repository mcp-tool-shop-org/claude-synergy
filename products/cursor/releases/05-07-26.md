# cursor — PR Review, Build Plan in Parallel, and Split PRs

<p>This release introduces a new PR review experience, faster execution on plans through parallel agents, and new quick-action pills for common workflows.</p>
<h2>PR review</h2>
<p>A new PR review experience is now available in Cursor 3. Take PRs from creation to merge all in one place.</p>
<ul>
<li>The Reviews tab now shows inline review threads and top-level PR comments.</li>
<li>The Commits tab gives you a focused view of commit history for the PR.</li>
<li>The Changes tab makes it easier to navigate larger PRs with a file tree and changes picker.</li>
</ul>
<p>You can see useful context like reviewer status and pending review banners, and quick action pills allow you to take next steps faster.</p>
<h2>Build in parallel from plans</h2>
<p>Cursor can now execute on plans faster by multitasking across tasks instead of tackling them one at a time.</p>
<p>Click &quot;Build in Parallel&quot; to have it identify independent parts of your plan and run them simultaneously using async subagents. Cursor will keep dependent steps in order when needed.</p>
<h2>Split changes into PRs</h2>
<p>When multitasking in Cursor, you can now use a built-in quick action to split changes into PRs.</p>
<p>It will use chat context to identify logical slices, default to independent PRs unless dependencies are required, create a backup snapshot, and propose a split plan for your approval.</p>
<h2>Pin skills as quick actions</h2>
<p>You can now pin your most commonly used skills as quick-action pills for faster access.</p>
<p>Improvements (6)</p>
<ul>
<li>Added the ability to control Explore subagent behavior from settings: choose a specific model for Explore subagents to run on, inherit the same model as the parent agent, or disable Explore subagents altogether.</li>
<li>Added support for general model names for subagent configuration (i.e., set `model: opus` to have subagents always use the newest Opus model).</li>
<li>`/multitask` is now available in the editor for running async subagents to parallelize your requests instead of adding them to the queue.</li>
<li>Improved prompt input undo grouping, so undo/redo feels more natural during edits.</li>
<li>Improved long-chat handling and reduced jumpiness and other surprising behaviors.</li>
<li>Made MCP connection behavior more predictable, and added explicit stale token cleanup on re-auth.</li>
</ul>
<p>Bug Fixes (5)</p>
<ul>
<li>Fixed terminal interaction bugs in the agents window, including editing shortcut issues and approval/overlay edge cases.</li>
<li>Fixed several slash menu and input-approval regressions.</li>
<li>Fixed MCP auth edge cases, including transient 401 handling and stale credential behavior.</li>
<li>Fixed multi-repo environment selection and cache issues.</li>
<li>Fixed various cloud agent timing and hydration edge cases that could degrade reliability.</li>
</ul>
