# cursor — Cursor Security Review

<p><a href="https://cursor.com/docs/security-review">Cursor Security Review</a> is now in beta on Teams and Enterprise plans. You can run two types of always-on security agents: Security Reviewer and Vulnerability Scanner.</p>
<h2>Security Reviewer</h2>
<p>Security Reviewer checks every PR for security vulnerabilities, auth regressions, privacy and data-handling risks, agent tool auto-approvals, and prompt injection attacks. It will leave inline comments at the exact diff location with severity and remediation.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/security-reviewer.png&quot; loading=&quot;lazy&quot; alt=&quot;Security Reviewer leaving inline comments on a pull request diff.&quot; /&gt;&lt;figcaption&gt;Security Reviewer leaving inline comments on a pull request diff.&lt;/figcaption&gt;&lt;/figure&gt;</p>
<h2>Vulnerability Scanner</h2>
<p>Vulnerability Scanner runs scheduled scans of your codebase to check for known vulnerabilities, outdated dependencies, and configuration issues. You can configure it to send updates of its findings in Slack.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/vuln-scanner.png&quot; loading=&quot;lazy&quot; alt=&quot;Vulnerability Scanner findings and scheduled scans in Cursor.&quot; /&gt;&lt;figcaption&gt;Vulnerability Scanner findings and scheduled scans in Cursor.&lt;/figcaption&gt;&lt;/figure&gt;</p>
<p>---</p>
<p>Customize Cursor-managed security agents by adjusting triggers, adding your own instructions, giving them custom tooling, and choosing how outputs are shared. For example, you can plug in MCP servers for your existing SAST, SCA, and secrets scanners for Cursor to use as part of the review.</p>
<p>We&#39;re also continuously improving the runtime, harness, and models powering Cursor Security Review for a strong out-of-the-box experience.</p>
<p>Security agents draw from your existing usage pool. Admins can enable Security Review in the <a href="https://cursor.com/dashboard/security-review">Cursor dashboard</a> to get started.</p>
