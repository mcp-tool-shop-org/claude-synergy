# cursor — Tiled Layout and Upgraded Voice Input in the Agents Window

<p>This release introduces improvements to our Agents Window interface as part of Cursor 3.</p>
<h2>Tiled layout</h2>
<p>Split your current view into panes to run and manage several agents in parallel. The tiled layout makes it easier to multi-task and compare outputs across agents without jumping between tabs.</p>
<p>Expand panes to focus on a conversation, drag agents into tiles, and use keybindings for quick navigation and organization. Your setup also persists across sessions.</p>
<h2>Upgraded voice input</h2>
<p>Dictation through voice input is more reliable and accurate. It records your full voice clip and transcribes it with batch STT for higher-quality speech-to-text.</p>
<p>You can press and hold `Ctrl+M` to speak, and we&#39;ve added controls to the UI while recording, such as a waveform, timer, and buttons for cancelling and confirming.</p>
<h2>Branch selection in empty state</h2>
<p>Previously, starting an agent from the empty state usually defaulted to your current branch. Now you can search and select a branch first, then launch a cloud agent directly against that branch.</p>
<p>This cuts down on additional steps to switch branches and reduces accidental runs on the wrong branch.</p>
<h2>Diff to file navigation</h2>
<p>Jump from the diff straight to the exact line in the file. Once there, you have the full power of the editor, make changes manually, use Tab, go to definition, and more.</p>
<h2>Filters for searching files</h2>
<p>Use include/exclude filters in &quot;Search in Files&quot; for scoping code search to specific file sets.</p>

<p>Agents Window Improvements</p>
<ul>
<li>Prompt buttons now stay in place while voice input is processing.</li>
<li>Plan tabs now get the same document behaviors as files: support for reliable loading, dirty tracking, reload on plan changes, and the ability to save, copy, and export markdown.</li>
<li>New agent sessions now start in your preferred project target by default.</li>
<li>File tab names are now resolved within the current agent&#39;s visible tabs instead of trying to be globally unique across all other agents&#39; tabs.</li>
<li>`Cmd-K` now shows fewer, more relevant agent results, capped to the recent matching set (i.e., items that match your query and are from a recent subset).</li>
<li>On macOS, text is now rendered with anti-aliasing, producing sharper character edges.</li>
<li>Design Mode now lets you navigate the element tree (up, down, and sideways) with keyboard support to pick the UI element before commenting.</li>
<li>The Agents Window now avoids expensive updates and fetches unless they&#39;re truly needed.</li>
<li>Closing tabs is now less likely to glitch the file tree, and recovery is faster.</li>
<li>Limited local diff fetches to reduce CPU/network spikes and lag in SCM views.</li>
<li>File tree now responds to changes more reliably and is less likely to flicker, stale, or miss updates.</li>
<li>Extension events (e.g., file change, diagnostics update) are now scoped to each workspace, reducing cross-project interference.</li>
<li>Hitting enter to send a follow-up in a long chat used to hang for over a second and now feels instant.</li>
<li>Large edits stream more smoothly now after cutting dropped frames by ~87%.</li>
</ul>
<p>Agents Window Bug Fixes</p>
<ul>
<li>Fixed a bug where scrolling through long conversations used to stutter. Now it&#39;s smooth, even in large threads.</li>
<li>Fixed a bug where an agent conversation full of diffs or code blocks would flash and freeze.</li>
</ul>
