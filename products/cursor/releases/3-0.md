# cursor — New Cursor Interface

<p>Cursor 3 is now available.</p>
<h2>Agents Window</h2>
<p>The new Cursor interface allows you to run many agents in parallel across repos and environments: locally, in worktrees, in the cloud, and on remote SSH.</p>
<p>It&#39;s simpler, more powerful, and centered around agents, while keeping the depth of a development environment.</p>
<p>To try the <a href="https://cursor.com/docs/agent/agents-window">Agents Window</a>, upgrade Cursor and type `Cmd+Shift+P -&gt; Agents Window`.</p>
<p>You can switch back to the IDE anytime, or have both open simultaneously.</p>
<p>Read more in our <a href="https://cursor.com/blog/cursor-3">announcement</a>.</p>
<h2>Design Mode</h2>
<p>In the Agents Window, you can use Design Mode to annotate and target UI elements directly in the browser.</p>
<p>This allows you to give more precise feedback and iterate faster by pointing the agent to exactly the part of the interface you&#39;re referring to.</p>
<p>Keyboard shortcuts include:</p>
<ul>
<li>⌘ + Shift + D to toggle to Design Mode</li>
<li>Shift + drag to select an area</li>
<li>⌘ + L to add element to chat</li>
<li>⌥ + click to add element to input</li>
</ul>
<h2>Agent Tabs in the Editor</h2>
<p>Agent Tabs allow you to view multiple chats at once, side-by-side or in a grid.</p>

<p>Editor (4)</p>
<ul>
<li>Added a new command `/worktree` that creates a separate git worktree so changes happen in isolation.</li>
<li>Added a new command `/best-of-n` that runs the same task in parallel across multiple models, each in its own isolated worktree, then compares outcomes.</li>
<li>Deprecated the previous worktree and best-of-n selection from the Editor.</li>
<li>Removed cloud agents from the Editor.</li>
</ul>
<p>Plugins &amp; MCP (2)</p>
<ul>
<li>MCP Apps now support structured content, enabling richer tool outputs.</li>
<li>Third-party plugin imports now default to **off** for Enterprises when unset, while preserving explicit Admin overrides.</li>
</ul>
<p>Enterprise &amp; Teams (3)</p>
<ul>
<li>Added the directory group name so audit logs are human-readable without looking up IDs.</li>
<li>Added a team-level Admin setting for cloud agents that restricts creating, editing, and deleting team secrets to Admins.</li>
<li>Added an Enterprise Admin control for disabling &quot;Made with Cursor&quot; code attribution for the entire team. Per-user settings still exist via Cursor Settings &gt; Agent &gt; Attribution.</li>
</ul>
<p>Other Improvements (10)</p>
<ul>
<li>Large-file diff rendering is now much faster, smoother, and less memory-heavy.</li>
<li>Agents are now better at monitoring long-running jobs.</li>
<li>Added an `Await` tool that lets agents wait for background shell commands and subagents to complete, or wait for specific output such as &quot;Ready&quot; or &quot;Error&quot;.</li>
<li>Reduced the browser automation tool surface and tightened the subagent to use browser tools only, helping it stay more focused on the task. Also improved the browser instructions to reduce error loops, and added screenshot-based coordinate clicking as a fallback when DOM interactions are unreliable.</li>
<li>Plans are now included in shared chats alongside the transcript.</li>
<li>Added caching to improve Explorer subagents startup time.</li>
<li>Past chat transcripts are now surfaced directly in at-mention search results.</li>
<li>Added a &quot;scroll to bottom&quot; button in the agent panel that appears when content overflows.</li>
<li>Tab bar can now span the full available width in maximized chat layouts.</li>
<li>Consolidated the Early Access release track behind Nightly.</li>
</ul>
<p>Bug Fixes (8)</p>
<ul>
<li>Fixed text area behavior for Network Access Controls so pressing `Enter` can reliably add a newline at the end of the input.</li>
<li>Fixed hooks loading so multi-root workspaces read project hook files from all workspace folders instead of only the first one.</li>
<li>Fixed a markdown parsing bug where parenthesized HTTP(S) links could be misread as citations.</li>
<li>Fixed todo card visibility to prevent them from disappearing after all todos complete.</li>
<li>Fixed Agent queued prompts that were not resuming automatically after editing operations.</li>
<li>Fixed picker behavior for models that are disabled but selectable by removing misleading &quot;not allowed&quot; styling and auto-enabling a model when the user selects it.</li>
<li>Fixed a bug where expanding/collapsing thinking blocks didn&#39;t work while streaming was still in progress.</li>
<li>Fixed a bug where Shift+Enter line breaks weren&#39;t treated as multiline content, so the prompt input field could stay in an incorrect state.</li>
</ul>
