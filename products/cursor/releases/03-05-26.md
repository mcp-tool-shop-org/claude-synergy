# cursor — Automations

<p>Cursor now supports <a href="https://cursor.com/docs/cloud-agent/automations">automations</a> for building always-on agents that run based on triggers and instructions you define.</p>
<p>Automations run on schedules or are triggered by events from Slack, Linear, GitHub, PagerDuty, and webhooks.</p>
<p>When invoked, the agent spins up a cloud sandbox and follows your instructions using the MCPs and models you&#39;ve configured. Agents also have access to a memory tool that lets them learn from past runs and improve with repetition.</p>
<p>Create automations at <a href="https://cursor.com/automations">cursor.com/automations</a>, or start from a <a href="https://cursor.com/marketplace#automations">template</a>. Read more in our <a href="https://cursor.com/blog/automations">announcement</a>.</p>
