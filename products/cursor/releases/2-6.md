# cursor — MCP Apps and Team Marketplaces for Plugins

<p>This release introduces interactive UIs in agent chats, a way for teams to share private plugins, and improvements to core capabilities like Debug mode.</p>
<h3>MCP Apps</h3>
<p><a href="https://cursor.com/docs/context/mcp#mcp-apps">MCP Apps</a> support interactive user interfaces like charts from <a href="https://cursor.com/marketplace/amplitude">Amplitude</a>, diagrams from <a href="https://cursor.com/marketplace/figma">Figma</a>, and whiteboards from <a href="https://cursor.com/marketplace/tldraw">tldraw</a> directly inside Cursor.</p>

<h3>Team marketplaces for plugins</h3>
<p>On Teams and Enterprise plans, Admins can now create <a href="https://cursor.com/docs/plugins#team-marketplaces">team marketplaces</a> to share private plugins internally. Go to the settings page to manage and distribute plugins with central governance and access controls.</p>
<p>&lt;br /&gt;</p>
<p>Desktop Improvements (15)</p>
<ul>
<li>Added support for multiple parallel Debug mode sessions.</li>
<li>Debug mode now cleans up stale code after every turn.</li>
<li>Debug mode now adapts the number of instrumentation logs based on the complexity.</li>
<li>Added a right-click context menu and zoom support to the browser tool.</li>
<li>The content from your plan files are now included in autocomplete suggestions as you type in the agent chat input.</li>
<li>When you attach multiple images to a chat message, they now display as a gallery instead of a flat list.</li>
<li>Added multiline support for Plan mode questions.</li>
<li>Modals load faster.</li>
<li>Agent workflows are faster and more predictable for multi-file edits and PR-heavy tasks.</li>
<li>Improved PR and review context with more accurate file/line anchoring and clearer diff/hunk rendering.</li>
<li>Smoother tool-use flows across terminal, web, and integration actions, with better handling for long multi-step runs.</li>
<li>More reliable MCP setup and configuration, with cleaner tool-call UX during agent runs.</li>
<li>Clearer, more consistent team and enterprise policy and access controls.</li>
<li>Improved Slack integration with better linking and status behavior to make team workflows easier to follow.</li>
<li>Improved reliability for longer-running agent sessions.</li>
</ul>
<p>Desktop Bug Fixes (10)</p>
<ul>
<li>Fixed web links in the plan editor.</li>
<li>Fixed refresh behavior so branch and PR status appear more reliably.</li>
<li>Fixed false blockers when branches diverge during review and merge flows.</li>
<li>Fixed review comments where file and line references could be incomplete or inconsistent.</li>
<li>Fixed diff display so add/delete and hunk line information is preserved more accurately.</li>
<li>Fixed MCP configuration dialogs that could get stuck or behave inconsistently.</li>
<li>Fixed model picker showing duplicate or mismatched entries for some users.</li>
<li>Fixed team permission and access control inconsistencies across organization setups.</li>
<li>Fixed reliability issues in long-running workflows (timeouts, retries, abort handling) for better completion rates.</li>
<li>Fixed port allocation conflicts across multiple Debug mode sessions.</li>
</ul>
<p>Web Improvements &amp; Fixes (2)</p>
<ul>
<li>Improved dashboard and account management with clearer visibility into overview, analytics, and collections.</li>
<li>Fixed layout issues in account management and analytics views on the dashboard.</li>
</ul>
