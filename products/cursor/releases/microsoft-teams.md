# cursor — Cursor in Microsoft Teams

<p>Cursor is now available in Microsoft Teams.</p>
<p>Mention @Cursor in any Teams channel to delegate a task to a <a href="https://cursor.com/docs/cloud-agent">cloud agent</a> or pull information from Cursor into Teams.</p>
<p>Cursor automatically picks the right repository and model based on your prompt and recent agent activity. It reads the entire thread for context before implementing a solution and creating a PR for your team to review.</p>
<p>Get started by installing the integration in the <a href="https://cursor.com/dashboard/integrations#integrations">Cursor dashboard</a>. Learn more in our <a href="https://cursor.com/docs/integrations/microsoft-teams">docs</a>.</p>
