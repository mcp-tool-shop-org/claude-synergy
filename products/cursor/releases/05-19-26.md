# cursor — Cursor in Jira

<p>Cursor is now available in Jira.</p>
<p>Assign work items to Cursor, or mention `@Cursor` in a comment to kick off a <a href="https://cursor.com/docs/cloud-agent">cloud agent</a>. Cursor uses the work item title, description, comments, and your team&#39;s repository settings to scope the task.</p>
<p>You can ask Cursor to fix bugs, add features, update tests, or investigate something described in the ticket. When the agent finishes, Jira shows completion updates and includes a link to the pull request.</p>
<p>Install the integration from <a href="https://cursor.com/dashboard/integrations#integrations">Cursor integrations</a>. You need Cursor admin access and Jira Commercial Cloud with Rovo enabled. Learn more in our <a href="https://cursor.com/docs/integrations/jira">docs</a>.</p>
