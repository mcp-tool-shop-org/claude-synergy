# cursor — Improvements to Cursor Automations

<p>This release brings <a href="https://cursor.com/docs/cloud-agent/automations">Cursor Automations</a> to the Agents Window and introduces the ability to configure automations with multiple attached repos or no repos at all.</p>
<p>For the next 7 days, all agent runs for newly created automations are 50% off.</p>
<h2>Automations in the Agents Window</h2>
<p>Cursor Automations are now available in the <a href="https://cursor.com/blog/cursor-3">Agents Window</a>, in addition to cursor.com/automations. Create and manage your automations in the same workspace as your agents.</p>
<h2>Multi-repo automations</h2>
<p>A lot of engineering work spans more than one codebase. You can now attach multiple repos to an automation so agents reason across all required context and work across repos to deliver, test, and verify tasks.</p>
<h2>No-repo automations</h2>
<p>Many useful automations exist apart from code, where agents monitor your tools and act on key signals. You can now create automations without an attached repository.</p>
<p>We&#39;ve added five new templates for no-repo automations to the <a href="https://cursor.com/marketplace">Cursor Marketplace</a> to help you get started:</p>
<ul>
<li><a href="https://cursor.com/marketplace/automations/slack-digest-agent">**Slack digest agent**</a>: Summarizes unread DMs and key Slack channels every morning and prioritizes them by importance</li>
<li><a href="https://cursor.com/marketplace/automations/product-analytics-agent">**Product analytics agent**</a>: Delivers a weekly digest of key metrics from your data warehouse like Databricks</li>
<li><a href="https://cursor.com/marketplace/automations/product-faq-agent">**Product FAQ agent**</a>: Watches a Slack channel for questions and writes a first response based on docs, codebase context, and past threads</li>
<li><a href="https://cursor.com/marketplace/automations/product-finance-agent">**Product finance agent**</a>: Pulls financial data from a billing provider like Stripe for recurring revenue reports</li>
<li><a href="https://cursor.com/marketplace/automations/customer-health-monitoring-agent">**Customer health agent**</a>: Monitors key systems like Granola, Slack, and Databricks and flags accounts where health signals are shifting</li>
</ul>
<p>Read our <a href="https://cursor.com/docs/cloud-agent/automations">docs</a> to learn more.</p>
