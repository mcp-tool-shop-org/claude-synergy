# cursor — CLI Agent Modes and Cloud Handoff

<p>This release brings many of the editor’s most-loved features to the <a href="https://cursor.com/docs/cli/overview">Cursor CLI</a>, along with improvements that make it easier to use.</p>
<h3>Plan mode in CLI</h3>
<p>Use <a href="https://cursor.com/docs/agent/modes">Plan mode</a> to design your approach before coding. Cursor will ask clarifying questions to refine your plan. Get started with **`/plan`** or **`--mode=plan`**.</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/uploads/plan-mode.mp4&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<h3>Ask mode in CLI</h3>
<p>Use <a href="https://cursor.com/docs/agent/modes">Ask mode</a> to explore code without making changes, just like in the editor. Start asking questions with **`/ask`** or **`--mode=ask`**.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/01-16-26-ask-mode.png&quot; loading=&quot;lazy&quot; /&gt;&lt;/figure&gt;</p>
<h3>Handoff to Cloud Agents</h3>
<p>Push your local conversation to a <a href="https://cursor.com/docs/cloud-agent">Cloud Agent</a> and let it keep running while you&#39;re away. Prepend **`&amp;`** to any message to send it to the cloud, then pick it back up on web or mobile at <a href="https://cursor.com/agents">cursor.com/agents</a>.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/uploads/cli-push-to-cloud.png&quot; loading=&quot;lazy&quot; /&gt;&lt;/figure&gt;</p>
<h3>Word-level Inline Diffs</h3>
<p>Show exactly what changed with precise word-level highlighting in the CLI.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/01-16-26-diffs.png&quot; loading=&quot;lazy&quot; /&gt;&lt;/figure&gt;</p>
<h3>One-click MCP authentication</h3>
<p>Connect Cursor to external tools and data sources with a new login flow supporting automatic callback handling. The agent gets access to authenticated <a href="https://cursor.com/docs/context/mcp">MCPs</a> immediately.</p>
<p>Use **`/mcp list`** for an updated interactive MCP menu to browse, enable, and configure MCP servers at a glance.</p>
<p>Improvements (8)</p>
<ul>
<li>Added <a href="https://cursor.com/docs/agent/hooks">hooks</a> for session start/end, prompt, and stop for customizing agent lifecycle events.</li>
<li>See Cursor streaks and stats with **`/usage`**.</li>
<li>Added WebFetch, WebSearch tools, &amp; approval options for granular controls over web search and fetch requests from MCP tools.</li>
<li>Added **`/about`** for seeing basic details about your environment and Cursor CLI setup.</li>
<li>Faster message queueing and UX.</li>
<li>**`Shift+Enter`** for newlines now works in iTerm2, Ghostty, Kitty, Warp, and Zed. Run **`/setup-terminal`** to auto-configure **`/Option+Enter`** Apple Terminal, Alacritty, or VS Code. **`Ctrl+J`** and **`\+Enter`** work universally as alternatives.</li>
<li>Smarter terminal environment detection for optimal keybindings and display.</li>
<li>Better markdown rendering with proper links, tables, and rules.</li>
<li>Menu resize handling, long line truncation, and stable state on window changes.</li>
</ul>
<p>Changes (2)</p>
<ul>
<li>**`/list`** removed. Use **`/resume`** to see all prior conversations.</li>
<li>**`/models`** removed. Use **`/model`** to see all models or select a model.</li>
</ul>
<p>Bug Fixes (2)</p>
<ul>
<li>Fixed process hangs and silent failures. Agent runs should be more stable with fewer errors.</li>
</ul>
