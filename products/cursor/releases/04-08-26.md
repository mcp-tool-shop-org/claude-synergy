# cursor — Bugbot Learned Rules and MCP Support

<p>This release introduces updates to Bugbot including the ability to self-improve in real time, MCP support, improvements to Bugbot Autofix, and the highest resolution rate to date.</p>
<h2>Bugbot Learned Rules</h2>
<p>Bugbot can now learn from feedback on pull requests and turn those signals into <a href="https://cursor.com/docs/bugbot#learned-rules">learned rules</a> that improve future reviews.</p>
<p>It looks at reactions and replies to Bugbot comments and comments from human reviewers to create candidate rules. Bugbot automatically promotes the ones that accumulate signal and disables the ones that stop being useful.</p>

<p>Read more about learned rules in our <a href="https://cursor.com/blog/bugbot-learning">announcement</a> or manage learning in the <a href="https://cursor.com/dashboard/bugbot/repository-rules">Bugbot dashboard</a>.</p>
<h2>Bugbot MCP Support</h2>
<p>Give Bugbot access to <a href="https://cursor.com/docs/bugbot#mcp-support">MCP servers</a> for additional context during code reviews. On Teams and Enterprise plans, you can add tools to Bugbot in the <a href="https://cursor.com/dashboard/bugbot">Bugbot dashboard</a>.</p>

<p>Bugbot Improvements (6)</p>
<ul>
<li>Bugbot&#39;s resolution rate is now 78%.</li>
<li>Added a &quot;Fix All&quot; action to apply multiple Bugbot fixes in one operation.</li>
<li>Redesigned Bugbot settings, and split personal and team settings into clearer sections.</li>
<li>Bugbot Autofix only runs when findings are substantial enough to warrant a fix.</li>
<li>Bugbot Autofix now uses only relevant rules, reducing noise in prompting.</li>
<li>Improved reliability of Bugbot Autofix CI checks on PRs.</li>
<li>Simplified Bugbot check progress messages in GitHub PRs.</li>
</ul>
<p>Bugbot Bug Fixes (2)</p>
<ul>
<li>Fixed a bug where stale privacy mode state from inactive teams could incorrectly block Bugbot Autofix.</li>
<li>Fixed infra issues that caused longer than expected Bugbot run times.</li>
</ul>
