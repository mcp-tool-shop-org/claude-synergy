# cursor — Multitask, Worktrees, and Multi-root Workspaces

<p>This release introduces a new way to multitask with async subagents, an improved worktrees experience, and multi-root workspaces for making cross-repo changes.</p>
<h2>Multitask in Agents Window</h2>
<p>With `/multitask`, Cursor will run async subagents to parallelize your requests instead of adding them to the queue. It will also break down larger tasks into smaller chunks for a fleet of async subagents to tackle simultaneously.</p>
<p>If you already have messages in the queue, you can ask Cursor to multitask on them instead of waiting for the current run to finish.</p>
<h2>Worktrees in Agents Window</h2>
<p>We&#39;ve added new and improved <a href="https://cursor.com/docs/configuration/worktrees">worktrees</a> in the <a href="https://cursor.com/docs/agent/agents-window">Agents Window</a>.</p>
<p>Run isolated tasks in the background across different branches. When you&#39;re ready to test changes, move any branch into your local foreground with one click.</p>
<h2>Multi-root workspaces in Agents Window</h2>
<p>A single agent session can now target a reusable workspace made of multiple folders.</p>
<p>This allows Cursor to make cross-repo changes spanning frontend, backend, and shared libraries, without retargeting the agent every time it moves between repos.</p>
