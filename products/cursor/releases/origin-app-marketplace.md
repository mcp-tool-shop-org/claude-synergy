# cursor — Origin App Marketplace

<p>Origin now integrates with over 20 apps for deployments, CI, code review, security, monitoring, and project management, from partners including Cloudflare, Linear, Sentry, and Socket Security.</p>
<p>Starting today, the marketplace is also open to public submissions, so any team building developer tools can publish an app for Origin.</p>

<p>The marketplace now includes apps for:</p>
<ul>
<li>**Deployments:** <a href="https://cursor.com/codebase/apps/public/cloudflare">Cloudflare</a>, <a href="https://cursor.com/codebase/apps/public/netlify">Netlify</a>, <a href="https://cursor.com/codebase/apps/public/render">Render</a>, <a href="https://cursor.com/codebase/apps/public/spacelift-deploy-us">Spacelift</a>, and <a href="https://cursor.com/codebase/apps/public/vercel">Vercel</a></li>

<h2>Publish to Marketplace</h2>
<p>To submit an app:</p>
<ol>
<li><a href="https://cursor.com/codebase/settings/apps">Create an app</a> in your namespace. It stays private to your namespace while you build.</li>
<li>Build against the <a href="https://cursor.com/docs/api/origin">Origin API</a>. Apps authenticate with an app JWT and installation access tokens, receive webhook events, and write back check runs, pull request comments, and reviews.</li>
<li>Make the app public, then submit it from the app&#39;s page with a slug, suggested tags, and a demo video. The video should show install, uninstall, and your core product flows.</li>
<li>We review the submission and list the app once it&#39;s approved.</li>
</ol>
