# cursor — Start from scratch, without a repo

<p>Cloud Agents no longer require a connected GitHub or other third-party SCM provider to get started. Prompt from the get-go, then save your work to a Cursor Origin repo.</p>
<h2>Get started</h2>
<p>Select **Start from scratch** in the repo picker, then prompt the agent. In the background, Cursor creates an Origin repo for you.</p>
<p>&lt;figure&gt;&lt;img src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/changelog/start-from-scratch-QflXlxizUwAvBbal0Kst46I0mEZT93.png&quot; loading=&quot;lazy&quot; alt=&quot;Start from scratch in the repo picker&quot; /&gt;&lt;figcaption&gt;Start from scratch in the repo picker&lt;/figcaption&gt;&lt;/figure&gt;</p>
<h2>Turn it into a real repo, whenever you want</h2>
<p>Once the agent&#39;s build is to your liking, click the **Create repo** button to save your work in an Origin repo. Choose a custom name or pick one of the suggested ones, then set the visibility to private or internal. You&#39;ll get a fully scaffolded Origin repo, ready to share or keep building on. Navigate to the Codebase tab to find your repo and access your project.</p>
<h2>A live preview, right in the browser</h2>
<p>Cursor now port-forwards your cloud agent&#39;s live environment straight to your browser, so you can preview it and use tools like design mode.</p>
<h2>Publish your work</h2>
<p>Connect a Vercel account and hit publish to get a live URL for what you built.</p>
<p>A Vercel account is required to use the publish feature.</p>
<p><a href="https://cursor.com/agents">Get started today</a>.</p>
