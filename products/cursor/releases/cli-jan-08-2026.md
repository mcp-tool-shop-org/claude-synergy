# cursor — New CLI Features and Improved CLI Performance

<p>This release introduces new CLI controls for models, MCP management, rules and commands, alongside major hooks performance improvements and bug fixes.</p>
<h3>Model list and selection</h3>
<p>Use the new **`agent models`** command, **`--list-models`** flag, or **`/models`** slash command to list all available models and quickly switch between them.</p>

<h3>Rules generation and management</h3>
<p>Create new rules and edit existing ones directly from the CLI with the **`/rules`** command.</p>
<p>&lt;figure&gt;&lt;video src=&quot;https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/uploads/rules-clean-2.mov&quot; controls preload=&quot;metadata&quot; loop&gt;&lt;/video&gt;&lt;/figure&gt;</p>
<h3>Enabling MCP servers</h3>
<p>Enable and disable MCP servers on the fly with **`/mcp enable`** and **`/mcp disable`** commands.</p>

<p>New Features (7)</p>
<ul>
<li>Tabs are now automatically named based on chats.</li>
<li>New **`agent`** command is now the primary CLI entrypoint. **`cursor-agent`** remains as a backward-compatible alias.</li>
<li>Added **`agent models`** command, **`-list-models`** flag, and **`/models`** slash command to list all available models.</li>
<li>Added **`/mcp enable`**, **`/mcp disable`** commands to manage MCP servers.</li>
<li>Added **`/rules`** to create new rules and edit existing rules.</li>
<li>Added **`/commands`** to create new commands and edit existing commands.</li>
<li>Executed subcommands are now recorded in command history.</li>
<li>MCP server names with spaces are now supported in all **`/mcp`** commands.</li>
</ul>
<p>Hooks (3)</p>
<ul>
<li>Hooks now execute in parallel with merged responses, improving performance for projects with multiple hook scripts.</li>
<li>Hooks execution latency reduced by 10x.</li>
<li>**`afterFileEdit`** hook now correctly provides **`old_string`** with the file&#39;s previous content for proper diff capture.</li>
</ul>
<p>Improvements &amp; Bug Fixes (7)</p>
<ul>
<li>**`Ctrl+D`** now follows standard shell behavior, requiring a double-press to exit.</li>
<li>**`Shift+Enter`** now inserts a newline instead of submitting, making it easier to write multi-line prompts.</li>
<li>Fixed ghost line rendering bug where deleted lines would leave visual artifacts on screen.</li>
<li>Fixed race condition where conversation state could be overwritten during turn completion.</li>
<li>Fixed &quot;Cannot find module&quot; error related to node-pty on some platforms.</li>
<li>Fixed chat name generation.</li>
<li>Fixed several bugs with follow-up messages.</li>
</ul>
