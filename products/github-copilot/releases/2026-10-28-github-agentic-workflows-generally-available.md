<p><a href="https://github.github.com/gh-aw/?utm_source=agentic-workflows-changelog-aw-website&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">GitHub Agentic Workflows</a>, an open source project from GitHub Next, is now generally available. With agentic workflows, you can automate reasoning-based tasks like issue triage, CI failure analysis, documentation updates, and test writing by using coding agents inside GitHub Actions.</p>
<p>Define your automation in natural language Markdown files, and GitHub Agentic Workflows compiles them into standard Actions YAML. Because these are GitHub Actions, they reuse your existing runner groups and policy constraints. You can use GitHub Copilot or bring your own coding agent to power each workflow.</p>
<blockquote class="gh-changelog-quote"><p>We’ve been rolling out our agentic developer workflows, and the results are measurable. One of our leads saved an estimated 29 hours a week on his development work alone. Across his team, measured velocity has more than doubled on average, and AI now authors 91% of the team’s commits. With these workflows, the team cut production errors from about 11,000 a day to under 1,000 and drove a technology migration end to end.</p>
<p>One workflow takes a feature from requirements to implementation with validation evidence. Others keep our frameworks current and steadily raise code quality and test coverage. Because AI drives the process to completion, our engineers can run four or five efforts in parallel and stay focused on the bigger goals.<br>
    <cite>Ben Alton – Senior manager, Strategy, Architecture &amp; Innovation team at Accenture</cite></p></blockquote>
<h3 id="built-in-safeguards"><a class="heading-link" href="#built-in-safeguards">Built-in safeguards<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>GitHub Agentic Workflows incorporates layered safeguards for your automation. Agents access GitHub content respecting the <a href="https://github.github.io/gh-aw/reference/integrity/">integrity filter</a> rules, run with read-only permissions by default, and execute inside a sandboxed container behind the <a href="https://github.github.com/gh-aw/introduction/architecture/?utm_source=agentic-workflows-changelog-firewall&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#agent-workflow-firewall-awf">Agent Workflow Firewall</a>. The outputs are validated through the <a href="https://github.github.com/gh-aw/reference/safe-outputs/?utm_source=agentic-workflows-changelog-safe-outputs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">safe outputs</a> process, and a dedicated <a href="https://github.github.com/gh-aw/reference/threat-detection/?utm_source=agentic-workflows-changelog-threat-detection&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">threat detection</a> job scans all proposed changes before they are applied.</p>
<h3 id="additional-capabilities-for-general-availability"><a class="heading-link" href="#additional-capabilities-for-general-availability">Additional capabilities for general availability<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Highlights since the public preview include:</p>
<ul>
<li><strong>Actions Runner Controller (ARC) and Docker-in-Docker support:</strong> Run agentic workflows on self-hosted ARC runners with Docker-in-Docker.</li>
<li><strong>Improved budget forecasting:</strong> <code>gh aw forecast</code> is no longer experimental. It now includes both threat detection credits and monthly ranges for a fuller picture of your AI credit spend.</li>
<li><strong>New models, engine choices, and workflows:</strong> The model inventory has been refreshed, model providers can be picked per workflow, and there are new workflow templates that can be added with <code>gh aw add-wizard</code>.</li>
<li><strong>Model routing:</strong> Workflows can use a model router that optimizes for task type and difficulty.</li>
<li><strong>Improved agent isolation:</strong> Agents can run in a Cloud Hypervisor or NVX micro-VM and prevent data leaks in cross-repository workflows with enclaves.</li>
</ul>
<p>See the <a href="https://github.com/github/gh-aw/releases">GitHub Agentic Workflows release notes</a> for the full list of changes.</p>
<h3 id="get-started"><a class="heading-link" href="#get-started">Get started<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Follow the <a href="https://github.github.com/gh-aw/setup/quick-start/?utm_source=agentic-workflows-changelog-quickstart&amp;utm_medium=changelog&amp;utm_campaign=universe-2026/">quickstart guide</a> to install the CLI extension and trigger your first workflow in minutes. Explore prebuilt workflows in GitHub Next’s <a href="https://github.com/githubnext/agentics?utm_source=agentic-workflows-changelog-agentics&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">agentics repository</a> for ready-to-use examples covering triage, dependency management, code review, and reporting.</p>
<p>GitHub Agentic Workflows is now generally available on github.com for GitHub Free, Team, and Enterprise. Using the default GitHub Copilot CLI engine to power a workflow requires a Copilot license.</p>
<p>Learn more in the <a href="https://github.github.com/gh-aw/?utm_source=agentic-workflows-changelog-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">GitHub Agentic Workflows documentation</a>, and join the conversation in the <a href="https://github.com/orgs/community/discussions/211013?utm_source=agentic-workflows-changelog-community-discussion&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">community discussion</a>.</p>
