<p>This week, bring GitHub Enterprise Server repositories into the Copilot app and see which agent sessions need you first in VS Code. You can also try two new models, Claude Fable 5.2 and Gemini 4 Carbon.</p>
<h3 id="github-copilot"><a class="heading-link" href="#github-copilot">GitHub Copilot<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<ul>
<li>Claude Fable 5.2 is available to Copilot Pro+, Max, Business, and Enterprise users. It requires data retention by default, and Copilot Business and Enterprise administrators must turn on its policy, which is off by default. Learn more about <a href="https://github.blog/changelog/2026-11-09-claude-fable-5-2-in-github-copilot/">Claude Fable 5.2</a>.</li>
<li>Gemini 4 Carbon is available to Copilot Pro+, Max, Business, and Enterprise users.</li>
</ul>
<h3 id="github-copilot-app"><a class="heading-link" href="#github-copilot-app">GitHub Copilot app<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<ul>
<li>Continue cloud and Codespace sessions on your phone. A new <strong>Open in</strong> menu includes a GitHub Mobile option that shows a QR code.</li>
<li>Sign back in to MCP servers such as Slack without leaving the conversation. When a server needs you to sign in again, the conversation offers the matching connector, connects it in place, and resumes your task.</li>
<li>Work with repositories, issues, and pull requests from GitHub Enterprise Server in the Copilot app, now generally available. You’ll still need a GitHub.com or GHE.com account, and cloud sessions aren’t available for GHES. Learn more about <a href="https://docs.github.com/enterprise-server@latest/copilot/copilot-on-ghes/sign-in-on-copilot-app">signing in with GHES</a>.</li>
<li>Schedule Project automations down to the minute, or use a custom cron schedule such as weekdays at 9:30.</li>
<li>Dictate in French, Spanish, and other languages. Download the multilingual voice model in settings, then choose <strong>Auto</strong> or a specific language.</li>
<li>Filter issues and pull requests by custom fields, such as a GitHub Project’s Size, from the <strong>Add filter</strong> menu.</li>
<li>Combine high contrast with red, green, or blue-yellow color filters in <strong>Settings</strong> &gt; <strong>Accessibility</strong>, and preview combinations before you apply them. High contrast replaces the separate “Increase contrast” setting. You can also choose GitHub Dimmed as a dark-only palette in <strong>Settings</strong> &gt; <strong>Themes</strong>.</li>
</ul>
<p>Install the <a href="https://gh.io/app">GitHub Copilot app</a>.</p>
<h3 id="github-copilot-in-vs-code-1-146-release"><a class="heading-link" href="#github-copilot-in-vs-code-1-146-release">GitHub Copilot in VS Code (1.146 release)<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<ul>
<li>Let an agent run model comparisons for you. With <code>Compare Models</code> enabled, turn on the agent tools in settings, and agents can find available models, launch comparisons, and read the results to summarize findings. This is experimental.</li>
<li>Track agent sessions across all your workspaces from one view with Inbox mode in the Agents window’s sessions list. Sessions that need your attention appear first, and you can dismiss, hold, or snooze the rest. This is experimental.</li>
<li>Move a chat out of the Agents window into its own window, then arrange the chat, its editors, and its terminals to fit the task. Chat windows are in preview.</li>
<li>Find, install, and uninstall extensions without leaving the Agents window. Extensions with unsupported features show a warning before you install them. This is experimental.</li>
<li>Move to the Copilot harness before the Local harness is removed in February 2027. The Copilot harness is already the default for new sessions, and the <a href="https://code.visualstudio.com/docs/agents/run/move-to-copilot">transition guide</a> covers moving any remaining workflows.</li>
</ul>
<p>Explore everything that’s new in the <a href="https://aka.ms/vscode/146">full release notes</a>.</p>
