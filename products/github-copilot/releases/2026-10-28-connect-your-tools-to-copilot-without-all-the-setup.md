<p>The context your agent needs is often outside your repository: a thread in Slack, a design in Figma, an error in Sentry. Until now, giving Copilot that context meant finding a Model Context Protocol (MCP) server, setting up a sign-in, and repeating that in each tool you use. GitHub-verified MCP servers, or connectors, are rolling out in public preview. With them, you only have to connect once.</p>
<h3 id="connect-once-use-it-across-copilot"><a class="heading-link" href="#connect-once-use-it-across-copilot">Connect once, use it across Copilot<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Pick a service, sign in, and you’re done. There’s no server to find, nothing to install locally, and no credentials to manage. A service you connect in one place works across the GitHub Copilot app, Copilot CLI, VS Code, Copilot in the cloud, and GitHub Mobile. And it works with no extra setup. Copilot keeps you signed in in the background.</p>
<h3 id="bring-in-the-tools-your-team-already-uses"><a class="heading-link" href="#bring-in-the-tools-your-team-already-uses">Bring in the tools your team already uses<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>At launch, you can connect 26 services, including Slack, Figma, Notion, Sentry, Linear, Atlassian Rovo, Cloudflare, Vercel, and Work IQ.</p>
<p>To connect a service:</p>
<ul>
<li><strong>Copilot app</strong>: Open <strong>Customize</strong> and select <strong>Connect</strong> on the service you want.</li>
<li><strong>Copilot CLI</strong>: Run <code>/mcp</code>, switch to the <strong>Connectors</strong> tab, and select <strong>Connect</strong> on the service you want.</li>
<li><strong>VS Code</strong>: Open the Agents window, go to <strong>Customizations</strong>, and connect the service you want.</li>
<li><strong>github.com</strong>: Browse services on the <a href="https://github.com/copilot/customize?utm_source=connectors-changelog-customize-tab&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">Copilot customization page</a> and select the service you want.</li>
</ul>
<p>Copilot uses a connected service’s tools when they’re relevant to your request. In the Copilot app, you can also set up automations that use a connected service on a schedule, so Copilot does recurring work for you.</p>
<h3 id="use-connected-services-in-copilot-in-the-cloud"><a class="heading-link" href="#use-connected-services-in-copilot-in-the-cloud">Use connected services in Copilot in the cloud<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Connected services also work in Copilot in the cloud, whether you start a session on github.com or in the GitHub Mobile app.</p>
<h3 id="try-it"><a class="heading-link" href="#try-it">Try it<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>GitHub-verified MCP servers are rolling out in public preview to users on all Copilot plans. To try them with Copilot Business or Copilot Enterprise, an admin needs to enable the <code>Editor preview features</code> policy for your <a href="https://docs.github.com/enterprise-cloud@latest/copilot/how-tos/administer-copilot/manage-for-organization/manage-policies#enabling-copilot-features-and-models-in-your-organization">organization</a> or <a href="https://docs.github.com/enterprise-cloud@latest/copilot/how-tos/administer-copilot/manage-for-enterprise/manage-enterprise-policies#defining-policies-for-your-enterprise">enterprise</a>. If your enterprise uses an MCP allowlist in managed settings, an admin also needs to <a href="https://docs.github.com/enterprise-cloud@latest/copilot/how-tos/administer-copilot/manage-mcp-usage/configure-enterprise-allowlist?utm_source=connectors-changelog-enterprise-enable-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#allowing-copilot-connectors">add GitHub-verified MCP servers</a> to it. Some services also need to be enabled by an admin on their side, such as allowing Slack MCP access.</p>
<p>Learn more about <a href="https://docs.github.com/copilot/concepts/customizations/copilot-connectors">GitHub-verified MCP servers</a>. Share feedback in our <a href="https://github.com/orgs/community/discussions/211002?utm_source=connectors-changelog-community-discussion&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">Community discussion</a>.</p>
<p>Happy coding! 💙</p>
