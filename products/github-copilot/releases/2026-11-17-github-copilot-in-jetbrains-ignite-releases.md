<p>This update brings remote access, on-device voice dictation, and browser use controls to GitHub Copilot for JetBrains. Copilot users in JetBrains IDEs also get context usage shortcuts, historical diffs, simpler follow-up controls, and improvements to chat reliability.</p>
<h2 id="whats-new"><a class="heading-link" href="#whats-new">What’s new<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<h3 id="cloud-sandbox-public-preview"><a class="heading-link" href="#cloud-sandbox-public-preview">Cloud sandbox (public preview)<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Cloud sandbox runs Copilot sessions in an isolated, GitHub-hosted environment instead of on your computer. Copilot can make code changes and run commands and tests there, freeing local resources and allowing parallel sessions. We’re rolling this out in phases.</p>
<p><img decoding="async" loading="lazy" alt="User chooses cloud sandbox from the dropdown and works in the cloud sandbox with Copilot" src="https://github.com/user-attachments/assets/1bb83780-126a-4969-aa54-6470837f06bb"></p>
<h3 id="remote-access-public-preview"><a class="heading-link" href="#remote-access-public-preview">Remote access (public preview)<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>You can now opt in to remote access to make Copilot chats available in other Copilot clients, such as VS Code and the Copilot app. Discover shared sessions from remotely accessible computers, or reopen remote sessions from history to continue the conversation. We’re rolling this out in phases.</p>
<p><img decoding="async" loading="lazy" alt="Remote access to Copilot sessions in JetBrains" src="https://github.com/user-attachments/assets/d91ab2a0-8231-42e6-9de5-9726cb967c40"></p>
<h3 id="browser-use-public-preview"><a class="heading-link" href="#browser-use-public-preview">Browser use (public preview)<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Paired with <a href="https://chromewebstore.google.com/detail/github-copilot/hblomdgalaelcilcdepgohfcogjiijhe">GitHub Copilot in Chrome</a>, Copilot’s built-in browser use plugin can open and navigate web pages, read their content, and interact with links, buttons, and forms to gather information or complete web-based tasks.</p>
<p>Enable Browser Use in JetBrains under <strong>GitHub Copilot &gt; Chat &gt; Enable Browser Use</strong>.</p>
<p><img decoding="async" loading="lazy" alt="GitHub Copilot extension in Chrome showing it's connected and ready" src="https://github.com/user-attachments/assets/9110bf45-2ac1-4f53-8dfd-18cf0da7abde"></p>
<h3 id="on-device-voice-dictation-public-preview"><a class="heading-link" href="#on-device-voice-dictation-public-preview">On-device voice dictation (public preview)<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>You can now dictate chat messages on supported native plugin packages with <strong>Editor Preview</strong> enabled. Opt in and download a model to get started. Transcripts stay as editable drafts until you select <strong>Send</strong>.</p>
<p><img decoding="async" loading="lazy" alt="Copilot interface showing someone pressing a record button and to use on-device voice dictation and then Copilot spelling out 'create a simple math library' in the chat " src="https://github.com/user-attachments/assets/e0d2fdaf-2d6c-4ce6-be3a-61317c2d3e34"></p>
<h3 id="split-mode-remote-development"><a class="heading-link" href="#split-mode-remote-development">Split mode remote development<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>GitHub Copilot supports JetBrains split mode remote development, with chat and editor UI running on your local client while Copilot operations run on the remote backend. Make sure you have the GitHub Copilot plugin installed both locally and on the remote backend.</p>
<h2 id="user-experience-enhancements"><a class="heading-link" href="#user-experience-enhancements">User experience enhancements<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>You can manage conversations and find model options with fewer steps:</p>
<ul>
<li><strong>Conversation timing</strong>: See timestamps on Copilot agent prompts and responses.</li>
<li><strong>Session cleanup</strong>: Use <strong>Delete</strong> beside <strong>Archive</strong> in session history, and choose whether to skip future single-session deletion confirmations.</li>
<li><strong>Model picker</strong>: Find <strong>Copilot Fusion</strong> pinned at the top of Copilot agent model management, where it stays enabled even when you deselect the entire model group.</li>
<li><strong>Organization usage</strong>: See Copilot Access usage in the quota dialog consistently with other organization plans, including organization help links rather than upgrade or overage actions.</li>
<li><strong>Steer and queue</strong>: Press <code>Enter</code> to steer a running Copilot agent session, or <code>Ctrl+Enter</code> (<code>Command+Enter</code> on macOS) to queue a follow-up.</li>
<li><strong>Inline chat details</strong>: See model names and per-response token details while retaining agent session credit totals. Ask mode response footers now show the selected Fusion tier rather than the underlying model, and the model picker stays open when you turn Copilot Fusion on or off.</li>
<li><strong>Worktree names</strong>: Use shorter Copilot worktree directory and branch names that retain their timestamps.</li>
</ul>
<h2 id="quality-improvements"><a class="heading-link" href="#quality-improvements">Quality improvements<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>This update improves chat persistence, startup, and recovery, preserves saved history, and fixes proxy-related loading issues and saved Claude Code paths on Unix. You also get clearer error messages for failed tool calls, working historical session diffs on newer JetBrains IDE EAP builds, and improvements to context search, code formatting, input focus, and MCP sign-in recovery.</p>
<h2 id="changed"><a class="heading-link" href="#changed">Changed<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<h3 id="onboarding-and-usage-tips"><a class="heading-link" href="#onboarding-and-usage-tips">Onboarding and usage tips<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>The chat onboarding tour is now generally available to eligible users. Chat usage tips are available by default, while your saved tips preference remains unchanged.</p>
<h3 id="enterprise-managed-providers-and-copilot-fusion"><a class="heading-link" href="#enterprise-managed-providers-and-copilot-fusion">Enterprise-managed providers and Copilot Fusion<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Enterprise-managed settings now disable Claude and Codex unless an administrator policy allows an exception. Copilot preserves your saved provider preferences.</p>
<p>Copilot Fusion now applies enterprise-managed tier defaults while keeping available tiers selectable and preserving your saved choices.</p>
<h3 id="code-review-and-java-modernization"><a class="heading-link" href="#code-review-and-java-modernization">Code review and Java modernization<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Code review now uses the Copilot agent review engine. You still see results in the existing inline review interface.</p>
<p>You can now find Java modernization findings in the “Problems View” on supported IDEs. We’ve restored automatic Maven vulnerability checks: opening or importing a Maven project sends dependency coordinates to GitHub Advisories to check for vulnerabilities.</p>
<h2 id="deprecation"><a class="heading-link" href="#deprecation">Deprecation<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>Support for JetBrains IDE 2025.2 has ended. Upgrade to 2025.3 or later to continue receiving GitHub Copilot updates. We recommend version 2026.2 or later for the best experience.</p>
<h2 id="try-it-out"><a class="heading-link" href="#try-it-out">Try it out<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>We encourage you to try out the <a href="https://plugins.jetbrains.com/plugin/17718-github-copilot--your-ai-pair-programmer/versions">latest version of the GitHub Copilot plugin</a> and share your feedback. We’d love to hear about your experience in the following channels:</p>
<ul>
<li>In-product feedback: Use the feedback options within your IDE.</li>
<li>Feedback repository: Share your thoughts in the <a href="https://github.com/microsoft/copilot-intellij-feedback/issues">GitHub Copilot for JetBrains IDEs issues</a>.</li>
</ul>
