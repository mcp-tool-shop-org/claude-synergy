<p>This week, GitHub Copilot introduces Jira integration in Copilot app and adaptive model orchestration with Project HydraFusion in Copilot CLI. We also introduced new agent automation in Visual Studio Code and expanded enterprise controls for Copilot in JetBrains.</p>
<h3 id="github-copilot-app"><a class="heading-link" href="#github-copilot-app">GitHub Copilot app<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p><img decoding="async" loading="lazy" alt="The Customize window in the Copilot App with the Canvas tab selected. Three large boxes are featured, Azure DevOps, Microsoft Foundry, and Jira. Each of them provides a title, description, and install button." src="https://github.com/user-attachments/assets/e059ce80-9dea-4410-bc67-ebb48ec7bdae"></p>
<p>Turn Jira issues into action. Bring Jira issues into a shared canvas, choose what moves forward, and let Copilot carry the context into investigation, implementation, and pull request preparation.</p>
<p>Download <a href="https://github.com/features/ai/github-app?utm_source=download-app-09-07&amp;utm_medium=changelog&amp;utm_campaign=weekly-copilot-launches-aug-2026">the Copilot app</a>.</p>
<h3 id="github-copilot-cli"><a class="heading-link" href="#github-copilot-cli">GitHub Copilot CLI<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Project HydraFusion is now in <code>/experimental</code>. HydraFusion delivers automated semantic routing between local, cloud, and compound models. You select HydraFusion like any other model, and it chooses a workflow that balances performance, cost, and latency for each task.</p>
<p>To learn more, read the <a href="https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/">Project HydraFusion blog post</a>.</p>
<p><img decoding="async" loading="lazy" alt="A text window in Copilot CLI with the Current tab selected. The text shows a model picker listing several options in a list with Hydrafusion (Preview) selected." src="https://github.com/user-attachments/assets/e61de3fb-c572-4b0e-8138-a41e1b787465"></p>
<p>Install <a href="https://github.com/features/copilot/cli?utm_source=install-cli-09-07&amp;utm_medium=changelog&amp;utm_campaign=weekly-copilot-launches-aug-2026">Copilot CLI</a>.</p>
<h3 id="vs-code-1-137-release-updates"><a class="heading-link" href="#vs-code-1-137-release-updates">VS Code 1.137 release updates<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<ul>
<li>Schedule recurring agent tasks to run hourly, daily, or weekly, or run them on demand with automations, now in public preview.</li>
<li>Voice mode is now in experimental so you can talk to, interrupt, or redirect Copilot while it works on your code.</li>
<li>New in experimental, review issue and pull request details directly in the Agents window, even when the repository is not open.</li>
</ul>
<p>Explore everything that’s new in the <a href="https://aka.ms/VSCode/137">full release notes</a>.</p>
<h3 id="github-copilot-in-jetbrains"><a class="heading-link" href="#github-copilot-in-jetbrains">GitHub Copilot in JetBrains<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Now in public preview, enterprise administrators can centrally configure sandbox behavior for GitHub Copilot in JetBrains IDEs. Managed policies can control sandbox enablement, filesystem and network access, proxy settings, developer-tool access, macOS Keychain access, and more.</p>
<p>Learn more in the <a href="https://github.blog/changelog/2026-09-08-enterprise-managed-sandbox-in-copilot-for-jetbrains/">previous Copilot in JetBrains changelog</a>.</p>
