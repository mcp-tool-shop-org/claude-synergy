<p>With Copilot Automations, you can combine prompts, triggers, and tools to design workflows around the way your team works. Triggers define when your automation runs (e.g., “every day at 9am” or “when a pull request is opened”). Tools define what your automation can do (e.g., “update issue labels” or “create pull request”).</p>
<p>Automations now support:</p>
<ul>
<li><strong>New triggers</strong>: Start automations from external systems using the API, respond to more GitHub events, and chain automations into multi-step workflows.</li>
<li><strong>New tools</strong>: Choose from 20 new GitHub tools and connect tools from custom MCP servers.</li>
<li><strong>Cost controls</strong>: Set AI credit limits per run, day, week, or month.</li>
</ul>
<h2 id="more-triggers"><a class="heading-link" href="#more-triggers">More triggers<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<h3 id="trigger-automations-from-external-systems-using-the-api"><a class="heading-link" href="#trigger-automations-from-external-systems-using-the-api">Trigger automations from external systems using the API<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>You can now trigger automations with the GitHub REST API, allowing you to connect automations to any external system. For example, you could triage incoming Jira tickets, fix new issues in Sentry, or investigate PagerDuty incidents.</p>
<p>Define your automation with the relevant prompt and tools, then set up a webhook handler to receive events from the external system and call the <a href="https://docs.github.com/rest/agent-automations/agent-automations?apiVersion=2026-03-10&amp;utm_source=tools-triggers-costs-changelog-api-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">Trigger an automation API</a>, passing in relevant context.</p>
<h3 id="24-new-github-triggers"><a class="heading-link" href="#24-new-github-triggers">24 new GitHub triggers<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>You can now run automations in response to 24 more events across issues, pull requests, discussions, and security alerts:</p>
<ul>
<li><strong>Issues</strong>: Assigned, sub-issue added, labeled, closed, reopened, and status changed</li>
<li><strong>Pull requests</strong>: Assigned, ready for review, labeled, merge conflict, review submitted, review requested, closed, reopened, converted to draft, review dismissed, and review thread resolved or unresolved</li>
<li><strong>Discussions</strong>: Discussion opened, discussion updated, and comment or reply created</li>
<li><strong>Security alerts</strong>: Code scanning alert created, secret scanning alert created, and Dependabot alert created</li>
</ul>
<h3 id="chain-automations-together"><a class="heading-link" href="#chain-automations-together">Chain automations together<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Automations can now trigger other automations, so you can stack them into multi-step workflows. There are two ways to set this up:</p>
<ul>
<li><strong>The “Can be triggered by” setting</strong>: Each trigger now has a “Can be triggered by” option. It defaults to <code>Only users</code>, but you can set it to <code>Users and Copilot</code> so that events from other automations, such as a pull request opened by Copilot, also fire the trigger.</li>
<li><strong>Automation run triggers</strong>: New <strong>Automation run succeeded</strong> and <strong>Automation run failed</strong> triggers let you run one automation after another finishes.</li>
</ul>
<h2 id="more-tools"><a class="heading-link" href="#more-tools">More tools<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<h3 id="20-new-github-tools"><a class="heading-link" href="#20-new-github-tools">20 new GitHub tools<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>You can now allow your automations to:</p>
<ul>
<li>Upload image or video attachments to include in issues and pull requests (e.g., screenshots or screen recordings)</li>
<li>Retry workflow runs</li>
<li>Merge pull requests</li>
<li>Update issue and pull request comments</li>
<li>Mark pull requests as ready for review or convert them to drafts</li>
<li>Hide and unhide comments, pull request review comments, and pull request reviews</li>
<li>Remove reactions from issues, pull requests, and comments</li>
<li>Read discussions, list discussion categories, and comment on discussions</li>
</ul>
<h3 id="connect-tools-from-custom-mcp-servers"><a class="heading-link" href="#connect-tools-from-custom-mcp-servers">Connect tools from custom MCP servers<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Your automations can now use tools provided by MCP servers, so they can work with external systems as well as GitHub. As with GitHub tools, you choose exactly which tools your automation can use.</p>
<p>To configure MCP tools for an automation, <a href="https://docs.github.com/copilot/how-tos/copilot-on-github/customize-copilot/configure-mcp-servers?utm_source=tools-triggers-costs-changelog-mcp-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">add the MCP server in your repository’s settings</a>, then pick the relevant tools from the tool picker when you create your automation.</p>
<h2 id="cost-controls"><a class="heading-link" href="#cost-controls">Cost controls<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>You can now limit how many AI credits each automation can consume. When you create or edit an automation, you can set any combination of these optional limits:</p>
<ul>
<li><strong>Per run</strong>: An automation run stops when it reaches this limit.</li>
<li><strong>Daily, weekly, and monthly</strong>: Once the automation reaches one of these limits, new runs won’t start until the period resets.</li>
</ul>
<p>Automations without limits continue to run as they do today. To get started, see <a href="https://docs.github.com/copilot/how-tos/use-copilot-agents/cloud-agent/create-automations?utm_source=tools-triggers-costs-changelog-credit-limit-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#setting-ai-credits-limits">setting AI credit limits on github.com</a> or <a href="https://docs.github.com/copilot/how-tos/github-copilot-app/using-automations?utm_source=tools-triggers-costs-changelog-cloud-credit-limit-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#setting-ai-credits-limits-for-cloud-automations">setting AI credit limits in the GitHub Copilot app</a>.</p>
<p>Copilot Automations is available with Copilot Pro, Pro+, Max, Business, and Enterprise plans. You can create automations in any repository where you have write access.</p>
<p>Join the discussion within <a href="https://github.com/orgs/community/discussions/211006?utm_source=tools-triggers-costs-changelog-community-discussion&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">GitHub Community</a>.</p>
