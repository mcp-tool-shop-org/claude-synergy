<p>Copilot is most useful when it can work where you do. The GitHub Copilot app now supports your Azure DevOps repositories, your GitHub Enterprise Server instance, and the browser you’re already signed in to.</p>
<h3 id="work-with-azure-devops-repositories-in-the-github-copilot-app"><a class="heading-link" href="#work-with-azure-devops-repositories-in-the-github-copilot-app">Work with Azure DevOps repositories in the GitHub Copilot app<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Clone an Azure DevOps repository, ask an agent to create a branch, make code changes, and open a pull request, then see it through to completion without leaving the GitHub Copilot app. Track its status in the sidebar, click <strong>Fix</strong> on a review comment to have an agent address it, or turn on agent merge to let an agent fix CI failures and complete the pull request once your Azure DevOps checks and policies pass.</p>
<p>Azure DevOps integration is now in public preview. To get started, open <strong>Settings</strong> &gt; <strong>Experimental</strong> and turn on <strong>Azure DevOps integration</strong>, then go to <strong>Accounts</strong> &gt; <strong>Add account</strong> and sign in with the Microsoft account you use for Azure DevOps. Cloud sessions aren’t available for Azure DevOps repositories.</p>
<p>For more information, see the <a href="https://docs.github.com/copilot/how-tos/github-copilot-app/manage-azure-devops-work?utm_source=app-changelog-manage-azdo-docs&amp;utm_medium=changelog&amp;utm_campaign=ignite-nov-2026">Azure DevOps documentation</a>.</p>
<p><video loop="" controls="" autoplay="" muted="" width="100%" src="https://github.com/user-attachments/assets/2f1f59ed-a889-46df-8a8d-720cec4a08f9%20"><br>
</video></p>
<h3 id="let-copilot-work-in-your-browser"><a class="heading-link" href="#let-copilot-work-in-your-browser">Let Copilot work in your browser<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Ask Copilot to fill out forms, pull information from webpages, or test and debug the web app you’re building, right in the browser you’re already signed in to. Browser use, now in public preview, works in Chromium-based browsers, including Google Chrome and Microsoft Edge, with the <a href="https://chromewebstore.google.com/detail/github-copilot/hblomdgalaelcilcdepgohfcogjiijhe">GitHub Copilot extension for Chrome</a> and runs in an isolated tab group. It also works alongside computer use.</p>
<p>Browser use is off by default. To get started, install the extension, then open <strong>Settings</strong> &gt; <strong>Computer Use</strong> and turn on both <strong>Enable Computer Use</strong> and <strong>Enable Browser Use</strong>. You can manage permission levels in the extension’s settings.</p>
<p><video loop="" controls="" autoplay="" muted="" width="100%" src="https://github.com/user-attachments/assets/4fd64f98-4caf-4045-a64d-6d58ff37486f"></video></p>
<p>Browser use is also available in Copilot CLI, VS Code, and JetBrains IDEs.</p>
<p>For more information, see the <a href="https://gh.io/about-browser-use">browser use documentation</a>.</p>
<h3 id="bring-your-github-enterprise-server-work-into-the-app"><a class="heading-link" href="#bring-your-github-enterprise-server-work-into-the-app">Bring your GitHub Enterprise Server work into the app<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Add your GitHub Enterprise Server (GHES) account to work with remote repositories, issues, and pull requests in the GitHub Copilot app. GHES support, previously an opt-in preview, is now generally available. Update to GitHub Copilot app version 1.2.0 or later to use it.</p>
<p>To get started, sign in with a GitHub.com or GHE.com account, then open <strong>Settings</strong> &gt; <strong>Accounts</strong> &gt; <strong>Add account</strong> and choose <strong>GitHub Enterprise Server</strong>. Cloud sessions aren’t available for GHES.</p>
<p>For more information, see the <a href="https://docs.github.com/enterprise-server@latest/copilot/copilot-on-ghes/sign-in-on-copilot-app?utm_source=app-changelog-ghes-docs&amp;utm_medium=changelog&amp;utm_campaign=ignite-nov-2026">Copilot GHES documentation</a>.</p>
<h3 id="get-started"><a class="heading-link" href="#get-started">Get started<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Download or update the <a href="https://github.com/features/ai/github-app?utm_source=app-changelog-app-download&amp;utm_medium=changelog&amp;utm_campaign=ignite-nov-2026">GitHub Copilot app</a>.</p>
