<p>Issue artifacts attach agent-generated outputs and other important context directly to an issue. By keeping plans, research, links, and visualizations alongside the work, they give coding agents richer context and teams a durable record as the work evolves.</p>
<p><video loop="" controls="" autoplay="" muted="" width="100%" src="https://github.com/user-attachments/assets/f6b2cef1-0bd9-4bb2-92af-549557e8436d"><br>
</video></p>
<p>With issue artifacts, you can attach:</p>
<ul>
<li><strong>Markdown files</strong> for plans, research, root cause analyses, and other documents.</li>
<li><strong>Links</strong> to Slack or Microsoft Teams threads, prototypes, and other external resources.</li>
<li><strong>HTML files</strong> for interactive visualizations, flowcharts, and diagrams, with the ability to toggle between a rendered preview and the source.</li>
</ul>
<h2 id="get-started-with-the-github-app"><a class="heading-link" href="#get-started-with-the-github-app">Get started with the GitHub App<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>When you use the GitHub App to work on an issue, artifacts created during the session are automatically attached to that issue. You can also prompt the session to create a specific artifact, such as an implementation plan, root cause analysis, or summary of historical context. Support for creating and viewing HTML artifacts in the GitHub App is coming soon.</p>
<h2 id="get-started-with-gh-issue-artifact"><a class="heading-link" href="#get-started-with-gh-issue-artifact">Get started with <code>gh issue artifact</code><span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>The new <code>gh issue artifact</code> command brings issue artifact support to GitHub CLI. You can use the <code>create</code>, <code>edit</code>, <code>list</code>, <code>view</code>, <code>download</code>, and <code>delete</code> commands to manage issue artifacts. Coding agents and developer tools that use <code>gh</code> can also invoke them as part of their workflows.</p>
<p>Artifacts can also be addressed by their GitHub URLs, and Markdown documents support image and video attachments with <code>--attach</code>. For usage details, see the <a href="https://cli.github.com/manual/gh_issue_artifact"><code>gh issue artifact</code> documentation</a>.</p>
<h2 id="manage-and-view-artifacts-on-github-com"><a class="heading-link" href="#manage-and-view-artifacts-on-github-com">Manage and view artifacts on github.com<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>Create, edit, and delete artifacts directly from an issue on github.com. You can update an artifact as plans and decisions change while retaining its version history, giving teammates and agents a current source of truth without losing how it evolved.</p>
<p>Each artifact can be linked, making it easy to open, reference, and share.</p>
<h2 id="share-your-feedback"><a class="heading-link" href="#share-your-feedback">Share your feedback<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<p>Join the <a href="https://github.com/orgs/community/discussions/210917">GitHub Community</a> to tell us what you think and help shape the public preview.</p>
