<p>Agents should understand more than your codebase—they should understand how your team works. Your preferences, repository conventions, skills, and custom instructions guide how changes should be made, while code in related repositories can show how the pieces fit together. Without that context, agents spend time rediscovering knowledge and can miss your team’s conventions.</p>
<p>GitHub intelligence is the context and learning layer sourced from the graph of GitHub data. It makes this data useful to agents, helping them remember how you work, keep that guidance current, and find the code and development history relevant to the next task. The goal is for agents to build on what you and your team already know, rather than treating every session as a fresh start.</p>
<p>That is the advantage of building where your team’s work already lives. A repository memory can capture why an edge case matters and which test covers it. GitHub intelligence allows agents to use that context, with controls over what they can access.</p>
<p>Three capabilities bring this into your workflow:</p>
<ul>
<li>Memory carries knowledge between sessions</li>
<li>Dreaming keeps the context current</li>
<li>Code search reaches beyond your checkout.</li>
</ul>
<p>Availability and settings vary by capability.</p>
<h3 id="memory-pick-up-where-you-left-off"><a class="heading-link" href="#memory-pick-up-where-you-left-off">Memory: Pick up where you left off<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p><a href="https://docs.github.com/copilot/concepts/prompting-and-context/copilot-memory?utm_source=gh-intelligence-changelog-memory-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">GitHub Copilot Memory</a> is now generally available on paid Copilot plans. Copilot can remember personal preferences and repository conventions across sessions and clients. Memories can be created in the Copilot app, Copilot CLI, VS Code, Copilot cloud agent, Copilot code review, Slack, Teams, and GitHub Mobile.</p>
<p>You can tell Copilot, <code>Remember to start my pull request descriptions with a TL;DR</code>, and it can reuse that preference across Copilot experiences. Repository memories can capture the right test command or how your team expects Copilot to check its work, so you spend less time repeating guidance in each session. Copilot sessions autonomously generate and curate memories, learning from every interaction.</p>
<p>Among the Copilot CLI sessions reviewed during the public preview where the agent used memory, 93% showed better adherence to developer preferences and 42% showed more efficient workflows attributed to the memories included in the session context.</p>
<p>You can interact with memories in the Copilot app, Copilot CLI, and VS Code, or manage personal memories in your Copilot settings, where you can <a href="https://github.com/settings/copilot/memory?utm_source=gh-intelligence-changelog-memory-settings&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">view or delete saved preferences</a>.</p>
<h3 id="dreaming-continuous-context-improvement"><a class="heading-link" href="#dreaming-continuous-context-improvement">Dreaming: Continuous context improvement<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Copilot dreaming, now in public preview, reflects on past work to improve future agentic sessions.</p>
<p>Three dream types are currently available:</p>
<ul>
<li><strong>Personal memory curation</strong> customizes Copilot to your personal preferences by updating memories based on your agent conversations.</li>
<li><strong>Repository customization</strong> manages repository-scoped memories and proposes updates and improvements to existing skills and custom instruction files.</li>
<li><strong>Code review customization</strong> turns recurring accepted code-review feedback into guidance for Copilot code review.</li>
</ul>
<p>Dreaming can add, update, and remove personal and repository memories. Changes to checked-in skills and instructions are proposed in pull requests for your team to review.</p>
<p>Dreaming is opt-in.</p>
<ul>
<li><strong>Individual subscribers:</strong> Enable personal curation in your Copilot settings and repository dreams in each repository’s settings. See <a href="https://docs.github.com/copilot/how-tos/use-copilot-agents/copilot-memory/manage-for-yourself?utm_source=gh-intelligence-changelog-dreaming-individuals-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#enabling-copilot-dreaming-for-your-personal-account">personal and repository setup</a>.</li>
<li><strong>Organizations and enterprises:</strong> Administrators <a href="https://docs.github.com/copilot/how-tos/use-copilot-agents/copilot-memory/manage-as-administrator?utm_source=gh-intelligence-changelog-dreaming-admin-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#enabling-copilot-dreaming">enable dreaming through Copilot policies</a>. Enterprise administrators can delegate that choice to organization administrators. Repository dreams cover the repositories allowed by Copilot Memory’s repository access settings. Users must also enable personal dreaming in their own Copilot settings.</li>
</ul>
<p>Dream runs consume AI credits. See the <a href="https://docs.github.com/copilot/concepts/prompting-and-context/copilot-dreaming?utm_source=gh-intelligence-changelog-dreaming-billing-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#availability-and-prerequisites">dreaming documentation for prerequisites, setup, and costs</a>.</p>
<h3 id="code-search-reach-beyond-your-checkout"><a class="heading-link" href="#code-search-reach-beyond-your-checkout">Code Search: Reach beyond your checkout<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Software projects rarely live in a single repository. <a href="https://docs.github.com/search-github/github-code-search/about-github-code-search?utm_source=gh-intelligence-changelog-code-search-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026">GitHub code search</a> helps Copilot find relevant code, configuration, schemas, and documentation across related projects and dependencies without needing a local clone. Copilot can search for exact text and symbols, match patterns with regular expressions, and narrow results by repository, path, or language. <a href="https://docs.github.com/copilot/concepts/prompting-and-context/repository-indexing?utm_source=gh-intelligence-changelog-semantic-search-docs&amp;utm_medium=changelog&amp;utm_campaign=universe-2026#semantic-code-search-in-copilot-chat">Semantic search</a> can also find code by what it does, such as retrying a failed payment, even when you don’t know the file, function name, or repository it lives in.</p>
<p>For example, you’re fixing failed payments, but retry behavior spans a payments service, a shared library, and background workers. Use <code>/research</code> to ask Copilot, <code>How do these components retry failed charges, and where could retries overlap?</code> Copilot can inspect implementations and callers across those repositories to help you understand how the system fits together before changing it.</p>
<p>That unlocks workflows that would otherwise require you to assemble the context yourself:</p>
<ul>
<li><strong>Plan a migration:</strong> Use <code>/research</code> to identify implementations and callers across repositories, plan the changes each service needs, and check which projects still use the old API.</li>
<li><strong>Investigate a bug:</strong> Trace related implementations across services and shared libraries, bring specific code references into the investigation, and use that context to propose a coordinated fix.</li>
<li><strong>Follow organizational standards:</strong> Find existing patterns across your organization and use them to guide changes in an unfamiliar codebase.</li>
</ul>
<p>Whether the task calls for an exact symbol, a regular expression in file contents or paths, or a natural-language description, Copilot can search across repositories in your organization to find relevant context. You spend less time cloning projects, tracking down files, and copying code into the conversation. In addition, Copilot gets the context it needs to make the right changes.</p>
<h3 id="try-it-today"><a class="heading-link" href="#try-it-today">Try it today<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Your team shouldn’t have to teach every agent the same lessons. GitHub intelligence helps agents carry those lessons forward, find the context they need, and put more of each session toward the work you actually want done.</p>
