<p><a href="https://github.blog/changelog/2026-04-13-remote-control-cli-sessions-on-web-and-mobile-in-public-preview">Remote control for Copilot CLI sessions</a> is now generally available on GitHub Mobile and github.com, so you can start work in your terminal and keep it moving from anywhere.</p>
<p>With this release, remote control now supports non-GitHub repositories and directories not associated with a repository.</p>
<p>We’re also introducing remote control in <a href="https://aka.ms/vscode-remote-control?utm_source=changelog-remote-control-ga-vscode-remote-cta&amp;utm_medium=changelog&amp;utm_campaign=dev-pod-copilot-cli-2026">VS Code</a> and <a href="https://plugins.jetbrains.com/plugin/17718-github-copilot--your-ai-pair-programmer/versions/stable/1048241?utm_source=changelog-remote-control-jetbrains-cta&amp;utm_medium=changelog&amp;utm_campaign=dev-pod-copilot-cli-2026">JetBrains</a>, making GitHub Copilot truly multi-surface and available across any device.</p>
<p>When remote control is enabled, Copilot streams your CLI session activity in real time, so you can view and steer your sessions on the go. Simply kick off a Copilot CLI session in the terminal, VS Code, or JetBrains, then monitor or steer it from the GitHub Mobile app or github.com.</p>
<div style="width: 3840px;" class="wp-video"><video class="wp-video-shortcode" id="video-95724-1" width="3840" height="2160" preload="metadata" controls="controls"><source type="video/mp4" src="https://github.blog/wp-content/uploads/2026/05/changelog-take-2.mp4#t=0.001?_=1"><a href="https://github.blog/wp-content/uploads/2026/05/changelog-take-2.mp4#t=0.001">https://github.blog/wp-content/uploads/2026/05/changelog-take-2.mp4#t=0.001</a></video></div>
<h3 id="built-for-staying-productive-from-your-phone"><a class="heading-link" href="#built-for-staying-productive-from-your-phone">Built for staying productive from your phone<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<ul>
<li>Track session progress live while you’re away from your desk.</li>
<li>Steer midsession, or queue the next message as soon as the current step finishes.</li>
<li>Review and tweak plans before Copilot starts implementing.</li>
<li>Stop a session at any time.</li>
<li>Approve or deny permission requests based on your settings.</li>
<li>Respond to Copilot’s questions when it needs input, regardless of where you are.</li>
</ul>
<h3 id="tips-for-starting-from-copilot-cli"><a class="heading-link" href="#tips-for-starting-from-copilot-cli">Tips for starting from Copilot CLI<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<ul>
<li>Run <code>/update</code> to make sure you’re on the latest version of Copilot CLI.</li>
<li>Start a remote session with <code>copilot --remote</code>, or enable it midsession with <code>/remote on</code>.</li>
<li>Scan the QR code or open the link in the GitHub Mobile app or on github.com.</li>
<li>For longer runs, use <code>/keep-alive</code> to help keep your machine awake.</li>
<li>View your sessions in the <strong>Agents</strong> tab in the repository.</li>
</ul>
<blockquote><p>
  <strong>Note:</strong> If you’re working with non-GitHub repositories or directories not associated with a repository, they will appear on github.com/copilot/agents.
</p></blockquote>
<h3 id="tips-for-starting-from-vs-code"><a class="heading-link" href="#tips-for-starting-from-vs-code">Tips for starting from VS Code<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<ul>
<li>Download the latest version of <a href="https://code.visualstudio.com/download?utm_source=changelog-remote-control-ga-vscode-download-cta&amp;utm_medium=changelog&amp;utm_campaign=dev-pod-copilot-cli-2026">VS Code</a>.</li>
<li>Enable the <code>github.copilot.chat.cli.remote.enabled</code> setting.</li>
<li>Start or resume a Copilot CLI session from the Chat view.</li>
<li>Enter <code>/remote on</code> in the chat input to enable remote control and create the linked GitHub task page.</li>
<li>Select <strong>Open</strong> on GitHub to open the linked task page.</li>
</ul>
<blockquote><p>
  <strong>Note:</strong> If you’re a Copilot Business or Copilot Enterprise user, an administrator will have to <a href="//docs.github.com/en/copilot/concepts/agents/copilot-cli/about-remote-control?utm_source=changelog-remote-control-ga-admin-docs-cta&amp;utm_medium=changelog&amp;utm_campaign=dev-pod-copilot-cli-2026#administering-remote-control">enable remote control and CLI policies</a> before you can use it.
</p></blockquote>
<p>Download or update GitHub Mobile today from the <a href="https://apps.apple.com/us/app/github/id1477376905">Apple App Store</a> or <a href="https://play.google.com/store/apps/details?id=com.github.android">Google Play Store</a> to get started.</p>
<p>Learn more about how remote control works for <a href="https://docs.github.com/en/copilot/how-tos/copilot-cli/steer-remotely?utm_source=changelog-remote-control-ga-steer-docs-cta&amp;utm_medium=changelog&amp;utm_campaign=dev-pod-copilot-cli-2026">Copilot CLI</a>, <a href="https://aka.ms/vscode-remote-control?utm_source=changelog-remote-control-ga-vscode-remote-cta&amp;utm_medium=changelog&amp;utm_campaign=dev-pod-copilot-cli-2026">VS Code</a> and <a href="https://github.com/microsoft/copilot-intellij-feedback/wiki/Enable-Copilot-CLI-Remote-Control?utm_source=blog-remote-control-jetbrains-cta&amp;utm_medium=blog&amp;utm_campaign=dev-pod-copilot-cli-2026">JetBrains</a> sessions.</p>
<p>Join the conversation in the <a href="https://github.com/orgs/community/discussions/192947">GitHub Community discussion</a>.</p>
