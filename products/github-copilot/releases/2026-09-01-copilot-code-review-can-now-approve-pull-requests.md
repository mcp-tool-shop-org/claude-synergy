<p>Copilot now tells you when a pull request is ready to approve, and admins can authorize it to sign off on approval. The ability for Copilot to approve is off by default and configurable at the enterprise, organization, and repository level. The approval assessments will now appear as a part of the overview comment in every Copilot review. This feature is available in public preview to GitHub Copilot Pro, Pro+, Max, Business, and Enterprise plans.</p>
<p><video width="100%" loop="" controls="" autoplay="" muted="" src="https://github.com/user-attachments/assets/351026c5-07a4-4bb7-ab29-66a6f200a04f"></video></p>
<h3 id="%e2%9c%85-approval-assessments"><a class="heading-link" href="#%e2%9c%85-approval-assessments">✅ Approval assessments<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>Every Copilot code review now includes an approval assessment in the overview comment. The assessment signals whether Copilot considers the pull request ready to approve, giving you an at-a-glance read on its judgment alongside its detailed comments.</p>
<blockquote><p>
  An approval assessment alone does not count toward merge requirements. Copilot’s determination is surfaced so you can decide how to act on it.
</p></blockquote>
<h3 id="%e2%9a%99%ef%b8%8f-turning-on-approvals"><a class="heading-link" href="#%e2%9a%99%ef%b8%8f-turning-on-approvals">⚙️ Turning on approvals<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h3>
<p>By default, Copilot will not approve pull requests. When enabled, Copilot can submit an approval that counts toward the repository’s required-approvals rule. If new commits are pushed after Copilot approves, its approval is dismissed just like a human reviewer’s, and you can request a new review from Copilot to get a fresh approval.</p>
<p>Admins control this behavior at three levels:</p>
<ul>
<li><strong>Enterprise:</strong> Admins can leave approvals off for the whole enterprise or let organizations decide.</li>
<li><strong>Organization:</strong> Admins can turn approvals on org-wide, let repository admins decide, enable it for specific repositories, or turn it off org-wide.</li>
<li><strong>Repository:</strong> Admins can turn approvals on or off, and choose which file paths Copilot is allowed to approve.</li>
</ul>
<p>To learn more about configuring approvals for your enterprise, organization, or repository, see the <a href="https://docs.github.com/copilot/how-tos/copilot-on-github/set-up-copilot/configure-code-review#customizing-copilot-code-review-1">Copilot code review documentation</a>.</p>
