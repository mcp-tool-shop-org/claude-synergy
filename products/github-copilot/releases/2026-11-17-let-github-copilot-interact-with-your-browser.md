<p>Paired with the <a href="https://chromewebstore.google.com/detail/github-copilot/hblomdgalaelcilcdepgohfcogjiijhe">GitHub Copilot Chrome extension</a>, browser use is now available in public preview in <a href="https://github.com/features/copilot/cli?utm_source=chromium-browser-changelog-cli&amp;utm_medium=changelog&amp;utm_campaign=ignite-nov-2026">GitHub Copilot CLI</a>, <a href="https://github.com/features/ai/github-app?utm_source=chromium-browser-changelog-app&amp;utm_medium=changelog&amp;utm_campaign=ignite-nov-2026">GitHub Copilot app</a>, <a href="https://code.visualstudio.com/">VS Code</a> and <a href="https://plugins.jetbrains.com/plugin/17718-github-copilot--your-ai-pair-programmer">JetBrains</a>. This is part of our ongoing effort to bring <a href="https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps/?utm_source=chromium-browser-changelog-computer-use-changelog&amp;utm_medium=changelog&amp;utm_campaign=ignite-nov-2026">computer use</a> into developers’ everyday workflows, making it easier to work with Copilot in the tools they already use. Browser use can be used together with computer use to give Copilot more direct access to workflows in a web browser.</p>
<p>Bring browser use into your daily workflow. You can ask Copilot to control the browser, debug web apps in real time, automate browser tests, and handle complex web tasks, all alongside the tools you already use.</p>
<p><video loop="" controls="" autoplay="" muted="" width="100%" src="https://github.com/user-attachments/assets/a3d9e087-d857-4bc2-b3bf-bdf34418a845"><br>
</video></p>
<h2 id="prerequisites"><a class="heading-link" href="#prerequisites">Prerequisites:<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<ul>
<li>Install <a href="https://chromewebstore.google.com/detail/github-copilot/hblomdgalaelcilcdepgohfcogjiijhe">GitHub Copilot in Chrome</a></li>
</ul>
<h2 id="to-get-started"><a class="heading-link" href="#to-get-started">To get started:<span class="heading-hash pl-2 text-italic text-bold" aria-hidden="true"></span></a></h2>
<ul>
<li>Enable browser use in your Copilot client:
<ul>
<li>Copilot CLI: enter <code>/plugin</code>, then find and enable browser use. You can then start a new session to use it.</li>
</ul>
<p><img decoding="async" loading="lazy" alt="enable browser use in the plugins part of Copilot CLI" src="https://github.com/user-attachments/assets/8f12f7aa-853a-4e2b-8c21-54456d881bfa"></p>
<ul>
<li>Copilot app: Go to <strong>Settings</strong> &gt; <strong>Computer Use</strong> &gt; <strong>Enable Browser Use</strong></li>
</ul>
<p><img decoding="async" loading="lazy" alt="copilot app settings showing enable browser use" src="https://github.com/user-attachments/assets/a4c69d1e-67e0-405e-bdd9-223cc9cb9d20"></p>
<ul>
<li>VS Code/JetBrains: Go to <strong>Settings</strong> &gt; <strong>Enable Browser Use.</strong></li>
</ul>
</li>
<li>Click the browser extension to check if its state is Connected.
<p><img decoding="async" loading="lazy" alt="GitHub Copilot extension in Chrome showing it's connected and ready" src="https://github.com/user-attachments/assets/9110bf45-2ac1-4f53-8dfd-18cf0da7abde"></p>
</li>
<li>
<p>Ask Copilot to use your browser to complete a task.</p>
<p><img decoding="async" loading="lazy" width="810" height="372" alt="browser-use-demo" src="https://github.com/user-attachments/assets/25bd0b58-3872-4d33-8450-486bcdb5d424"></p>
</li>
<li>
<p>You can also use the extension’s settings to manage permission levels and turn on experimental features.</p>
<p><img decoding="async" loading="lazy" width="625" height="300" alt="more settings" src="https://github.com/user-attachments/assets/56d06a3a-e05e-4356-bc33-a3aae5f52afd"></p>
</li>
</ul>

<p>Learn more in the <a href="https://gh.io/about-browser-use">browser use documentation</a>.</p>
