# mcp-registry v1.8.10

Improve incremental server listing query selection and planning, including sparse windows and deep pagination (#1865).

Database operators should prebuild both replacement indexes concurrently and validate their definitions before deploying to a busy database; see deploy/README.md. Existing indexes are retained for a separate post-rollout cleanup. API ordering and filtering remain unchanged.

This release also includes the merged HTTP authentication retry and multi-proof verification fixes, publisher private-key file/environment support, and registry UI title improvements since v1.8.9.
