# mcp-registry v1.8.5

This release adds production performance diagnostics: request arrivals and backlog, database pool/query metrics, and bounded slow-listing logs correlated with ingress request IDs. Slow-request logs separate connection acquisition, query/fetch waits, row decoding, and response processing, including snapshots while requests remain stuck.

It also includes publisher fixes for P-384 signatures and repository IDs, GitLab subgroup URL support, and stricter validation of incomplete repository metadata and invalid arguments. Previously stored invalid metadata may need correction when republishing or editing.

The ingress cache/timing log fields require the accompanying infrastructure rollout. Application release artifacts alone do not deploy the hosted registry. No new database migration is included.
