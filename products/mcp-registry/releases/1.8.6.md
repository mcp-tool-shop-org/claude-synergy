# mcp-registry v1.8.6

This release improves registry search performance under mixed search, pagination and publishing traffic.

- Select search page keys through covering indexes before fetching complete records.
- Plan searches for their actual parameter values to handle broad and rare terms reliably.
- Optimize namespace suffix searches and require at least three Unicode characters for nonempty search terms (shorter searches return HTTP 422).
- Include reproducible cyclic-load benchmarks and repeated staging validation against a public production-data snapshot.

Deployment: prebuild and verify migrations 016/017 indexes concurrently on busy databases. The validated burst capacity uses a 3-CPU PostgreSQL quota on the existing nodes, with the application connection pool unchanged. See deploy/README.md and tools/readbench/STAGING_SEARCH_RESULTS.md for procedure, evidence and limitations.
