# claude-agent-sdk-typescript v0.3.321

## What's changed

- Fixed `canUseTool` getting the app's own PreToolUse hook reason in `decisionReason` when another hook also asked
- Fixed a PreToolUse hook's `ask` being lost when another hook's `defer` finished first and could not be honored
- Fixed every hook being dropped when one event in the `hooks` option is set to `undefined`
- Fixed `WarmQuery.query()` with a string prompt hanging after `startup()` with `resume` when the resumed session finished a turn of its own before the prompt was sent
- Fixed `setMcpServers` closing a folder's `.mcp.json` or local-scope MCP server when passed an in-process server of the same name, in sessions bound with `SpareProcess.claim()`
- Fixed `reloadSkills()`, `reloadPlugins()` and `system/init` dropping project skills, commands or agents that a worktree lacks after Claude entered it
- Fixed sessions hanging on save, and `importSessionToStore()` never rejecting, when memory ran out while a transcript was being read
- Improved `resume` and `continue` on the bundled Claude Code binary: `initialize` is read during boot, so start-up work is less likely to run before your hooks are registered
- Changed queued subagent reports in auto mode to share one model call: each keeps its own message and result, and all but the last end in an empty `result` with `num_turns: 0`
- Changed an SDK MCP server named `claude-in-chrome` to follow the organization's Claude in Chrome policy: where the policy denies it, the server is not connected
- Updated to parity with Claude Code v2.1.321
