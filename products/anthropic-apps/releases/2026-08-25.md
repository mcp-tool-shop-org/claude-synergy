# anthropic-apps — August 25, 2026

<ul><li><strong>Memory in Claude Cowork, editable topics, and a sensitive topics setting:</strong> Memory now works across chat and Cowork in the cloud. Everything Claude remembers is listed under <b>Topics</b> in <b><a href="https://claude.ai/settings/memory" rel="nofollow noopener noreferrer" target="_blank">Settings &gt; Memory</a></b>, where you can edit or delete any item. Topics such as health or beliefs stay out of memory unless you turn on <b>Include sensitive topics in memory</b>. See <b><a href="https://support.claude.com/en/articles/11817273">Use Claude's chat search and memory to build on previous context</a></b>.</li></ul>
