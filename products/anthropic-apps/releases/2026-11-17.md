# anthropic-apps — November 17, 2026

<ul><li><strong>Choose a release channel in Claude Desktop:</strong> You can now use a release channel to set which version of Claude Desktop you get when the app updates. <b>Stable</b> stays the default and gets new versions less often, after more testing. <b>Latest</b> gets a new version about once a day, so fixes and new features reach you sooner. For more information, see <b><a href="https://support.claude.com/en/articles/10065433-install-claude-desktop#h_ac219b3bde">Choose a release channel</a></b>.</li></ul>
