# Analytics API for Enterprise plans — February 13, 2026

The Enterprise Analytics API provides programmatic access to usage and engagement data for Claude and Claude Code Remote usage within your organization. Data is aggregated per organization, per day, and each endpoint returns a snapshot for a single date that you specify. For more information, see Access usage data with the Analytics API.
