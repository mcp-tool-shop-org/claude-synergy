## Notable releases

- **2026-04-17 — Claude Design launch.** New Anthropic Labs product for collaborative visual outputs (designs, prototypes, slides, one-pagers), launched alongside Opus 4.7.
- **2026-04-16 — Claude Opus 4.7 GA.** Improvements in software engineering and complex long-running coding tasks, better vision for higher-resolution images.
- **2026-04-09 — Claude Cowork generally available on macOS and Windows.** Exit from research preview; adds Analytics API integration, usage analytics, and OpenTelemetry support.
- **2026-03-23 — Computer use research preview in Cowork.** Pro and Max plan users get Claude that opens files, runs dev tools, points/clicks/navigates; supercharges Dispatch for asynchronous tasks.
- **2026-03-02 — Memory free for all users.** Memory from chat history extended from paid plans to the free tier — a significant platform-wide expansion.
- **2026-02-17 — Claude Sonnet 4.6 launch.** Full skill upgrade across coding, computer use, long-context reasoning, agent planning, knowledge work, design; 1M token context window in beta.
