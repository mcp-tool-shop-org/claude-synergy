# mcp-java-sdk v2.1.0

## Highlights

- Tool list filtering #1108 by @Kehrlann
- HTTP client transport rework: `HttpClient`-based transports are now `Publisher`-based, and request customizers compose on the builders.
  - #1079 by @Kehrlann and @chemicL
  - #1165 by @Kehrlann

## Enhancements

- extensions attribute on `ClientCapabilities` and `ServerCapabilities` (SEP-2133). #1064 by @YousefHaggy
- `ServerHttpHeaderValidator` replaces `ServerTransportSecurityValidator`. #982 by @neerajbhatt
- Streamable HTTP server session sweeping and keep-alive. #1130 by @Kehrlann
- Remove the 2024-11-05 protocol from Streamable HTTP. #1126 by @Kehrlann
- Reject non-application/json POST requests. #1164 by @Kehrlann

## Bug fixes

- Stream leak when resuming with LAST_EVENT_ID. #1127 by @Kehrlann
- STDIO `sendMessage` is now thread-safe. #935 by @nquinquenel
- Malformed request bodies return 400 INVALID_REQUEST with Jackson 3. #1168 by @Kehrlann
- listXyz() methods return re-subscribable `Mono`s. #1175 by @kamisheng
- NPE when changing features on a server with derived capabilities. #1178 by @itzjb
- NPE in `addRoot`/`removeRoot` when roots `listChanged` is unset. #1179 by @Kehrlann
- Automatic-Module-Name no longer contains hyphens. #1135 by @Kehrlann
- Log instead of aggregating exceptions in `JSONRPCErrorResponse`. #1182 by @Kehrlann

## New contributors

@slachiewicz, @YousefHaggy, @kamisheng, @itzjb, @neerajbhatt and @nquinquenel
