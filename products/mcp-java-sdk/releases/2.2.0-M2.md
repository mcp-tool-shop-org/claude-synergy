# mcp-java-sdk v2.2.0-M2

## What's Changed

### ⚠️ Breaking changes

This affects the modern server (2026-07-28 preview).:

* Return a handler from `find` in modern server repositories by @chemicL in https://github.com/modelcontextprotocol/java-sdk/pull/1282

### 🚀 New features

These affect the modern server (2026-07-28 preview).:

* Enforce required client capabilities in the modern server by @chemicL in https://github.com/modelcontextprotocol/java-sdk/pull/1283
* Validate SEP-2243 `Mcp-Param` headers in the modern server by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1286
* Add `putAll(Map)` to `McpTransportContext` by @chemicL in https://github.com/modelcontextprotocol/java-sdk/pull/1288
  * `McpTransportContext` no longer has content-based `equals`/`hashCode`.
* Document the 2026-07-28 modern server preview (b8f43af6)

### 🐞 Bug fixes

* Require a numeric port in wildcard Host/Origin matching by @anzal1 in https://github.com/modelcontextprotocol/java-sdk/pull/1193
* `LoggingMessageNotification#data` accepts non-String payload by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1201
* Standardize SSE response headers by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1204
* Fix modern servlet transport Content-Type validation by @tarun-agarwal1044 in https://github.com/modelcontextprotocol/java-sdk/pull/1207
* Fix race condition in tools list filter by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1260
* Notify resources `list_changed` when removing a resource template by @subhashpolisetti in https://github.com/modelcontextprotocol/java-sdk/pull/1266

### 📦 Dependency upgrades

* Bump `com.networknt:json-schema-validator` 2.0.4 -> 2.0.8 and 3.0.6 -> 3.0.8 by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1259
* Bump `com.fasterxml.jackson.core:jackson-annotations` from 2.21 to 2.22 @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1267
* Bump `io.projectreactor:reactor-bom` from 2024.0.0 to 2024.0.18 by @dependabot[bot] in https://github.com/modelcontextprotocol/java-sdk/pull/1239
* Bump `com.fasterxml.jackson.core:jackson-databind` from 2.21.1 to 2.21.8 by @dependabot[bot] in https://github.com/modelcontextprotocol/java-sdk/pull/1233
* Bump `tools.jackson.core:jackson-databind` from 3.1.4 to 3.1.8 by @dependabot[bot] in https://github.com/modelcontextprotocol/java-sdk/pull/1238
* Bump `org.slf4j:slf4j-api` from 2.0.16 to 2.0.20 by @dependabot[bot] in https://github.com/modelcontextprotocol/java-sdk/pull/1224
