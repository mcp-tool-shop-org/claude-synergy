# mcp-java-sdk v2.2.0-M1

## Highlights
- **Modern stateless server for MCP 2026-07-28**: #1170 by @chemicL

  The first step toward the stateless Streamable HTTP paradigm. It is a new server in `io.modelcontextprotocol.modern`, independent of the legacy `McpSchema`, and it passes all 37 required 2026-07-28 conformance scenarios.
  - **No sessions**: each request is handled on its own, which suits horizontally scaled deployments.
  - **One server, sync or async**: many concepts were simplified and allow the transport to choose whether to offload blocking code or not, freeing the user to use either a synchronous or asynchronous paradigm to implement features. 
  - **Your own catalogs**: tools, resources and prompts come from repositories you implement, so per-tenant, filtered and paginated catalogs are straightforward.
  - **Stream only when it pays**: handlers return plain JSON or SSE, user code decides.
  - **Not yet supported**: a modern client, tasks and SEP-2243 custom headers.
