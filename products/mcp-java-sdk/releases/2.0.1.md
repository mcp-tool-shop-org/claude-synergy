# mcp-java-sdk v2.0.1

## What's Changed

* Upgrade conformance suite to 0.1.16, Spring AI conformance to 2.0.0 GA by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1032
* Return empty completion when no handler matches a valid ref by @jstar0 in https://github.com/modelcontextprotocol/java-sdk/pull/996
* Close response after sending error in McpStreamableServerSession#responseStream by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1041
* Fix error behavior on unregistered handlers in stateless server handler by @maff in https://github.com/modelcontextprotocol/java-sdk/pull/800
* Remove invalid WARN message for missing notification handler in stateless servers by @bperhaps in https://github.com/modelcontextprotocol/java-sdk/pull/835
* Fix SSE event classification to follow spec for missing event field by @iaJingda in https://github.com/modelcontextprotocol/java-sdk/pull/913
* fix: stop pagination on empty cursors by @nanookclaw in https://github.com/modelcontextprotocol/java-sdk/pull/954
* fix McpTransportContext.create() mutability issue and add tests by @iuliiasobolevska in https://github.com/modelcontextprotocol/java-sdk/pull/1076
* Bound HTTP server and client reads by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1102
* Bound STDIO server and client reads by @Kehrlann in https://github.com/modelcontextprotocol/java-sdk/pull/1103

## Depedency updates

* Bump json-schema-validator to 2.0.4 / 3.0.6, jackson to 2.21.1 / 3.1.4 by @joaodinissf in https://github.com/modelcontextprotocol/java-sdk/pull/1058
