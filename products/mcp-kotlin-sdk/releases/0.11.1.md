# mcp-kotlin-sdk 0.11.1

### Description

Fixes an SSE stream crash on Netty when clients connect to the Streamable HTTP GET endpoint.

### Fixed

- Fixed GET SSE stream crash on Netty in Streamable HTTP where `appendSseHeaders()` was called after response headers were already committed, causing `UnsupportedOperationException` and client retry loops by @devcrocod in [#681](https://github.com/modelcontextprotocol/kotlin-sdk/pull/681)
