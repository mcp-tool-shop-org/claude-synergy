<p>The new permissions picker in the Chat view lets you control how much autonomy the agent has. The permission level applies only to the current session. You can change it at any time during a session by selecting a different level from the permissions picker.</p>
<p>You can choose from the following permission levels:</p>
<table class="table table-striped">
<thead>
<tr>
<th>Permission level</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Default Approvals</strong></td>
<td>Uses your configured approval settings. Tools that require approval show a confirmation dialog before they run.</td>
</tr>
<tr>
<td><strong>Bypass Approvals</strong></td>
<td>Auto-approves all tool calls without showing confirmation dialogs and automatically retries on errors.</td>
</tr>
<tr>
<td><strong>Autopilot</strong> (Preview)</td>
<td>Auto-approves all tool calls, automatically retries on errors, auto-responds to questions, and the agent continues working autonomously until the task is complete.</td>
</tr>
</tbody>
</table>

<h2 id="_debug-events-snapshot" data-needslink="_debug-events-snapshot">Debug events snapshot</h2>
<p>To help you understand and troubleshoot agent behavior, you can now attach a snapshot of agent debug events as context in chat by using <code>#debugEventsSnapshot</code>. Use it to ask the agent about loaded customizations, token consumption, or to troubleshoot agent behavior.</p>
<p>You can also select the sparkle chat icon in the top-right corner of the Agent Debug panel to add the debug events snapshot as an attachment to the chat composer. Selecting the attachment opens the Agent Debug panel logs, filtered to the timestamp when the snapshot was taken.</p>
<p><img src="/assets/updates/1_111/agent-logs.png" alt="Screenshot of the option to attach debug events snapshot to chat from the Agent Debug panel." loading="lazy"></p>
<p>Learn more about <a href="https://code.visualstudio.com/docs/copilot/chat/chat-debug-view">Debugging chat interactions</a> in our documentation.</p>
<h2 id="_chat-tip-improvements" data-needslink="_chat-tip-improvements">Chat tip improvements</h2>
<p>The chat experience evolves rapidly and we want to make sure you are aware of new features and improvements. We redesigned the chat tips experience to better surface relevant tips at the right time in your chat journey.</p>
<p>Chat tips now guide you through a structured onboarding journey. Foundational tips, such as using the Plan agent and creating a custom agent are shown first. After you complete or dismiss the foundational tips, quality-of-life tips like experimental settings or generating Mermaid diagrams are shown in random order.</p>
<p><img src="/assets/updates/1_111/chat-tip-init-command.png" alt="Screenshot of the redesigned chat tips experience, showing a tip for using the init command." loading="lazy"></p>
<p>Additional chat tip improvements include:</p>
<ul>
<li>Tips are only displayed when a single chat session is visible, such as in the Welcome view or Chat view. If multiple chat editors are open, tips are hidden to reduce clutter.</li>
<li>Tips include keyboard shortcuts to help you discover relevant key bindings.</li>
<li>Tips are hidden after you act on or dismiss them for the current session.</li>
<li>We added tips for the <code>/init</code> and <code>/fork</code> slash commands. The <code>/init</code> tip helps you discover the command for initializing project configuration, and the <code>/fork</code> tip introduces manual conversation forking, which lets you branch a conversation to explore different approaches.</li>
</ul>

<h2 id="_engineering" data-needslink="_engineering">Engineering</h2>
<p>With the move to <strong>weekly Stable releases</strong>, we continue to improve our engineering processes to ship high-quality features at a faster pace.</p>
<h3 id="_test-plan-item-creation" data-needslink="_test-plan-item-creation">Test plan item creation</h3>
<p>We added a one-click experience for creating test plan items from feature request issues. This reduces the manual steps needed to set up structured testing plans for new features.</p>
<h3 id="_verification-step-generation" data-needslink="_verification-step-generation">Verification step generation</h3>
<p>As test plan items are assigned randomly to engineers, clear verification steps are crucial for efficient and effective testing. We added a button to generate verification steps on relevant issues. This helps ensure that issues have clear, structured steps for verifying fixes and features before they are closed.</p>
<h3 id="_automatic-pr-media-attachment-to-linked-issues" data-needslink="_automatic-pr-media-attachment-to-linked-issues">Automatic PR media attachment to linked issues</h3>
<p>When you merge a pull request that includes an image or GIF in its description, the media content is now automatically posted as a comment on the linked issue. This streamlines the verification process by making it easier to see the visual demonstration of a fix or feature directly on the issue.</p>
<h3 id="_chat-showcase-pipeline" data-needslink="_chat-showcase-pipeline">Chat showcase pipeline</h3>
<p>A new automated pipeline processes issues that are labeled with <code>chat-showcase</code>. When a showcase issue is identified, a corresponding chat tip issue is automatically created, making it easier to add tips for features.</p>
