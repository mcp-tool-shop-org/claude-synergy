<h2 id="_visual-studio-code-agents-preview" data-needslink="_visual-studio-code-agents-preview">Visual Studio Code Agents (Preview)</h2>
<p><strong>Visual Studio Code Agents</strong> is a new preview companion app that ships alongside VS Code Insiders, built for agent-native development.</p>
<ul>
<li>
<p><strong>Parallelize tasks across projects</strong> - Kick off agent sessions across multiple repos in parallel (each isolated in its own worktree), quickly switch context (with UI that adapts to your selection), and iterate on human and agentic reviews.</p>
</li>
<li>
<p><strong>Monitor and review</strong> - Track session progress, view diffs inline, leave feedback for agents, and create pull requests without leaving the app.</p>
</li>
<li>
<p><strong>Your customizations carry over</strong> - Custom instructions, prompt files, custom agents, MCP servers, hooks, and plugins all work in the Agents app, along with your other VS Code customizations like themes, for example.</p>
</li>
<li>
<p><strong>No extra install</strong> - The app ships alongside VS Code Insiders. Launch it from your Start menu or Applications folder in the OS, or run <strong>Chat: Open Agents Application</strong> from the Command Palette.</p>
</li>
</ul>
<p>The Agents app is a rapidly evolving preview. It's currently only available in VS Code Insiders, and we're looking forward to getting your feedback in GitHub issues.</p>
<p><img src="/assets/updates/1_115/agents-release-notes-1.webp" alt="Screenshot of the VS Code Agents app with a session and changes open." loading="lazy"></p>

<h4 id="_longrunning-script-support" data-needslink="_longrunning-script-support">Long-running script support</h4>
<p>The <code>Run Playwright Code</code> tool has improved support for long-running scripts. Scripts that take longer than five seconds to run (by default) now return a deferred result for the agent to poll.</p>
<h4 id="_fewer-duplicate-tabs" data-needslink="_fewer-duplicate-tabs">Fewer duplicate tabs</h4>
<p>Agents are now more heavily discouraged from repetitively opening browser tabs. Now, when an agent attempts to open a new tab and an available tab is already open to the same host, no new tab is opened unless an explicit flag is passed by the agent.</p>
<h3 id="_pinchtozoom-in-the-integrated-browser-macos" data-needslink="_pinchtozoom-in-the-integrated-browser-macos">Pinch-to-zoom in the integrated browser (macOS)</h3>
<p>The <a href="https://code.visualstudio.com/docs/debugtest/integrated-browser">integrated browser</a> now supports pinch-to-zoom on macOS. Use the trackpad pinch gesture to magnify web page content up to 3x.</p>
<p>Unlike the standard browser zoom (<span class="dynamic-keybinding" data-commandid="workbench.action.browser.zoomIn" data-osx="⌘=" data-win="Ctrl+=" data-linux="Ctrl+="><span class="keybinding">⌘=</span> (Windows, Linux <span class="keybinding">Ctrl+=</span>)</span> / <span class="dynamic-keybinding" data-commandid="workbench.action.browser.zoomOut" data-osx="⌘-" data-win="Ctrl+-" data-linux="Ctrl+-"><span class="keybinding">⌘-</span> (Windows, Linux <span class="keybinding">Ctrl+-</span>)</span>), pinch-to-zoom is a purely visual magnification and doesn't reflow the page layout.</p>

<h2 id="_terminal-tools-improvements" data-needslink="_terminal-tools-improvements">Terminal tools improvements</h2>
<p>This release improves the agent experience for running terminal commands in the background.</p>
<h3 id="_send-input-to-background-terminals" data-needslink="_send-input-to-background-terminals">Send input to background terminals</h3>
<p>Previously, background terminals were read-only, with only <code>get_terminal_output</code> available. This was particularly limiting when a foreground terminal timed out and moved to the background, as the agent could no longer interact with it.</p>
<p>With the new <code>send_to_terminal</code> tool, the agent can continue interacting with background terminals. For example, if an SSH session times out while waiting for a password prompt, the agent can still send the required input to complete the connection.</p>
