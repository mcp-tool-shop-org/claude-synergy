# claude-api — November 2, 2026

<ul>
<li>Long conversations and agent loops on the Messages API can now send smaller requests and get a lower time to first token with <a href="/docs/en/build-with-claude/message-threads">message threads</a>, in beta with the <code>message-threads-2026-08-12</code> beta header. The API keeps the conversation on the server, so each later request sends only the new messages. A thread expires 5 minutes after its last request and is deleted no more than 1 hour after its last use. Message threads are available on the Claude API, <a href="/docs/en/build-with-claude/claude-platform-on-aws">Claude Platform on AWS</a>, Claude Models on Google Cloud (Anthropic managed), and <a href="/docs/en/build-with-claude/claude-in-microsoft-foundry">Claude in Microsoft Foundry</a>.</li>
</ul>
