# claude-api — October 9, 2026

<ul>
<li>You can now let a Claude Managed Agents agent use <a href="/docs/en/managed-agents/multiagent-orchestration#dynamic-workflows">dynamic workflows</a>, in beta with the <code>managed-agents-2026-04-01</code> beta header. For work with many pieces, such as reviewing hundreds of documents, the agent can write a workflow. A workflow is a program that runs many agents in phases and combines their results. The server runs it in the background as a workflow run. To <a href="/docs/en/managed-agents/multiagent-orchestration#turn-on-dynamic-workflows">turn dynamic workflows on</a>, set the agent’s <code>multiagent</code> field to <code>{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}</code>. To guide the agent, tell it in its system prompt when to start a run. Follow each run through <code>workflow_run.*</code> events on the session’s event stream. See <a href="/docs/en/managed-agents/workflow-runs">Workflow runs</a>.</li>
</ul>
