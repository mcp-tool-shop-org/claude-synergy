# claude-api — October 1, 2026

<ul>
<li>We’ve added a <code>line</code> field to the <a id="_R_48gn6aqav5ut5u7ivd5urdalb_" aria-describedby="_R_c8gn6aqav5ut5u7ivd5urdalbH2_" href="/docs/en/api/models/list">Models API</a><span id="_R_c8gn6aqav5ut5u7ivd5urdalbH2_" data-find-omitted="" class="sr-only select-none">Preview with links to the API reference available — press Tab until focus enters the card, Escape to return.</span>. <code>GET /v1/models</code> and <code>GET /v1/models/{model_id}</code> now return the model line each model belongs to. Claude Opus 4.5 and Claude Opus 4.6 both report <code>opus</code>, for example. Use <code>line</code> to group models without parsing their IDs. <code>line</code> is <code>null</code> for a model that belongs to no line. See <a href="/docs/en/models/overview#using-the-models-api">Using the Models API</a>.</li>
<li><a href="/docs/en/managed-agents/dreams">Dreams</a> (research preview) now supports Claude Opus 5.5, Claude Fable 5.1, and Claude Sonnet 5.5. See <a href="/docs/en/managed-agents/dreams#feature-availability">Supported models</a>.</li>
</ul>
