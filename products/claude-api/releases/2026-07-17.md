# claude-api — July 17, 2026

<ul>
<li>The legacy <strong>Workbench</strong> (<a href="https://platform.claude.com/workbench" target="_blank" rel="noopener noreferrer">platform.claude.com/workbench</a>) in the Claude Console is being sunset with access ending on August 17, 2026. Saved prompts, variables, and evals are not supported in the updated <a href="https://platform.claude.com/playground" target="_blank" rel="noopener noreferrer">Workbench</a> in the Console. You can export any data you want to keep from the banner and under your <strong>Organizational Settings</strong>. For more, see <a href="https://support.claude.com/en/articles/8606378-how-do-i-use-the-workbench" target="_blank" rel="noopener noreferrer">How do I use the Workbench?</a> in the Claude Help Center.</li>
<li>The experimental prompt tools APIs for generating, improving, and templatizing prompts (<code>/v1/experimental/generate_prompt</code>, <code>/v1/experimental/improve_prompt</code>, and <code>/v1/experimental/templatize_prompt</code>) are being retired along with the Workbench on August 17, 2026. After removal, requests to these endpoints will return an error.</li>
</ul>
