# claude-api — June 29, 2026

<ul>
<li>We’ve removed <a href="/docs/en/build-with-claude/fast-mode">fast mode</a> for Claude Opus 4.6. Requests to <code>claude-opus-4-6</code> with <code>speed: "fast"</code> no longer run at fast speed or premium pricing: they run at standard speed, are billed at standard rates, and do not return an error. The response’s <code>usage.speed</code> field reports the speed used. To continue using fast mode, migrate to <a href="/docs/en/models/opus-4-8/overview">Claude Opus 4.8</a>. Read more in <a href="/docs/en/build-with-claude/fast-mode#supported-models">Fast mode model availability</a>.</li>
</ul>
