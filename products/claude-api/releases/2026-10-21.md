# claude-api — October 21, 2026

<ul>
<li>We’ve released API version <code>2026-10-21</code>. <a href="/docs/en/api/migration-2026-10-21">Migrating to API version 2026-10-21</a> shows how to upgrade.</li>
<li>We’ve released new versions of the <a href="/docs/en/cli-sdks-libraries/overview">client SDKs</a> and the <a href="/docs/en/cli-sdks-libraries/cli/quickstart"><code data-link-continues="after">ant</code> CLI</a> that send API version <code>2026-10-21</code> by default: Python SDK 2.0.0, TypeScript SDK 1.0.0, C# SDK 13.0.0, Go SDK 2.0.0, Java SDK 3.0.0, PHP SDK 1.0.0, Ruby SDK 2.0.0, and <code>ant</code> CLI 2.0.0. See <a href="/docs/en/api/migration-2026-10-21#upgrade">Switch to 2026-10-21</a>.</li>
<li>The new SDK and CLI versions also have breaking changes that don’t depend on the API version, and they are licensed under Apache 2.0 instead of the MIT License. See <a href="/docs/en/api/migration-2026-10-21#sdk-changes">SDK and CLI changes</a>.</li>
<li>We’ve added the <code>enforcement_status</code> and <code>enforcement_actions</code> fields to <a href="/docs/en/manage-claude/user-profiles">user profiles</a>, so you can see whether Anthropic has restricted or banned one of your end customers. See <a href="/docs/en/manage-claude/user-profiles#check-whether-anthropic-has-restricted-or-banned-a-profile">Check whether Anthropic has restricted or banned a profile</a>.</li>
</ul>
