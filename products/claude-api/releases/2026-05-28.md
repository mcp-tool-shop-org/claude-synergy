Claude Opus 4.8 supports a <a href="/docs/en/build-with-claude/context-windows">1M token context window</a> by default on the Claude API, Amazon Bedrock, Google Cloud, and Microsoft Foundry, 128k max output tokens, and the same set of tools and platform features as Claude Opus 4.7. See the <a href="/docs/en/about-claude/models/migration-guide">migration guide</a> for baseline settings, features, and migration guidance.</li>
<li>We’ve launched <a href="/docs/en/build-with-claude/mid-conversation-system-messages">mid-conversation system messages</a>. On Claude Opus 4.8, you can send <code>role: "system"</code> messages after a user turn (subject to <a href="/docs/en/build-with-claude/mid-conversation-system-messages#limitations">placement rules</a>) in the <code>messages</code> array, preserving prompt cache hits when instructions change during a long-running session. No beta header is required.</li>
<li>The <a href="/docs/en/build-with-claude/refusals-and-fallback#refusal-response"><code>stop_details</code></a> field on refusal responses is now publicly documented; it returns a <code>category</code> (<code>cyber</code>, <code>bio</code>, or <code>null</code>) and a human-readable <code>explanation</code>, so your application can route different classes of refusal to the right next step. No beta header is required.</li>
<li>On Claude Opus 4.8, the <a href="/docs/en/build-with-claude/effort">effort parameter</a> defaults to <code>high</code> across all surfaces, including Claude Code and the Messages API.</li>
<li>On Claude Opus 4.8, the minimum cacheable prompt length for <a href="/docs/en/build-with-claude/prompt-caching">prompt caching</a> is 1,024 tokens, lower than on Claude Opus 4.7.</li>
<li>With <a href="/docs/en/build-with-claude/thinking">adaptive thinking</a> enabled, Claude Opus 4.8 triggers reasoning only when a turn needs it, reducing wasted thinking tokens compared to Claude Opus 4.7 at the same effort level.</li>
<li>Claude Opus 4.8 supports <a href="/docs/en/build-with-claude/vision#high-resolution-image-support-on-claude-opus-4-7">high-resolution image input</a> (up to 2,576 pixels on the long edge), same as Claude Opus 4.7.</li>
<li><a href="/docs/en/build-with-claude/task-budgets">Task budgets</a> now support Claude Opus 4.8.</li>
<li>The <a href="/docs/en/agents-and-tools/tool-use/advisor-tool">advisor tool</a> now supports Claude Opus 4.8.</li>
<li><a href="/docs/en/agents-and-tools/tool-use/computer-use-tool">Computer use</a> now supports Claude Opus 4.8.</li>
<li><a href="/docs/en/build-with-claude/fast-mode">Fast mode</a> for Claude Opus 4.8 is available as a research preview on the Claude API only.</li>
<li>Setting the sampling parameters <code>temperature</code>, <code>top_p</code>, or <code>top_k</code> to a non-default value returns a 400 error on Claude Opus 4.8, same as on Claude Opus 4.7. See the <a href="/docs/en/about-claude/models/migration-guide">migration guide</a> for details.</li>
<li>In Claude Code, we’ve expanded Auto mode to more users for long-running tasks. See the <a href="https://code.claude.com/docs" target="_blank" rel="noopener noreferrer">Claude Code documentation</a>.</li>
<li>In Claude Code, Max plan users now default to <a href="/docs/en/build-with-claude/fast-mode">fast mode</a> on Claude Opus 4.8. See the <a href="https://code.claude.com/docs" target="_blank" rel="noopener noreferrer">Claude Code documentation</a>.</li>
<li>In Claude Code, Workflows are available as a research preview, letting you define and run multistep agentic plans. See the <a href="https://code.claude.com/docs" target="_blank" rel="noopener noreferrer">Claude Code documentation</a>.</li>
<li>We’ve deprecated <a href="/docs/en/build-with-claude/fast-mode">fast mode</a> for Claude Opus 4.6, with removal approximately 30 days after launch. Migrate to fast mode for Claude Opus 4.8 or Claude Opus 4.7. Read more in <a href="/docs/en/build-with-claude/fast-mode#supported-models">Fast mode model availability</a>.</li>
<li>For updates to claude.ai, Cowork, Claude for Microsoft 365, and other Claude apps in this release, see the <a href="https://support.claude.com/en/articles/12138966-release-notes" target="_blank" rel="noopener noreferrer">release notes for Claude Apps</a>.</li>
