# claude-api — October 23, 2026

<ul>
<li><span id="october-20-2026"></span>The <a href="/docs/en/manage-claude/claude-tag-api">Claude Tag API</a> is available in beta for Claude Enterprise organizations with the <code>experimental-claude-tag-2026-10-21</code> beta header. Its <code>/v1/organizations/claude_tag/</code> endpoints read and change <a href="https://claude.com/docs/claude-tag/overview" target="_blank" rel="noopener noreferrer">Claude Tag</a> settings on Slack channels and Slack workspaces, show which settings apply in a channel and where each comes from, and attach Access bundles. Call it with an Admin API key that your primary owner creates in claude.ai with the <code>read:claude_tag</code> or <code>write:claude_tag</code> scope. It is not available to Claude Platform (Claude Console) organizations.</li>
</ul>
