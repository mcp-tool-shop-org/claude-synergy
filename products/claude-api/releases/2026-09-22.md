# claude-api — September 22, 2026

<ul>
<li>We’ve launched <strong>Claude Opus 5.5</strong> (<code>claude-opus-5-5</code>), a model for long-running agentic coding and knowledge work. It has a <a href="/docs/en/build-with-claude/context-windows">1M token context window</a> by default, 128k max output tokens, and always-on <a href="/docs/en/build-with-claude/thinking">adaptive thinking</a>, at $4 / $20 USD per MTok (Claude Opus 5 is $5 / $25 USD). Claude Opus 5.5 is available on the Claude API, <a href="/docs/en/build-with-claude/claude-in-amazon-bedrock">Claude in Amazon Bedrock</a>, <a href="/docs/en/build-with-claude/claude-platform-on-aws">Claude Platform on AWS</a>, <a href="/docs/en/build-with-claude/claude-models-on-google-cloud/google-managed">Claude Models on Google Cloud (Google managed)</a>, and <a href="/docs/en/build-with-claude/claude-in-microsoft-foundry">Claude in Microsoft Foundry</a>. See <a href="/docs/en/models/opus-5-5/whats-new-opus-5-5">What’s new in Claude Opus 5.5</a> for capabilities, API changes, and migration guidance.</li>
<li>On Claude Opus 5.5, thinking can’t be disabled: <code>thinking: {"type": "disabled"}</code> and <code>thinking: {"type": "enabled", ...}</code> return a 400 error. Omit the <code>thinking</code> field and control thinking depth with the <a href="/docs/en/build-with-claude/effort">effort parameter</a>. <code>tool_choice</code> types <code>any</code> and <code>tool</code> also return a 400 error, as on Claude Fable 5.1; use <code>auto</code> with <a href="/docs/en/agents-and-tools/tool-use/strict-tool-use">strict tool use</a>. On the Claude API and Google Cloud, <a href="/docs/en/agents-and-tools/tool-use/computer-use-tool">computer use</a> on this model requires the <code>computer_toolset_20260801</code> toolset and the earlier <code>computer_20251124</code> tool returns a 400 error; on Amazon Bedrock, <code>computer_20251124</code> keeps working. See the <a href="/docs/en/models/opus-5-5/migration-guide#migrating-from-claude-opus-5">Claude Opus 5.5 migration guide</a>.</li>
<li><a href="/docs/en/build-with-claude/fast-mode">Fast mode</a> (research preview) is available for Claude Opus 5.5 on the Claude API.</li>
<li>Tools can now be defined inside a <a href="/docs/en/build-with-claude/mid-conversation-system-messages#define-tools-in-a-message-beta">mid-conversation system message</a>, in beta on the Claude API with the <code>inline-tools-2026-09-15</code> beta header. A <code>tool_addition</code> block can carry the tool’s full definition (<code>tool: {"type": "tool_definition", "definition": {...}}</code>), so you can add a tool, change its schema, or move a server tool to a newer version without editing <code>tools</code> or invalidating the prompt cache. The same header covers adding and removing tools by reference. With the MCP connector’s <code>mcp-client-2026-09-15</code> beta header as well, the definition can be an MCP toolset, and a response records each server’s fetched tool list in an <code>mcp_tool_listing</code> block, which pins that list when you send it back.</li>
</ul>
