# claude-api — August 26, 2026

<ul>
<li>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> session endpoints are out of beta for Cowork and Claude Code sessions. See <a href="/docs/en/manage-claude/compliance-sessions">Retrieve session transcripts</a>.</li>
<li>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> local session endpoints now also return transcripts of Claude Science sessions (<code>product_surface</code> value <code>claude_science</code>) and Claude for Microsoft 365 sessions in Excel, PowerPoint, Word, and Outlook (<code>product_surface</code> values beginning with <code>office_agents</code>), in beta for Claude Enterprise organizations, with your existing Compliance Access Key and the <code>read:compliance_user_data</code> scope. See <a href="/docs/en/manage-claude/compliance-sessions#retrieve-local-sessions">Sessions on users’ machines</a>.</li>
<li>The <a href="/docs/en/manage-claude/admin-api">Admin API</a> is now available in the <code>ant</code> CLI and the Python, TypeScript, C#, Go, Java, PHP, and Ruby SDKs under <code>client.beta.organization</code>. They cover organization info, members, invites, workspaces and workspace members, API keys, rate limits, service accounts, workload identity federation issuers and rules, and customer-managed encryption keys. Usage and cost reports and the Claude Enterprise user-management and analytics endpoints remain curl-only. The CLI and SDKs read an Admin API key from <code>ANTHROPIC_API_KEY</code> or an <code>org:admin</code> OAuth token from <code>ANTHROPIC_AUTH_TOKEN</code>.</li>
</ul>
