# claude-api — October 29, 2026

<ul>
<li>We’ve launched the <a href="/docs/en/manage-claude/usage-cost-analytics-api">Usage and Cost Analytics API</a> in beta with the <code>analytics-usage-cost-2026-08-24</code> beta header. Its <code>/v1/organizations/analytics/usage</code> and <code>/v1/organizations/analytics/cost</code> endpoints report token usage and cost for Claude Console and Claude Enterprise organizations. You can filter and group results by dimensions such as model, workspace, API key, and the user or service account behind each request.</li>
<li>The <a href="/docs/en/manage-claude/usage-cost-api">Usage and Cost API</a> is now a legacy API, and so are the <code>usage_report</code>, <code>cost_report</code>, <code>user_usage_report</code>, and <code>user_cost_report</code> endpoints of the <a href="/docs/en/manage-claude/analytics-api">Claude Enterprise Analytics API</a>. All of them remain supported. To move an existing integration, see <a href="/docs/en/manage-claude/usage-cost-analytics-api#migrate-from-usage-cost-api">Migrate from the Usage and Cost API</a> or <a href="/docs/en/manage-claude/usage-cost-analytics-api#migrate-from-enterprise-analytics-reports">Migrate from the Claude Enterprise usage and cost reports</a>.</li>
</ul>
