# claude-api — August 20, 2026

<ul>
<li>We’ve released <strong>v1.0 of the <a href="/docs/en/cli-sdks-libraries/sdks/python">Python SDK</a></strong>. The SDK’s HTTP layer moves from <code>httpx</code> to <a href="https://httpx2.pydantic.dev" target="_blank" rel="noopener noreferrer">httpx2</a>, a maintained, API-compatible fork: build custom <code>http_client</code>, <code>Timeout</code>, and transport objects from <code>httpx2</code> (the <code>DefaultHttpxClient</code> helpers are unchanged), and call <code>httpx2.alias_httpx()</code> at startup if you rely on tracing or mocking libraries that patch <code>httpx</code>. v1.0 requires Python 3.10 or later and removes long-deprecated surface, including the legacy Text Completions API, the <code>temperature</code>, <code>top_p</code>, and <code>top_k</code> parameters on Messages methods, and the tool runner’s client-side <code>compaction_control</code>. On the async client, <code>.with_raw_response</code> results now need <code>await response.parse()</code>, and <code>AnthropicBedrock</code> now raises an error when no AWS region is configured instead of defaulting to <code>us-east-1</code>. See the <a href="https://github.com/anthropics/anthropic-sdk-python/blob/main/MIGRATION.md" target="_blank" rel="noopener noreferrer">v1 migration guide</a> for every change with before-and-after snippets.</li>
<li>The <a href="/docs/en/agents-and-tools/tool-use/computer-use-tool">computer use</a> and <a href="/docs/en/agents-and-tools/tool-use/browser-use-tool">browser use</a> toolsets (<code>computer_toolset_20260801</code> and <code>browser_toolset_20260801</code>) are now available on <a href="/docs/en/build-with-claude/claude-models-on-google-cloud/google-managed">Google Cloud</a> for Claude Fable 5, Claude Mythos 5, Claude Opus 5, Claude Sonnet 5, and Claude Opus 4.8. Requests use the same <code>tools</code> entries as on the Claude API.</li>
</ul>
