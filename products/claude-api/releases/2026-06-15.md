# claude-api — June 15, 2026

<ul>
<li>We’ve retired the Claude Sonnet 4 model (<code>claude-sonnet-4-20250514</code>) and the Claude Opus 4 model (<code>claude-opus-4-20250514</code>). All requests to these models on the Claude API will now return an error. We recommend upgrading to <a href="/docs/en/models/overview#latest-models-comparison">Claude Sonnet 4.6</a> and <a href="/docs/en/models/opus-4-8/overview">Claude Opus 4.8</a> respectively. Researchers can request ongoing access through the <a href="https://support.claude.com/en/articles/9125743-what-is-the-external-researcher-access-program" target="_blank" rel="noopener noreferrer">External Researcher Access Program</a>.</li>
</ul>
