# claude-api — September 30, 2026

<ul>
<li>In Python SDK 1.10.0, TypeScript SDK 0.130.0, C# SDK 12.52.0, Go SDK 1.77.0, Java SDK 2.67.0, PHP SDK 0.53.0, Ruby SDK 1.75.0, and version 1.37.0 of the <code>ant</code> CLI, the <a href="/docs/en/manage-claude/admin-api">Admin API</a> methods for organization info, members, invites, workspaces, API keys, rate limits, service accounts, workload identity federation, customer-managed encryption keys, and compliance settings are out of beta: call them under <code>client.organization</code> and <code>ant organization</code>. These releases also keep <code>client.beta.organization</code> and <code>ant beta:organization</code>.</li>
<li>We announced the deprecation of the Claude Sonnet 4.5 model (<code>claude-sonnet-4-5-20250929</code>), with retirement on the Claude API scheduled for November 30, 2026. We recommend migrating to <a href="/docs/en/models/sonnet-5-5/migration-guide#migrating-from-sonnet-45">Claude Sonnet 5.5</a>. Read more in <a href="/docs/en/about-claude/model-deprecations">Model deprecations</a>.</li>
</ul>
