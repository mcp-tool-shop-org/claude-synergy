# claude-api — July 22, 2026

<ul>
<li>You can now set an <code>effort</code> level on a Claude Managed Agents agent’s model configuration. Pass <code>effort</code> inside the <code>model</code> object when you <a href="/docs/en/managed-agents/agent-setup#create-an-agent">create the agent</a>. See <a href="/docs/en/build-with-claude/effort#effort-levels">Effort levels</a> for what each level does.</li>
<li>Webhooks for Claude Managed Agents now cover the environment and memory store lifecycle: four <code>environment.*</code> event types and three <code>memory_store.*</code> event types. You can react to environment and memory store lifecycle changes without polling. See the Environment events and Memory store events tabs in <a href="/docs/en/managed-agents/webhooks#supported-event-types">Supported event types</a>.</li>
<li>When creating a Claude Managed Agents session, you can now <a href="/docs/en/managed-agents/sessions#seed-the-session-with-initial-events">seed it with initial events</a>. Pass <code>initial_events</code> on <code>POST /v1/sessions</code> with up to 50 <code>user.message</code> and <code>user.define_outcome</code> events. A non-empty list starts the agent loop in the same call, so you don’t need a separate send-events request to start work.</li>
<li>The <code>version</code> field is now optional when <a href="/docs/en/managed-agents/agent-setup#update-an-agent">updating a Claude Managed Agents agent</a>. Supply it for optimistic concurrency (a mismatch returns a 409 error), or omit it to apply the update unconditionally. See <a href="/docs/en/managed-agents/agent-setup#update-semantics">Update semantics</a>.</li>
<li>Claude Managed Agents session thread event streams now support <a href="/docs/en/managed-agents/event-deltas">event deltas</a>. <code>GET /v1/sessions/{session_id}/threads/{thread_id}/stream</code> accepts the same <code>event_deltas[]</code> query parameter as the session-level stream, so you can preview a subagent’s text as the model generates it. A connection previews only the thread it’s reading. See <a href="/docs/en/managed-agents/event-deltas#preview-session-thread-events">Preview session thread events</a>.</li>
</ul>
