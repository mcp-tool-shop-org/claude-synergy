# claude-api — September 24, 2026

<ul>
<li>We’re resuming billing for refusals that arrive before any output when <code>stop_details.category</code> is <code>"bio"</code>, <code>"frontier_llm"</code>, or <code>"reasoning_extraction"</code>, the categories where we measure low volumes of false positives. Mid-stream refusals were already billed. Refusals billed under this change are charged like any other request, at the rates of the model that ran it. Refusals before any output in other categories are still not billed, and fallback credit is unchanged. This change applies on all platforms. See <a href="/docs/en/build-with-claude/refusals-and-fallback#how-refusals-are-billed">How refusals are billed</a>.</li>
<li>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> local session endpoints are out of beta for Claude for Microsoft 365 sessions in Excel, PowerPoint, Word, and Outlook (<code>product_surface</code> values beginning with <code>office_agents</code>). See <a href="/docs/en/manage-claude/compliance-sessions#retrieve-local-sessions">Sessions on users’ machines</a>.</li>
<li>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> <a href="/docs/en/manage-claude/compliance-activity-feed">Activity Feed</a> no longer returns file names, project document names, or artifact titles. The <code>filename</code> and <code>title</code> fields on file, project document, and artifact activities are now always empty or omitted, including on activities recorded before this change. To look up a name or title by the ID on the activity, use a Compliance Access Key with the <code>read:compliance_user_data</code> scope. See <a href="/docs/en/manage-claude/compliance-activity-feed#understand-the-activity-object">Understand the Activity object</a>.</li>
</ul>
