# claude-api — June 18, 2026

<ul>
<li>The Python, TypeScript, Go, Java, Ruby, PHP, and C# SDKs now include support for <code>code_execution_20260120</code>, the <a href="/docs/en/agents-and-tools/tool-use/code-execution-tool">code execution tool</a> version that adds REPL state persistence and is the minimum version for <a href="/docs/en/agents-and-tools/tool-use/programmatic-tool-calling">programmatic tool calling</a>. To adopt it, set the tool’s <code>type</code> to <code>code_execution_20260120</code>; no beta header is required. It’s available on Claude Fable 5, Claude Mythos 5, Claude Opus 4.5 and newer, and Claude Sonnet 4.5 and newer; see the code execution tool’s <a href="/docs/en/agents-and-tools/tool-use/code-execution-tool#availability-feature-support">API support</a> section.</li>
</ul>
