# claude-api — November 4, 2026

<ul class="docs-public-part">
<li id="sdk-error-codes">We’ve added <a href="/docs/en/api/errors#error-codes">error codes</a> to the SDK so you can handle one cause of an error without parsing the response body. Each API error now carries the API’s error code, message, and details, and each error code has its own exception class (in Go, a constant). To use error codes, update to the <a href="/docs/en/cli-sdks-libraries/overview#latest-versions">latest version of the SDK</a>. See <a href="/docs/en/api/handle-errors">Handle errors</a>.</li>
</ul>
