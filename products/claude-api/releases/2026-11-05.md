# claude-api — November 5, 2026

<ul class="docs-public-part">
<li id="security-posture">The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> now includes Security posture data, in beta for Claude Enterprise organizations. The <a href="/docs/en/manage-claude/compliance-activity-feed">Activity Feed</a> records changes to attestations on the <strong>Security posture</strong> page in claude.ai <strong>Organization settings</strong>. The <code>GET /v1/compliance/organizations/{organization_id}/security_posture</code> endpoint returns an organization’s current Security posture results. See <a href="/docs/en/manage-claude/compliance-security-posture/overview">Security posture in the Compliance API</a>.</li>
<li id="ip-allowlisting">You can now set up an IP allowlist for your organization in the Claude Console, in beta. Requests to covered services from addresses not on your list are refused, which limits where a leaked API key can be used. Add IPv4 and IPv6 addresses or CIDR ranges, up to 1,000 per organization. See <a href="/docs/en/manage-claude/ip-allowlist">IP allowlisting</a> for what’s covered and how to set it up.</li>
<li id="admin-api-sign-out">You can now sign a member of your Claude Enterprise (claude.ai) organization out of Claude everywhere with the Admin API. This capability is in beta. See the <a href="/docs/en/api/beta/organization">Admin API reference</a>. The member stays in the organization and can sign in again. See <a href="/docs/en/manage-claude/user-management#sign-a-member-out-everywhere">Sign a member out everywhere</a> for the beta header and what the request doesn’t end.</li>

</ul>
