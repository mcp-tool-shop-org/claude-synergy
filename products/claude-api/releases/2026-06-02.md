# claude-api — June 2, 2026

<ul>
<li>The <a href="/docs/en/agents-and-tools/tool-use/advisor-tool">advisor tool</a> now supports a <code>max_tokens</code> parameter to cap the advisor model’s output for each call, reducing latency and output token cost for workloads that don’t need full-length advisor responses. Set <code>tools[].max_tokens</code> on the advisor tool definition; see <a href="/docs/en/agents-and-tools/tool-use/advisor-tool#capping-advisor-output">Capping advisor output</a>.</li>
<li>On the Claude API, you are no longer billed for a request when it returns <code>stop_reason: "refusal"</code> without Claude having generated any output. See <a href="/docs/en/test-and-evaluate/strengthen-guardrails/handle-streaming-refusals">Streaming refusals</a> for detecting and handling refusals.</li>
</ul>
