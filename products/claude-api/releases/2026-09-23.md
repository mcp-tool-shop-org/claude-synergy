# claude-api — September 23, 2026

<ul>
<li><a href="/docs/en/build-with-claude/cache-diagnostics">Cache diagnostics</a> is out of beta on the Claude API and no longer requires the <code>cache-diagnosis-2026-04-07</code> beta header. Include the <code>diagnostics</code> object on a Messages request to opt in; requests that still send the header work as before. Responses from <code>POST /v1/messages</code> now always include the <code>diagnostics</code> field, which is <code>null</code> when the request did not include the <code>diagnostics</code> object.</li>
</ul>
