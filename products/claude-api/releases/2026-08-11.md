# claude-api — August 11, 2026

<ul>
<li>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> now returns transcripts of Cowork and Claude Code sessions that run on your users’ machines, in beta for Claude Enterprise organizations. <code>GET /v1/compliance/apps/sessions/local</code> lists sessions across your organization, <code>GET /v1/compliance/apps/sessions/local/{session_id}</code> retrieves one session’s metadata, and <code>GET /v1/compliance/apps/sessions/local/{session_id}/messages</code> returns its transcript, all with your existing Compliance Access Key and the <code>read:compliance_user_data</code> scope. See <a href="/docs/en/manage-claude/compliance-sessions#retrieve-local-sessions">Sessions on users’ machines</a>.</li>
<li>We’ve added the <code>anthropic-workspace-id</code> response header to the Claude API. It carries the <code>wrkspc_</code>-prefixed ID of the workspace that the request’s API key or access token resolved to, including your organization’s Default Workspace. See <a href="/docs/en/manage-claude/workspaces#identify-the-workspace-behind-an-api-response">Identify the workspace behind an API response</a>.</li>
</ul>
