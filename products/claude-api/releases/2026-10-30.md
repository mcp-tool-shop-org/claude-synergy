# claude-api — October 30, 2026

<ul>
<li>We’ve deprecated <a href="/docs/en/build-with-claude/fast-mode">fast mode</a> for Claude Opus 4.8, with removal on November 30, 2026. After removal, requests to <code>claude-opus-4-8</code> with <code>speed: "fast"</code> will return an error. To continue using fast mode, migrate to <a href="/docs/en/models/opus-5-5/migration-guide#migrating-from-claude-opus-4-8">Claude Opus 5.5</a>. Read more in <a href="/docs/en/build-with-claude/fast-mode#supported-models">Fast mode model availability</a>.</li>
</ul>
