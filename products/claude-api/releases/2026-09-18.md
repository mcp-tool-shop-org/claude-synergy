# claude-api — September 18, 2026

<ul>
<li>For <a href="/docs/en/build-with-claude/cache-diagnostics">cache diagnostics</a>, a response to a request that sends the <code>cache-diagnosis-2026-04-07</code> beta header now always includes the <code>diagnostics</code> field. The field is <code>null</code> when the request did not include the <code>diagnostics</code> object. Previously the field was omitted in that case.</li>
<li>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> local session endpoints now also return transcripts of Claude in Chrome sessions (<code>product_surface</code> value <code>claude_in_chrome</code>), in beta for Claude Enterprise organizations, with your existing Compliance Access Key and the <code>read:compliance_user_data</code> scope. See <a href="/docs/en/manage-claude/compliance-sessions#retrieve-local-sessions">Sessions on users’ machines</a>.</li>
</ul>
