# claude-api — October 15, 2026

<ul>
<li>We’ve added <code>capabilities.thinking.types.between_tools</code> to the <a id="_R_4ggg6aqav5ut5u7ivd5urdalb_" aria-describedby="_R_cggg6aqav5ut5u7ivd5urdalbH2_" href="/docs/en/api/models/list">Models API</a><span id="_R_cggg6aqav5ut5u7ivd5urdalbH2_" data-find-omitted="" class="sr-only select-none">Preview with links to the API reference available — press Tab until focus enters the card, Escape to return.</span>. <code>GET /v1/models</code> and <code>GET /v1/models/{model_id}</code> now report whether each model accepts <code>thinking: {type: "between_tools"}</code>, which turns off up-front thinking. See <a href="/docs/en/models/overview#using-the-models-api">Using the Models API</a>.</li>
<li><span id="october-19-2026-3"></span>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> now returns the text each organization member saved as <strong>Instructions for Claude</strong> in claude.ai and as <strong>Global instructions</strong> in Cowork, in beta for Claude Enterprise organizations. Call <code>GET /v1/compliance/organizations/{org_uuid}/user_preferences</code> with your existing Compliance Access Key and the <code>read:compliance_user_data</code> scope. See <a href="/docs/en/manage-claude/compliance-org-data#list-user-preferences">List user preferences</a>.</li>
<li><span id="october-15-2026-4"></span><a href="/docs/en/build-with-claude/fast-mode">Fast mode</a> is out of research preview for Claude Opus 5.5, and you no longer need to request access. Requests to Claude Opus 5.5 no longer require the <code>fast-mode-2026-02-01</code> beta header, and requests that still send it keep working. Claude Opus 5.5 now has a default fast mode rate limit in the Start, Build, and Scale usage tiers. Fast mode for Claude Opus 5 and Claude Opus 4.8 remains in research preview. Keep sending the beta header with fast mode requests to those models.</li>
<li><span id="october-15-2026-3"></span><a href="/docs/en/build-with-claude/fast-mode">Fast mode</a> for Claude Opus 5.5 is now available on <a href="/docs/en/build-with-claude/claude-in-microsoft-foundry">Claude in Microsoft Foundry</a> for deployments hosted on Azure.</li>
</ul>
