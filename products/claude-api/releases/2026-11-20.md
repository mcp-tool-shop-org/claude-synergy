# claude-api — November 20, 2026

<ul class="docs-public-part">
<li id="analytics-api-chat-session-counting">The <a href="/docs/en/manage-claude/analytics-api">Claude Enterprise Analytics API</a> has a new rule for when a chat in <a href="/docs/en/manage-claude/analytics-api#how-metrics-are-defined">Chat and Cowork unified</a> counts as a session.<!-- -->
<ul>
<li><strong>New rule:</strong> A session starts the first time on a UTC day that Claude successfully runs a Bash command, creates a file, or edits a file in the chat. It ends when that day ends.</li>
<li><strong>Previous rule:</strong> A chat counted as a session after it moved into a Cowork cloud session (a sandbox where Claude runs code), including on later days. Uploading some types of files could cause that move.</li>
<li><strong>Rollout:</strong> The change reaches chats gradually, and existing chats can change later than new ones. Until then, a chat follows the previous rule. Activity from before then is not recounted. The API does not show which rule a chat follows.</li>
</ul>
</li>
<li>In <a id="_R_h4g2uaqav5ut5u7ivd5urdalb_" aria-describedby="_R_1h4g2uaqav5ut5u7ivd5urdalbH2_" href="/docs/en/api/beta/organization/analytics/users/list">List User Activity</a><span id="_R_1h4g2uaqav5ut5u7ivd5urdalbH2_" data-find-omitted="" class="sr-only select-none">Preview with links to the API reference available — press Tab until focus enters the card, Escape to return.</span>, these counts can change. <code>chat</code> and <code>sessions</code> are the objects in <code>chat_cowork_unified_metrics</code>.<!-- -->
<ul>
<li><strong>Sessions:</strong> <code>sessions.distinct_session_count</code> can be higher, or lower for some users.</li>
<li><strong>Messages:</strong> They count in <code>chat</code> before the session starts and in <code>sessions</code> after. <code>message_count</code> can be higher or lower in each.</li>
<li><strong>Chats:</strong> <code>chat.distinct_conversation_count</code> can be higher. A chat counts there on each day that it gets a message, even one that counts in <code>sessions</code>.</li>
<li><strong>Tool actions and file edits:</strong> They count in <code>sessions</code> during the session. <code>action_count</code> and <code>file_edit_count</code> can be higher or lower.</li>
<li><strong>Connectors:</strong> In most chats, <code>connectors_used_count</code> and <code>distinct_connectors_used_count</code> split the same way as messages. Added up across both objects, each can be higher or lower.</li>
<li><strong>Skills and plugins:</strong> Their use counts in <code>sessions</code>, even on a day with no session.</li>
<li><strong>Artifacts:</strong> Counts can move between <code>chat</code> and <code>sessions</code>.</li>
</ul>
</li>
<li>For chats that the change reached, the API does not get the names of some skills and plugins that Anthropic did not make, such as your own.<!-- -->
<ul>
<li><strong>List User Activity:</strong> <code>distinct_skills_used_count</code> can leave out these skills. Added up across both objects, it can be lower.</li>
<li><strong><a id="_R_4hhmg2uaqav5ut5u7ivd5urdalb_" aria-describedby="_R_chhmg2uaqav5ut5u7ivd5urdalbH2_" href="/docs/en/api/beta/organization/analytics/skills/list">Get Skill Usage</a><span id="_R_chhmg2uaqav5ut5u7ivd5urdalbH2_" data-find-omitted="" class="sr-only select-none">Preview with links to the API reference available — press Tab until focus enters the card, Escape to return.</span>:</strong> Spend for these skills can leave out these chats. <code>estimated_overage_spend</code> can be lower, and <code>attributed_list_price</code> can be lower or <code>null</code>.</li>
<li><strong><a id="_R_29pmg2uaqav5ut5u7ivd5urdalb_" aria-describedby="_R_69pmg2uaqav5ut5u7ivd5urdalbH2_" href="/docs/en/api/beta/organization/analytics/plugins/list">Get Plugin Usage</a><span id="_R_69pmg2uaqav5ut5u7ivd5urdalbH2_" data-find-omitted="" class="sr-only select-none">Preview with links to the API reference available — press Tab until focus enters the card, Escape to return.</span>:</strong> These plugins can appear under the <code>plugin_name</code> value <code>third-party</code>.</li>
</ul>
</li>
<li>In <a id="_R_98g2uaqav5ut5u7ivd5urdalb_" aria-describedby="_R_p8g2uaqav5ut5u7ivd5urdalbH2_" href="/docs/en/api/beta/organization/analytics/connectors/list">Get Connector Usage</a><span id="_R_p8g2uaqav5ut5u7ivd5urdalbH2_" data-find-omitted="" class="sr-only select-none">Preview with links to the API reference available — press Tab until focus enters the card, Escape to return.</span>, <code>individual_auth_distinct_user_count</code> and <code>managed_auth_distinct_user_count</code> can leave out some users of chats that the change reached, so they can be lower.</li>
<li>Other counts from the connector, skill, and plugin usage endpoints can be higher or lower.</li>
</ul>
