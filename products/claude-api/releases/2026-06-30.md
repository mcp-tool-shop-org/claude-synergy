# claude-api — June 30, 2026

<ul>
<li>We’ve launched <strong>Claude Sonnet 5</strong> (<code>claude-sonnet-5</code>), the next generation of our Sonnet model family, at introductory pricing of $2 / $10 USD per MTok (made the standard price on August 10, 2026). Claude Sonnet 5 supports a <a href="/docs/en/build-with-claude/context-windows">1M token context window</a>, 128k max output tokens, and the same set of tools and platform features as Claude Sonnet 4.6, except <a href="/docs/en/api/service-tiers#supported-models">Priority Tier</a>, which is not available on Claude Sonnet 5. Three behavior changes apply when migrating: <a href="/docs/en/build-with-claude/thinking">adaptive thinking</a> is now on by default; manual extended thinking (<code>thinking: {type: "enabled", budget_tokens: N}</code>) is removed and returns a 400 error (it was deprecated on Sonnet 4.6); and setting sampling parameters (<code>temperature</code>, <code>top_p</code>, <code>top_k</code>) to non-default values returns a 400 error. Claude Sonnet 5 also uses a new tokenizer that produces approximately 30% more tokens for the same text. The exact increase depends on the content and workload shape. See <a href="/docs/en/models/sonnet-5/overview">Claude Sonnet 5</a> for details. For behavioral differences and model-specific prompting patterns, see <a href="/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5">Prompting Claude Sonnet 5</a>.</li>
<li>Claude Managed Agents session event streams now support <a href="/docs/en/managed-agents/event-deltas">event deltas</a>. Opt in with the <code>event_deltas[]</code> query parameter on <code>GET /v1/sessions/{session_id}/events/stream</code>. The <code>event_start</code> and <code>event_delta</code> events preview an agent message’s text as it’s generated, before the complete <code>agent.message</code> event arrives.</li>
<li><a href="/docs/en/managed-agents/session-operations#listing-sessions">Listing sessions</a> for Claude Managed Agents now supports backward pagination. <code>GET /v1/sessions</code> returns a <code>prev_page</code> cursor alongside <code>next_page</code>; pass it as the <code>page</code> parameter to return to the previous page. See <a href="/docs/en/api/overview#pagination">Pagination</a>.</li>
<li>When creating a Claude Managed Agents session, you can now <a href="/docs/en/managed-agents/sessions#override-agent-configuration-for-a-session">override the agent’s configuration for that session</a>. Pass <code>agent</code> with <code>type: "agent_with_overrides"</code> to replace the model, system prompt, tools, MCP servers, or skills for a single session. The agent itself is unchanged.</li>
<li>Claude Managed Agents vaults now support an <code>injection_location</code> setting on <a href="/docs/en/managed-agents/vaults#add-a-credential">environment variable credentials</a> (the Environment variable tab). It controls whether the credential’s value is substituted, at egress, into the agent’s outbound request headers, the request body, or both.</li>
<li>Webhooks for Claude Managed Agents now cover the agent, deployment, and deployment run lifecycle. You can react to a newly published agent version, a paused deployment, or a failed scheduled run without polling. See the Agent events, Deployment events, and Deployment run events tabs in <a href="/docs/en/managed-agents/webhooks#supported-event-types">Supported event types</a>.</li>
</ul>
