# claude-api — July 14, 2026

<ul>
<li>You can now manage the people in your <strong>Claude Enterprise</strong> (claude.ai) organization with the Admin API (see the <a href="/docs/en/api/beta/organization">Admin API reference</a>), in beta for all Claude Enterprise organizations: list members and look them up by email address, change a member’s role, remove members, send and withdraw invites, manage groups and their membership, and read custom roles. Group and custom-role requests require the <code>anthropic-beta: ce-user-management-2026-07-13</code> beta header; member and invite requests take no beta header. An Admin API key with the <code>read:org_audit</code> scope can also call every user-management <code>GET</code> endpoint. See <a href="/docs/en/manage-claude/user-management">User management</a>.</li>
</ul>
