# claude-api — June 11, 2026

<ul>
<li>The <a href="/docs/en/agents-and-tools/tool-use/code-execution-tool">code execution tool</a> now supports <code>code_execution_20260521</code>, which discloses the 90-second per-cell execution time limit in the tool description so Claude can budget long-running cells. No beta header is required.</li>
<li>The <a href="/docs/en/agents-and-tools/tool-use/web-search-tool">web search tool</a> and <a href="/docs/en/agents-and-tools/tool-use/web-fetch-tool">web fetch tool</a> now support <code>web_search_20260318</code> and <code>web_fetch_20260318</code>, adding a <code>response_inclusion</code> parameter to drop consumed result blocks from the API response for agentic workflows. No beta header is required.</li>
</ul>
