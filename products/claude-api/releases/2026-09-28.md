# claude-api — September 28, 2026

<ul>
<li>We’ve launched <strong>Claude Sonnet 5.5</strong> (<code>claude-sonnet-5-5</code>). It’s available on the Claude API, <a href="/docs/en/build-with-claude/claude-in-amazon-bedrock">Claude in Amazon Bedrock</a>, <a href="/docs/en/build-with-claude/claude-platform-on-aws">Claude Platform on AWS</a>, <a href="/docs/en/build-with-claude/claude-models-on-google-cloud/google-managed">Claude Models on Google Cloud (Google managed)</a>, and <a href="/docs/en/build-with-claude/claude-in-microsoft-foundry">Claude in Microsoft Foundry</a>. For its context window, output limits, and prices, see the <a href="/docs/en/models/sonnet-5-5/overview">Claude Sonnet 5.5 model page</a>.</li>
<li>Code written for Claude Sonnet 5 can break on Claude Sonnet 5.5 in five ways. To turn off up-front thinking, send <code>thinking: {"type": "between_tools"}</code> instead of <code>"disabled"</code>, at <code>high</code> effort or below. Forced tool use (<code>tool_choice</code> types <code>any</code> and <code>tool</code>) returns a 400 error. Thinking blocks are tied to the model and the conversation. On the Claude API and Google Cloud, the earlier <code>computer_20251124</code> computer use tool isn’t accepted. The advisor tool rejects Claude Opus 4.8, Claude Opus 4.7, and Claude Sonnet 5 as advisors. See <a href="/docs/en/models/sonnet-5-5/whats-new-sonnet-5-5">What’s new in Claude Sonnet 5.5</a> for each change and the <a href="/docs/en/models/sonnet-5-5/migration-guide">Claude Sonnet 5.5 migration guide</a> for before-and-after requests. For model-specific prompting patterns, see <a href="/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5-5">Prompting Claude Sonnet 5.5</a>.</li>
<li>Thinking blocks that Claude Sonnet 5.5 produces work only in the account that produced them, or in an account linked to it. When another account sends one of these blocks, the API drops the block before the model sees it, and the request succeeds. Blocks from earlier models aren’t affected. See <a href="/docs/en/build-with-claude/preserved-thinking#account-bound-thinking">Thinking blocks stay with the account that produced them</a>.</li>
</ul>
