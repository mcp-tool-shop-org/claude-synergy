# claude-api — September 3, 2026

<ul>
<li>Version 1.30.0 of the <code>ant</code> CLI adds <code>ant apply</code>, which creates and updates agents, environments, skills, memory stores, and deployments from files in your repository. Describe each resource in a file, run <code>ant apply</code>, and approve the plan it prints. Commit the <code>claude-lock.json</code> lockfile it writes so that later runs, on your machine or in CI, update the same resources instead of creating new ones. See <a href="/docs/en/cli-sdks-libraries/cli/apply">Manage resources as code with ant apply</a>.</li>
<li><a href="/docs/en/build-with-claude/effort#change-effort-mid-conversation-beta">Per-message effort</a> changes, in beta, are also available on <a href="/docs/en/build-with-claude/claude-models-on-google-cloud/google-managed">Google Cloud</a> for Claude Fable 5.1, Claude Mythos 5.1, and Claude Opus 5, with the same <code>mid-conversation-output-config-2026-07-01</code> beta header.</li>
</ul>
