# claude-api — July 24, 2026

<ul>
<li>We’ve launched <strong>Claude Opus 5</strong> (<code>claude-opus-5</code>), a step-change improvement over Claude Opus 4.8. Claude Opus 5 supports a <a href="/docs/en/build-with-claude/context-windows">1M token context window</a> (both the default and the maximum), 128k max output tokens, and <a href="/docs/en/build-with-claude/thinking">thinking</a> on by default, at $5 / $25 USD per MTok, the same pricing as Claude Opus 4.8. It’s available on the Claude API, <a href="/docs/en/build-with-claude/claude-in-amazon-bedrock">Claude in Amazon Bedrock</a>, <a href="/docs/en/build-with-claude/claude-platform-on-aws">Claude Platform on AWS</a>, <a href="/docs/en/build-with-claude/claude-models-on-google-cloud/google-managed">Claude Models on Google Cloud (Google managed)</a>, and <a href="/docs/en/build-with-claude/claude-in-microsoft-foundry">Claude in Microsoft Foundry</a>. See <a href="/docs/en/models/opus-5/overview">Claude Opus 5</a> and the <a href="/docs/en/models/overview">models overview</a> for complete specs.</li>
<li>On Claude Opus 5, disabling thinking is allowed only at effort <code>high</code> or below: <code>thinking: {"type": "disabled"}</code> with effort <code>xhigh</code> or <code>max</code> returns a 400 error, a breaking change from Claude Opus 4.8. See <a href="/docs/en/build-with-claude/effort#effort-with-thinking">Effort with thinking</a>.</li>
<li><a href="/docs/en/build-with-claude/effort">Effort</a> is the primary control for steering Claude Opus 5: the model supports the full ladder (<code>low</code>, <code>medium</code>, <code>high</code>, <code>xhigh</code>, <code>max</code>), with <code>max</code> for capability-critical work.</li>
<li>Mid-conversation tool changes are now in beta on Claude Fable 5, Claude Mythos 5, Claude Opus 4.8, and Claude Opus 5: add or remove tools between turns of a conversation while preserving the prompt cache. Include the <code>mid-conversation-tool-changes-2026-07-01</code> beta header in your requests.</li>
<li>The <code>fallbacks</code> parameter now supports a <code>"default"</code> mode, which applies Anthropic’s recommended fallback models by refusal category. Server-side fallback is in beta, and the <code>"default"</code> mode requires the <code>server-side-fallback-2026-07-01</code> beta header. See <a href="/docs/en/build-with-claude/refusals-and-fallback">Refusals and fallback</a>.</li>
<li>We’ve removed <a href="/docs/en/build-with-claude/fast-mode">fast mode</a> for Claude Opus 4.7. Requests to <code>claude-opus-4-7</code> with <code>speed: "fast"</code> now return an error; unlike Claude Opus 4.6, they do not fall back to standard speed. Claude Opus 4.7 itself remains available at standard speed. To continue using fast mode, migrate to <a href="/docs/en/models/opus-5/overview">Claude Opus 5</a> or Claude Opus 4.8. Read more in <a href="/docs/en/build-with-claude/fast-mode#supported-models">Fast mode model availability</a>.</li>
</ul>
