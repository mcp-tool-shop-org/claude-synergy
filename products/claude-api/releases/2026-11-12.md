# claude-api — November 12, 2026

<ul>
<li id="self-hosted-managed-agents">We’ve launched <a href="/docs/en/managed-agents/self-hosted">self-hosted Claude Managed Agents</a>. You run the whole Managed Agents service, not only <a href="/docs/en/managed-agents/self-hosted-sandboxes">self-hosted sandboxes</a>, on your own infrastructure, and you store agents, sessions, and session history there. The server sends model requests to the provider that you choose, which is Anthropic by default. To request access, contact your Anthropic account team.</li>
