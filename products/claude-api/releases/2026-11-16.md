# claude-api — November 16, 2026

<ul class="docs-public-part">
<li id="text-watermark-claude-opus-4-6-and-4-5-models">Text generated by Claude Opus 4.6, Claude Opus 4.5, Claude Sonnet 4.5, and Claude Haiku 4.5 carries Anthropic’s text watermark on supported platforms. <a href="https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content" target="_blank" rel="noopener noreferrer">How Claude marks AI-generated content</a> lists those platforms. If a request to one of these models sets <code>temperature</code>, <code>top_p</code>, or <code>top_k</code> to a non-default value, the text might not carry the watermark. See <a href="/docs/en/build-with-claude/text-watermark">Text watermark</a>.</li>
<li id="encryption-key-webhook-events">We’ve added two event types to <a href="/docs/en/manage-claude/organization-webhooks#encryption-key-events">organization webhooks</a>, which are in beta. We send <code>external_key.failed</code> when your key management service keeps refusing a customer-managed encryption key, and <code>external_key.recovered</code> when the key works again.</li>
</ul>
