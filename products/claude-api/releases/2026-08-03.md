# claude-api — August 3, 2026

<ul>
<li>The <a href="/docs/en/manage-claude/compliance-api">Compliance API</a> now returns transcripts of Cowork sessions started on claude.ai web or mobile, in beta for Claude Enterprise organizations. <code>GET /v1/compliance/apps/sessions/remote</code> lists sessions and <code>GET /v1/compliance/apps/sessions/remote/{session_id}/messages</code> returns one session’s transcript, using your existing Compliance Access Key with the <code>read:compliance_user_data</code> scope. See <a href="/docs/en/manage-claude/compliance-sessions#retrieve-remote-sessions">Sessions in the cloud</a>.</li>
</ul>
