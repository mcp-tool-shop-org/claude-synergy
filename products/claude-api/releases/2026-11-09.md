# claude-api — November 9, 2026

<ul>
<li id="claude-fable-5-2">We’ve launched <strong>Claude Fable 5.2</strong> (<code>claude-fable-5-2</code>), built for demanding reasoning and long-horizon agentic work. <strong>Claude Mythos 5.2</strong> (<code>claude-mythos-5-2</code>) offers the same capabilities only to organizations verified through Anthropic’s verification programs, such as the <a href="https://support.claude.com/en/articles/14604842" target="_blank" rel="noopener noreferrer">Cyber Verification Program</a>. Both models have a <a href="/docs/en/build-with-claude/context-windows">1M token context window</a>, 128k max output tokens, and always-on <a href="/docs/en/build-with-claude/thinking">adaptive thinking</a>. They cost $8 USD per MTok of input and $40 USD per MTok of output (Claude Fable 5.1 and Claude Mythos 5.1 cost $10 USD per MTok of input and $50 USD per MTok of output). Claude Fable 5.2 is available on the Claude API, <a href="/docs/en/build-with-claude/claude-on-amazon-bedrock-legacy">Amazon Bedrock (<code data-link-continues="before after">bedrock-runtime</code>)</a>, <a href="/docs/en/build-with-claude/claude-platform-on-aws">Claude Platform on AWS</a>, <a href="/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-managed">Claude Models on Google Cloud (Anthropic managed)</a>, <a href="/docs/en/build-with-claude/claude-models-on-google-cloud/google-managed">Claude Models on Google Cloud (Google managed)</a>, and <a href="/docs/en/build-with-claude/claude-in-microsoft-foundry">Claude in Microsoft Foundry</a>. See <a href="/docs/en/models/fable-5-2/whats-new-fable-5-2">What’s new in Claude Fable 5.2</a> for API changes and migration guidance. For model-specific prompting patterns, see <a href="/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2">Prompting Claude Fable 5.2</a>.</li>
<li>Claude Fable 5.2 and Claude Mythos 5.2 enforce the <a href="/docs/en/build-with-claude/preserved-thinking#prefix-check">prefix check</a> for every account, whatever its age. Claude Fable 5.1 returns the error by default on accounts created on or after August 31, 2026 (see <a href="/docs/en/build-with-claude/preserved-thinking#enforcement">When <code data-link-continues="before after">prefix_mismatch_behavior</code> is unset</a>). If your code edits the <code>system</code> prompt, <code>tools</code>, or an earlier message and then sends back a Claude Fable 5.2 or Claude Mythos 5.2 thinking block from a later turn, the request returns a 400 error. Before you switch, <a href="/docs/en/models/fable-5-2/migration-guide#fable-5-2-preserved-thinking">check whether your code edits the prefix</a>.</li>
<li>Claude Fable 5.2 and Claude Mythos 5.2 read other models’ thinking blocks on the Claude API and Claude Models on Google Cloud (Google managed). So on those platforms, a conversation that moves onto either model keeps its reasoning. The other models include Claude Opus 5.5, Claude Sonnet 5.5, and Claude Haiku 5.5.</li>
<li>No other model reads thinking blocks from Claude Fable 5.2 or Claude Mythos 5.2. When a conversation moves from either one to a model outside this pair, the API drops those blocks. That includes a move to Claude Opus 5.5 or Claude Fable 5.1. The request still succeeds. See <a href="/docs/en/build-with-claude/preserved-thinking#switching-models">Switching models mid-conversation</a>.</li>
<li>Claude Fable 5.2 and Claude Mythos 5.2 support computer use through the <code>computer_toolset_20260801</code> toolset. A request that declares the earlier <code>computer_20251124</code> tool returns a 400 error on every platform except Amazon Bedrock, where the earlier tool still works. See <a href="/docs/en/agents-and-tools/tool-use/computer-use-tool#migrate-from-computer-20251124">Migrate from <code data-link-continues="before">computer_20251124</code></a>.</li>
<li>With the <a href="/docs/en/agents-and-tools/tool-use/advisor-tool">advisor tool</a>, which is in beta, a Claude Fable 5.2 or Claude Mythos 5.2 executor accepts only Claude Fable 5.2 or Claude Mythos 5.2 as its advisor. Any other advisor returns a 400 error, so set the advisor’s <code>model</code> to one of these two models when you move an executor to them. Every executor model accepts Claude Fable 5.2 as its advisor. See <a href="/docs/en/agents-and-tools/tool-use/advisor-tool#model-compatibility">Model compatibility</a>.</li>
<li>Both models require 30-day data retention, like Claude Fable 5.1 and Claude Mythos 5.1. They aren’t available under zero data retention unless expressly authorized by Anthropic. See <a href="/docs/en/manage-claude/api-and-data-retention#model-specific-data-retention-requirements">Model-specific data retention requirements</a>.</li>
<li>Thinking blocks that Claude Fable 5.2 and Claude Mythos 5.2 produce work only in the account that produced them, or in an account linked to it. See <a href="/docs/en/build-with-claude/preserved-thinking#account-bound-thinking">Preserved thinking</a>.</li>
<li id="dreams-claude-fable-5-2"><a href="/docs/en/managed-agents/dreams">Dreams</a> (research preview) now supports Claude Fable 5.2. See <a href="/docs/en/managed-agents/dreams#feature-availability">Supported models</a>.</li>
<li id="fast-mode-claude-fable-5-2">We’ve launched <a href="/docs/en/build-with-claude/fast-mode">fast mode</a> for Claude Fable 5.2 in Messages API requests on the Claude API. Fast mode delivers up to 2.5x higher output tokens per second, at $16 USD per MTok of input and $80 USD per MTok of output. Set <code>speed: "fast"</code> on your request, with no beta header.</li>
</ul>
