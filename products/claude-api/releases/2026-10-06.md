# claude-api — October 6, 2026

<ul>
<li>We’ve added <code>capabilities.server_tools</code> to the <a id="_R_14gl6aqav5ut5u7ivd5urdalb_" aria-describedby="_R_34gl6aqav5ut5u7ivd5urdalbH2_" href="/docs/en/api/models/list">Models API</a><span id="_R_34gl6aqav5ut5u7ivd5urdalbH2_" data-find-omitted="" class="sr-only select-none">Preview with links to the API reference available — press Tab until focus enters the card, Escape to return.</span>. <code>GET /v1/models</code> and <code>GET /v1/models/{model_id}</code> now report whether each model accepts the web search and code execution tools. To check whether a model accepts the code execution tool, read <code>capabilities.server_tools.code_execution</code>. The top-level <code>capabilities.code_execution</code> reports whether code can call your request’s other tools. See <a href="/docs/en/models/overview#using-the-models-api">Using the Models API</a>.</li>
</ul>
