# claude-api — September 9, 2026

<ul>
<li>For <a href="/docs/en/build-with-claude/cache-diagnostics">cache diagnostics</a>, the API now stores a request’s fingerprint only when the request includes the <code>diagnostics</code> object. A request that sends only the <code>cache-diagnosis-2026-04-07</code> beta header is still accepted, but no fingerprint is stored. A later turn that points <code>previous_message_id</code> at it reports <code>previous_message_not_found</code>. Include <code>diagnostics</code> on every turn, with <code>"previous_message_id": null</code> on the first.</li>
</ul>
