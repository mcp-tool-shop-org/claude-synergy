# claude-api — August 7, 2026

<ul>
<li>You can now set a budget on a Claude Managed Agents session: a hard cap on the session’s spend, priced at public list rates. A session that reaches its budget pauses with the <code>budget_reached</code> stop reason instead of starting new model requests; changing or removing the budget resumes it. Deployments accept the same budget and apply it to each session they start. See <a href="/docs/en/managed-agents/budgets">Session budgets</a>.</li>
<li>You can now give a Claude Managed Agents session an advisor: a model at least as capable as the agent’s own that the session’s primary thread can consult mid-turn for strategic guidance. Configure it as a <code>{"type": "advisor"}</code> entry in the agent’s multiagent roster, naming the <code>model</code> to consult. See <a href="/docs/en/managed-agents/multiagent-orchestration#give-the-session-an-advisor">Give the session an advisor</a>.</li>
<li>You can now control where model inference runs for a Claude Managed Agents agent. Set <code>inference_geo</code> inside the <code>model</code> object when you create the agent (see <a href="/docs/en/managed-agents/agent-setup#pin-the-inference-geo">Pin the inference geo</a>), or <a href="/docs/en/managed-agents/sessions#pin-the-inference-geo-for-a-session">override it for a single session</a>. See <a href="/docs/en/manage-claude/data-residency">Data residency</a> for the available geos and pricing.</li>
<li>Claude Managed Agents sessions can now <a href="/docs/en/managed-agents/skills#load-skills-from-a-github-repository">load skills from a GitHub repository</a>. When a session <a href="/docs/en/managed-agents/github">mounts a repository</a>, any skills in its root <code>.claude/skills</code> directory are discovered automatically at session start and available to the agent for that session.</li>
</ul>
