# claude-api — October 14, 2026

<ul>
<li>We’ve launched <a href="/docs/en/manage-claude/opentelemetry">OpenTelemetry export</a> in beta, so you can trace Messages API requests and Claude Managed Agents sessions in your observability platform. The Claude SDK emits spans in Python, TypeScript, C#, Go, Java, PHP, and Ruby. To get spans from the API, <a href="/docs/en/manage-claude/opentelemetry/api#add-a-destination">add an OpenTelemetry destination</a> in the Claude Console.</li>
<li>Claude Managed Agents <a href="/docs/en/managed-agents/scheduled-deployments">scheduled deployments</a> are now <a href="/docs/en/build-with-claude/claude-platform-on-aws#claude-managed-agents">available on Claude Platform on AWS</a>.</li>
</ul>
