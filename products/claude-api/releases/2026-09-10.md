# claude-api — September 10, 2026

<ul>
<li>Claude Managed Agents permission policies now include <code>auto</code>: the server evaluates each agent or MCP tool call and runs it, denies it, or pauses for your approval. <code>agent.tool_use</code> and <code>agent.mcp_tool_use</code> events report how each call was evaluated in an <code>evaluation</code> field alongside <code>evaluated_permission</code>. See <a href="/docs/en/managed-agents/permission-policies#let-the-server-evaluate-each-call-with-auto">Let the server evaluate each call with <code data-link-continues="before">auto</code></a>.</li>
<li>Version 1.32.0 of the <code>ant</code> CLI adds <code>ant beta:sessions connect</code>, which attaches your terminal to a Claude Managed Agents session. You can follow the session live, send messages, and allow or deny tool calls that are waiting for approval. Pass <code>--web</code> to serve the Claude Console’s session viewer locally and open the session there instead. See <a href="/docs/en/cli-sdks-libraries/cli/sessions-connect">Connect to a Managed Agents session from your terminal</a>.</li>
</ul>
