# mcp-typescript-sdk 1.31.0

## Upgrade notes
- Stored OAuth tokens and client information now include an `issuer` field. Storage that rejects unknown fields needs to allow it.
- Pass `expectedIssuer` when constructing `ClientCredentialsProvider`, `PrivateKeyJwtProvider` or `StaticPrivateKeyJwtProvider`. Constructing them without it is deprecated.

## What's Changed
* [v1.x] Bind stored OAuth credentials to the authorization server that issued them by @maxisbey in https://github.com/modelcontextprotocol/typescript-sdk/pull/2888
