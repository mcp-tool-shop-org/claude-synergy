# mcp-inspector 1.0.6

## What's Changed

### v1.x security fixes

1.0.6 is a security release for the deprecated v1 line. Upgrade with `npx @modelcontextprotocol/inspector@v1-latest`, or move to v2 (`@latest`).

* **A malicious MCP server can no longer crash the proxy by streaming an unbounded server-sent event.** The proxy now caps how much of an upstream SSE stream it will buffer. A single line, or a single event, longer than 16 MiB closes that upstream connection with an error instead of growing the proxy's heap until it runs out of memory and drops every session. This covers the `sse` and `streamable-http` transports, including a standalone GET stream with the wrong content-type. The cap sits well above any legitimate message (four times the SDK reference servers' 4 MB inbound limit). ([GHSA-3xgv-mvj6-g78r](https://github.com/modelcontextprotocol/inspector/security/advisories/GHSA-3xgv-mvj6-g78r)) by @cliffhall in https://github.com/modelcontextprotocol/inspector/pull/2998
* **A v1 release no longer moves the GHCR image's `latest` tag.** `ghcr.io/modelcontextprotocol/inspector:latest` stays on the current v2 image. by @cliffhall in https://github.com/modelcontextprotocol/inspector/pull/2959
