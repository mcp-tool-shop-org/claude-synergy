# mcp-inspector 1.0.5

## What's Changed

### v1.x security fixes

1.0.5 is a security release for the deprecated v1 line. Upgrade with `npx @modelcontextprotocol/inspector@v1-latest`, or move to v2 (`@latest`).

* **The proxy now refuses two more fixed cloud metadata addresses.** Its connection guard already blocked `169.254.0.0/16`. It now also blocks `100.100.100.200` (Alibaba Cloud ECS) and `192.0.0.192` (Oracle Cloud Classic), including their IPv4-mapped IPv6 forms. The surrounding `100.64.0.0/10` range stays reachable, so Tailscale and other CGNAT targets still work. ([GHSA-fvg8-f358-w2c8](https://github.com/modelcontextprotocol/inspector/security/advisories/GHSA-fvg8-f358-w2c8))
