## Known issue

**npm audit reports GHSA-fc5q-39xc-vjpf (picomatch ReDoS, `<= 4.0.7`), which has no patched release yet.** In the published package it is reached only through `vite`, which the Inspector uses for `--web --dev`, and the globs it matches come from developer configuration rather than from MCP servers or the network. Every other package `npm audit` flags is flagged only through picomatch. We will take a fixed picomatch as soon as one is published ([#3000](https://github.com/modelcontextprotocol/inspector/issues/3000)).
