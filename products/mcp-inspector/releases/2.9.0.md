## Known issue

**OAuth profiles that share a server can overwrite each other's tokens** ([#2549](https://github.com/modelcontextprotocol/inspector/issues/2549)). If you use `MCP_INSPECTOR_OAUTH_STATE_PATH` to keep separate OAuth profiles against the same server, give each profile its own secret store too: set `MCP_INSPECTOR_SECRET_STORE=file` and a distinct `MCP_INSPECTOR_SECRET_FILE` per profile (or a per-profile `MCP_STORAGE_DIR`). The default single-profile setup is unaffected. A fix is planned for 2.10.0.
