# windsurf — Wave 14: Arena Mode

<p class="body3 mb-10 mt-0 text-sk-black">Arena Mode brings side-by-side model comparison directly into your IDE, plus Plan Mode for smarter task planning.</p>
<img alt="1.9544.24 Windsurf Wave 14 Arena Mode Changelog Banner" loading="lazy" width="1758" height="771" decoding="async" data-nimg="1" class="mb-5 mt-4 h-auto w-full rounded-md border border-sk-dusk-shade/20 md:mb-12 md:mt-8" src="https://exafunction.github.io/public/images/blog/wave14/wave14-hero-banner.png" style="color: transparent;">
<h2 class="body2 mb-4 mt-0 font-medium text-sk-black" id="arena-mode"><a class="text-sk-sea hover:underline" aria-hidden="true" href="#arena-mode" tabindex="-1"><span class="icon icon-link"></span></a>Arena Mode</h2>
<p class="body3 mb-10 mt-0 text-sk-black">Run two Cascade agents side-by-side with hidden model identities and vote on which performs better. Arena Mode lets you discover which models actually work best for <em>your</em> workflow, codebase, and tasks—not just what benchmarks or influencers say.</p>
<ul class="body3 mb-10 ml-4 mt-0 list-disc space-y-2 text-sk-black"><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Battle Groups</strong>: Choose specific models to compare or let Windsurf randomly select from curated groups like "fast models" vs "smart models"</li><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Personal &amp; Global Leaderboards</strong>: Your votes contribute to both a personal leaderboard (your preferences) and a global one (across all Windsurf users)</li><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Sync or Branch</strong>: Send followup prompts to both agents simultaneously, or branch and explore different paths individually</li></ul>
<p class="body3 mb-10 mt-0 text-sk-black">To get started, select the new <strong class="font-medium text-sk-black">Arena</strong> tab in the model picker. All battle groups are free for the first week for paid users.</p>
<h2 class="body2 mb-4 mt-0 font-medium text-sk-black" id="plan-mode"><a class="text-sk-sea hover:underline" aria-hidden="true" href="#plan-mode" tabindex="-1"><span class="icon icon-link"></span></a>Plan Mode</h2>
<p class="body3 mb-10 mt-0 text-sk-black">Plan Mode is a new Cascade mode alongside Code and Ask. Use it to create detailed implementation plans before diving into code.</p>
<p class="body3 mb-10 mt-0 text-sk-black"><strong class="font-medium text-sk-black">Pro tip</strong>: Type <code>megaplan</code> in the Cascade input box to trigger an advanced form that asks clarifying questions to create a more aligned, comprehensive plan.</p>
