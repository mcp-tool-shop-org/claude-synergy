# windsurf — Introducing Adaptive

<p class="body3 mb-10 mt-0 text-sk-black">We've made several model packaging changes, with more info <a class="text-sk-sea hover:underline" href="http://windsurf.com/blog/windsurf-adaptive">here</a>.</p>
<h2 class="body2 mb-4 mt-0 font-medium text-sk-black" id="adaptive-model-router"><a class="text-sk-sea hover:underline" href="#adaptive-model-router" aria-hidden="true" tabindex="-1"><span class="icon icon-link"></span></a>Adaptive Model Router</h2>
<p class="body3 mb-10 mt-0 text-sk-black">A new <strong class="font-medium text-sk-black">Adaptive</strong> model option is now available in the model picker. Adaptive intelligently selects the best model for each task, helping you make your quota last longer by avoiding overuse of premium models.</p>
<ul class="body3 mb-10 ml-4 mt-0 list-disc space-y-2 text-sk-black"><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Availability</strong>: Now available to all self-serve users on Pro, Max, and Teams plans.</li><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Dynamic model selection</strong> - Automatically chooses the right underlying model for your task while drawing down quota at a fixed per-token rate.</li><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Extra usage promo</strong> - Beyond your quota, extra usage is offered at 0.50 USD per 1M input tokens, 2.00 USD per 1M output tokens, and 0.10 USD per 1M cache read tokens for the next 2 weeks.</li></ul>
<h2 class="body2 mb-4 mt-0 font-medium text-sk-black" id="updated-model-picker-with-pricing-context"><a class="text-sk-sea hover:underline" href="#updated-model-picker-with-pricing-context" aria-hidden="true" tabindex="-1"><span class="icon icon-link"></span></a>Updated Model Picker with Pricing Context</h2>
<p class="body3 mb-10 mt-0 text-sk-black">The model picker now shows token pricing information directly, so you can see the exact rate extra usage is billed at.</p>
<ul class="body3 mb-10 ml-4 mt-0 list-disc space-y-2 text-sk-black"><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Token pricing display</strong> - Per-model input, output, and cache read token rates visible in the picker.</li><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Prompt cache timer</strong> - A new prompt cache timer is integrated into the context window indicator to help you track caching status.</li><li class="body3 text-sk-black"><strong class="font-medium text-sk-black">Token counts in response cards</strong> - Response cards after messages now include token counts so you can understand exactly how each message cost was calculated.</li></ul>
